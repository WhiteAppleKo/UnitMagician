## 2. 유형별 맞춤 핵심 요구사항

### 2-1. 비시청각 영역 요구사항 (공식: [구현 수단 / 방법] + [기대 효과 / 최적화 목표])

* **데이터 오염 방지**: 읽기 전용 카탈로그 SO(`UnitDataSO`)와 런타임 수치 데이터 구조체(`UnitRuntimeData`)를 분리 구조로 구현하여 인게임 데이터 변형에 의한 에디터 원본 파일 오염 방지 및 데이터 안정성 확보
* **결합도 최소화**: VContainer `GameLifetimeScope` DI 아키텍처를 적용하여 시스템 간 직접 참조를 배제하고 루즈 커플링 모듈성 달성
* **확장성 확보**: `IUnitChangeable` 인터페이스 및 C# `Action` 이벤트 구독 방식으로 구현하여 단위 변환 대상 오브젝트 확장에 따른 추가 코드 수정 최소화
* **시간 독립 연산**: UI 및 마우스 입력 이벤트를 `Time.unscaledDeltaTime` 기반 연산 구조로 구현하여 전역 시간 감속 중 UI 조작 먹통 현상 사전 방지
* **메모리 파편화 방지**: 빈번히 생성/파괴되는 적 투사체 객체를 오브젝트 풀링(`ObjectPool`) 구조로 구현하여 메모리 할당 최소화 및 가비지 컬렉션 부하 방지

### 2-2. 시청각 영역 요구사항 (사용자 행동 입력에 따른 실질적 동작 및 결과)

* **시간 감속 비주얼 반응**: 사용자가 마우스 우클릭 조작 시 즉시 화면 그레이스케일 Post-Processing 필터가 켜지고 전역 월드 시간이 80% 감속된다.
* **적 공격 게이지 UI 표출**: 개별 적 객체가 공격 게이지 충전 조작 시 적 머리 위 World Canvas UI 게이지 바 FillAmount가 실시간으로 0%에서 100%까지 채워진다.
* **단위 변환 UI 타깃팅**: 사용자가 마우스 커서를 `UnitChangeableComponent` 부착 물체 위로 올릴 시 타깃 아웃라인 셰이더 및 수치/단위 조작 팝업 UI가 표출된다.
* **단위 변환 피드백 연출**: 사용자가 퀵슬롯 단축키(1, 2, 3, 4) 누름 및 마우스 클릭 적용 시 수치 변경 텍스트 연출 및 셰이더 상태 변화(액체화, 무게 강조 연출)가 작동한다.

## 3. DLV 아키텍처 적용 방안

```
[ Data Layer ]          ↔       [ Logic Layer ]          ↔       [ Visual Layer ]
- UnitDataSO                     - UnitChangeService               - UnitTargetingUI
- UnitRuntimeData                - ResourceService                 - EnemyGaugeUIComponent
- ResourceDataSO                 - TimeSlowService                 - ScreenSlowEffect
- EnemyDataSO                    - EnemyAttackComponent
```

### 3-1. Data Layer (데이터 영역)
* **`UnitDataSO`**: 읽기 전용 단위 원본 프리셋 (단위 식별자, 코스트 계수, 셰이더 참조)
* **`UnitRuntimeData`**: 실시간 변형 수치 저장 객체 (`currentValue`, `appliedUnit`)
* **`ResourceDataSO`**: 마나 최대치 (100), 회복량 파라미터
* **`EnemyDataSO`**: 적 체력, 공격 충전 속도, 드롭 마나 파라미터

### 3-2. Logic Layer (로직 영역)
* **`UnitChangeService`**: 레이캐스트 타깃팅 탐지, 마나 소모 검증 요청, 단위 변환 명령 전달
* **`ResourceService`**: 마나 잔여량 계산, 소모 차감 승인, 적 사망 이벤트 수신 회복 처리
* **`TimeSlowService`**: 전역 `Time.timeScale` 0.2f 전환, 쿨타임 타이머 관리
* **`EnemyAttackComponent`**: 개별 적 독립 게이지 충전 연산, 충전 100% 시 투사체 자율 생성

### 3-3. Visual Layer (시청각 영역)
* **`UnitTargetingUIComponent`**: 타깃 지정 오브젝트 팝업 UI 및 아웃라인 셰이더 렌더링
* **`EnemyGaugeUIComponent`**: 개별 적 머리 위 World Space Canvas FillAmount 렌더링
* **`ScreenSlowEffectComponent`**: 시간 감속 발동 시 화면 그레이스케일 필터 전환 연출

## 4. 예상 검수 방법 및 테스트 가이드

### 4-1. SO 원본 변형 방지 검수
* **테스트 항목**: 인게임 실행 중 단위 변환(kg → g, 수치 변경) 반복 실행
* **검증 기준**: Unity Editor 정지 후 `UnitDataSO` Asset 수치가 원본 상태로 유지되는지 확인

### 4-2. 시간 감속 UI 반응성 검수
* **테스트 항목**: 마우스 우클릭 시간 감속(80% 감속) 상태에서 마우스 커서 타깃팅 및 퀵슬롯 단축키 조작
* **검증 기준**: 인게임 월드는 느려지되, UI 팝업 및 퀵슬롯 조작이 실시간(`unscaledDeltaTime`)으로 지연 없이 즉시 반응하는지 확인

### 4-3. 마나 연산 및 적 처치 루프 검수
* **테스트 항목**: 마나 소모 단위 조작 실행 후 적 처치
* **검증 기준**: 단위 조작 시 수치 비례 마나 차감 확인, 적 사망 시 마나(20~50) 즉시 회복 확인
