# 8. 캐릭터 스탯·상태 시스템 확장 — 무적 플래그 + 소모 무제한 오버라이드

> 분류: 기존 확장(캐릭터 스탯·상태 시스템) · 관련 단계: 3단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 세션 3 논의로 구체화: 무적 게이트를 "피격 판정/데미지 판정 분리" 패턴으로 구현하도록 확정.

## 8.1 시스템 개요
3단계 보스 회복 기믹(무적 전환)과 튜토리얼 전용 자원 완화(마나 소모 무제한)를 지원하기 위해, 기존 `ICharacterStatService`에 두 가지 상태 오버라이드를 추가한다.

## 8.2 핵심 동작
- **무적 플래그**: [03.보스AI페이즈시퀀스시스템.md](./03.보스AI페이즈시퀀스시스템.md)의 보스 FSM("두뇌")이 On/Off를 호출하는 상태값.
- **피격 판정과 데미지 판정 분리(세션 3 확정)**: 무적 플래그는 피격 파이프라인의 **마지막 단계(데미지 적용 단계)만** 차단한다. 파이프라인이 시작되는 즉시 `HitContext`에 "피격 판정 O"가 기록되고, 이후 온도(속성) 게이트 등 다른 판정들도 정상적으로 컨텍스트에 누적된다 — 무적 플래그는 오직 최종 `TakeDamage` 호출(HP 감소)만 무효화한다. 즉 파이프라인 흐름은 **"피격 판정 O → (속성 게이트 등 정상 판정) → 무적이라 데미지 판정 X → 파이프라인 종료"**이며, 도중에 조기 반환(early return)해서 컨텍스트 누적 자체를 건너뛰지 않는다.
  - 이 설계가 중요한 이유: [05.광역상태이상빙결폭발시스템.md](./05.광역상태이상빙결폭발시스템.md)가 "보스가 무적인 회복 페이즈 중에도 얼음 속성 피격이 들어왔는지"를 판단해야 하는데, 만약 무적 체크가 파이프라인 맨 앞에서 조기 반환해버리면 이 정보 자체가 유실된다.
- **마나 소모 무제한 오버라이드**: [06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md)만 호출 가능한 전용 API로 On/Off. On 상태에서는 `UseMP` 호출이 항상 성공 처리되고 실제 MP 값이 차감되지 않는다.

## 8.3 사용자 조작 흐름
유저는 이 오버라이드를 직접 조작하지 않는다 — 3단계 진입/해제 시점에 시퀀서/보스 FSM이 자동으로 On/Off 하며, 유저는 "마법을 아무리 써도 마나가 줄지 않는다", "보스를 때려도 죽지 않는다"는 결과만 체감한다.

## 8.4 시각/청각 효과
- 무적 상태: 보스 HP 게이지 위에 무적 아이콘/이펙트(방어막 형태) 표시.
- 마나 무제한: HUD 마나 게이지가 항상 가득 찬 상태 유지, 소비 시에도 게이지가 줄어드는 애니메이션이 재생되지 않음.

## 8.5 예외/실패 케이스
- 무적 상태에서 유저가 계속 공격을 시도하면, 타격 이펙트(임팩트 파티클)는 재생되지만 데미지 숫자/HP 감소는 발생하지 않는다 — "때리고 있는데 안 죽는다"는 느낌을 의도적으로 준다.
- 무적 상태에서 얼음 속성 투사체가 명중해도 HP는 그대로지만, 05번 문서가 구독하는 `HitContext`에는 "피격 O + 속성 게이트 통과"가 정상적으로 기록되어 있어야 한다 — 광역 빙결 판정이 이 기록에 의존하기 때문에, 무적 로직이 컨텍스트 기록 자체를 막아버리는 구현은 반드시 피해야 한다.
- 오버라이드가 해제된 이후(3단계 종료)에는 마나가 정상적으로 소모되어, 마나가 부족하면 마법 시전이 막히고 슬롯 아이콘이 비활성 표시로 전환된다.

## 8.6 체크리스트
- [ ] 보스 체력이 50%에 도달해 무적 상태로 전환되면, 유저가 보스를 공격해도 데미지 숫자가 뜨지 않고 체력바가 줄지 않는다.
- [ ] 3단계 오버라이드 구간에서 유저가 마법을 계속 시전해도, 마나 게이지가 소모되지 않고 항상 가득 찬 상태로 표시된다.
- [ ] 무적 상태에서 얼음 속성 투사체가 보스에 명중하면, 체력은 줄지 않지만 곧이어 광역 빙결 폭발이 정상적으로 발동한다(피격 정보가 유실되지 않았음을 보여주는 결과).
- [ ] (예외) 오버라이드 구간이 아닌 평소 전투 중에는 마나가 정상적으로 소모되어, 마나가 부족하면 마법 시전이 막히고 슬롯 아이콘이 비활성 표시로 바뀐다.
