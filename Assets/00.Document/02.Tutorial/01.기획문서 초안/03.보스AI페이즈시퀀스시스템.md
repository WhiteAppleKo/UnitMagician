# 3. 보스 AI · 페이즈 시퀀스 시스템

> 분류: 신규(두뇌 · FSM) · 관련 단계: 2단계, 3단계, 4단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 세션 2 논의로 재설계: 보스는 [01.NPC전투액터공통프레임워크.md](./01.NPC전투액터공통프레임워크.md)의 `INpcCombatActor` 구현체를 "몸통"으로 갖고, 이 문서가 "두뇌"(페이즈 FSM) 역할만 한다. 두뇌는 몸통을 **상속하지 않고 참조(주입)**해서 지시만 내린다.

## 3.1 시스템 개요
사화산의 수호 골렘(보스)의 기본 전투 패턴, HP 50% 감지에 따른 무적/회복 페이즈 전환, 실패 시 체력 소폭 회복까지 담당하는 보스 전용 FSM이다. 실제 이동·공격 실행은 01번 프레임워크가 전담하고, 이 문서는 "언제 무엇을 하라고 지시할지"만 담당한다.

## 3.2 핵심 동작
- **FSM 상태**: `Idle → BasicAttack(순환) → (HP 50% 도달) → Invulnerable+Healing → (회복 완료) → BasicAttack 재개(무적 해제) → (4단계 핵 명중) → Dead` / `(4단계 명중 실패) → HP 60% 재설정 → BasicAttack 재개`.
- **BasicAttack 상태**: FSM이 주기적으로 보스 액터(`INpcCombatActor`)의 `Attack(player)`를 호출해 사전 정의된 공격 패턴을 실행시킨다. 패턴 수치(공격 간격, 종류)는 `PureDataBossPattern`(SO)으로 데이터화해, 01번 프레임워크의 `PureDataNpcActor`와 동일한 방식으로 인스펙터에서 조정 가능하게 한다.
- **상태 전환 조건**: `ICharacterStatService.RuntimeData.HP` 변화를 구독해 50% 임계값 도달을 감지. [06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md)로부터 `OnCoreHitSuccess`/`OnCoreHitFail` 신호를 수신.
- **무적/회복 처리**: FSM이 [08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md](./08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)의 무적 플래그 API와 `Heal()`을 호출한다 — FSM 자신은 무적 구현을 갖지 않고 호출만 한다.
- **처치 연동(세션 3 확정)**: "핵 명중" 여부를 보스 AI가 직접 판정하지 않는다 — [06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md)가 피격 파이프라인의 `HitContext`(피격 판정 + 온도 속성 게이트 통과 여부)와 이 FSM의 현재 페이즈 상태를 조합해 성공/실패를 판단하고, 그 결과(`OnCoreHitSuccess`/`OnCoreHitFail`)를 이 FSM에 통보한다. FSM은 통보받은 신호에 따라 `Dead` 상태로 전환하거나 HP 60% 재설정 후 `BasicAttack`으로 복귀할 뿐이다. 상세 판정 조건은 [05.광역상태이상빙결폭발시스템.md](./05.광역상태이상빙결폭발시스템.md) 5.2절 참고.

## 3.3 사용자 조작 흐름
1. 2단계: 유저가 일반 공격/기본 마법으로 보스를 공격 → 보스 FSM이 `BasicAttack` 상태에서 액터에게 반격을 지시, 유저는 회피하며 HP를 50%까지 깎는다.
2. 3단계: HP 50% 도달은 유저 조작과 무관하게 보스 FSM이 자체 감지해 회복 페이즈로 전환한다.
3. 4단계: 유저가 확대된 얼음 투사체로 핵을 명중시키면 즉시 처치, 실패하면 페이즈가 재시작된다.

## 3.4 시각/청각 효과
- 페이즈 전환 시: 전신 화염 이펙트 파티클 + 포효 사운드 + 화면 흔들림(약).
- 회복 중: 체력바가 서서히 차오르는 UI 애니메이션 + 흡수 파티클(사화산 열기 → 보스로 이동).
- 실패 시 소폭 회복: 체력바가 살짝 튀어 오르는 짧은 UI 강조 애니메이션.

## 3.5 예외/실패 케이스
- 유저가 2단계에서 과도하게 피격당해도(현재 시스템 범위 밖) 튜토리얼이므로 사망 처리는 하지 않는 것을 전제로 한다 — 사망 페널티 정책은 별도 확인 필요(이 문서 범위 밖).
- 유저가 4단계에서 아무 조작도 하지 않아 투사체가 자연 낙하/소멸하면, "명중 실패"와 동일하게 처리되어 체력 60% 회복 + 재도전 루프가 시작된다.

## 3.6 체크리스트
- [ ] 유저가 일반 공격과 기본 마법으로 보스를 공격하면, 보스 체력바가 점점 줄어들고 보스는 피할 수 있는 공격 패턴을 주기적으로 반복한다.
- [ ] 보스 체력이 50%에 도달하면, 유저 입력 없이도 보스가 전신 화염에 휩싸이며 무적 상태로 전환되고 체력바가 다시 서서히 차오른다.
- [ ] 4단계에서 거대 얼음 투사체가 보스 핵에 명중하면, 보스가 즉시 사망 모션으로 전환되고 체력바가 0으로 떨어진다.
- [ ] (예외) 4단계에서 유저가 조작하지 않아 투사체가 빗나가면, 보스 체력이 60% 수준으로 튀어 오르듯 회복되고 몇 초 뒤 재도전 연출이 시작된다.
