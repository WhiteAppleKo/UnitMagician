# 1. NPC 전투 액터 공통 프레임워크

> 분류: 신규(기반 프레임워크) · 관련 단계: 1, 2, 3, 4단계(간접 — 02/03번 시스템의 기반)
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 세션 2 논의로 신설: "아군 NPC"와 "보스"를 각각 독립적으로 구현하지 말고, 이동/공격을 실행하는 **공통 액터(몸통)**를 먼저 만들고 그 위에 아군/보스 전용 "두뇌"를 얹는 구조로 재설계했다.

## 1.1 시스템 개요
아군 NPC([02.아군NPC전투지원행동시스템.md](./02.아군NPC전투지원행동시스템.md))와 보스([03.보스AI페이즈시퀀스시스템.md](./03.보스AI페이즈시퀀스시스템.md))를 포함해, "이동하고 공격을 실행하는" 모든 NPC가 공유하는 범용 실행 계층(액추에이터/몸통)이다. 각 NPC 전용 "두뇌"(이벤트 시퀀서가 지시하는 아군, 보스 전용 FSM)가 이 프레임워크의 공통 API를 호출해 실제 이동/공격을 실행시킨다.

현재 프로젝트는 이동/전투 로직이 전부 플레이어 입력(`InputReader`)에 묶여 있어(`LocomotionLogicSystem`, `UnitCasterSystem` 등), AI·이벤트가 구동하는 NPC 실행 로직이 전혀 없다. 이 프레임워크가 없으면 아군 NPC와 보스가 각각 독립적인 일회성 로직으로 중복 구현되어, 향후 다른 스테이지의 적/아군을 추가할 때마다 시스템을 새로 만들어야 한다.

## 1.2 핵심 동작
- **공통 인터페이스**: `INpcCombatActor` — `MoveTo(Vector3 destination)`, `Attack(GameObject target, PureDataUnit magic = null)`, `PlayMotion(string motionKey)`와, 진행 상태를 알리는 `OnAttackExecuted`/`OnMoveCompleted` 같은 이벤트를 노출한다.
- **공통 구현체**: 아군/보스 GameObject에 부착되는 `NpcCombatActorComponent`가 실제 투사체 스폰, 애니메이션 재생, 물리 이동을 담당한다. 플레이어의 `UnitCasterSystem` Strategy 패턴처럼 "무엇을 실행할지"만 인터페이스로 노출하고, "누가 언제 호출하는지"(이벤트 시퀀서, 보스 FSM)는 완전히 분리한다.
- **데이터**: 공격 파라미터(투사체 프리팹, 발사 속도, 쿨타임)는 기존 컨벤션대로 `PureDataNpcActor`(SO)로 정의해 인스펙터에서 설정한다.
- **원칙(리뷰 반영 — 상속 대신 컴포지션)**: 보스 전용 페이즈 로직은 이 액터를 **참조(주입)해서 지시**할 뿐, 액터 클래스를 상속해서 오버라이드하지 않는다. `OptionUIComponent`/`CameraOptionUIController` 상속 구조에서 발생했던 중복 인스턴스 등록 버그, `ITargetStencilService` 이중 등록 버그와 같은 함정을 이 프로젝트가 이미 겪었기 때문에 동일한 패턴을 반복하지 않는다.

## 1.3 사용자 조작 흐름
이 프레임워크 자체는 유저가 직접 조작하지 않는다. "두뇌" 역할의 시스템(이벤트 시퀀서, 보스 FSM)이 조건을 판단해 이 프레임워크의 API를 호출하면, 그 결과가 화면에 나타나는 방식으로 유저에게 체감된다.

## 1.4 시각/청각 효과
액터 구현체가 재생하는 발사/이동 모션, 투사체 스폰 이펙트, 사운드 — 구체적인 연출은 이 프레임워크를 사용하는 각 시스템(02번 아군, 03번 보스) 문서에서 정의한다. 이 문서는 "실행 규약"만 정의하고 구체적 비주얼을 소유하지 않는다.

## 1.5 예외/실패 케이스
- 목표(타겟)가 파괴/처치되어 이미 존재하지 않는 상태에서 `Attack(target)`이 호출되면, 액터는 공격을 실행하지 않고 대기 상태를 유지한다(호출부에서 유효성 검증 후 호출하는 게 원칙이지만, 액터 자신도 방어적으로 무시해야 한다).
- 이동 중(`MoveTo` 진행 중)에 새로운 `Attack` 명령이 들어오면 이동을 중단하고 공격을 우선 실행할지, 이동 완료 후 공격할지 정책이 필요하다 — 확인 필요 항목.

## 1.6 체크리스트
> 이 문서는 기반 프레임워크라 일반화된 관점으로 서술한다. 구체적인 장면(발사 이펙트, 사운드 등)은 [02.아군NPC전투지원행동시스템.md](./02.아군NPC전투지원행동시스템.md), [03.보스AI페이즈시퀀스시스템.md](./03.보스AI페이즈시퀀스시스템.md) 체크리스트 참고.

- [ ] 두뇌 역할의 시스템이 임의의 NPC 액터에게 "특정 목표를 공격하라"는 명령을 내리면, 해당 NPC가 목표 방향으로 발사 모션을 재생하고 투사체(또는 공격 판정)가 목표를 향해 생성된다.
- [ ] 두뇌 역할의 시스템이 NPC 액터에게 "특정 위치로 이동하라"는 명령을 내리면, NPC가 해당 위치까지 걸어가 이동 모션을 재생하다가 도착 시 정지 모션으로 전환된다.
- [ ] (예외) 목표가 이미 사라진 상태에서 공격 명령이 들어오면, NPC는 아무 반응 없이 기존 대기 모션을 유지한다.
