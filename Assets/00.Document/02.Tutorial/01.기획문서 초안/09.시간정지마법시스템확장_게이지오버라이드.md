# 9. 시간 정지 마법 시스템 확장 — 게이지 오버라이드 + 이벤트 전용 접근

> 분류: 기존 확장(시간 정지 마법 시스템) · 관련 단계: 3단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)

## 9.1 시스템 개요
3단계의 "시간 정지 유지시간을 무제한으로 완화"하는 요구사항과, "자동 시간 정지 발동이 반드시 이벤트 시퀀서를 통해서만 이루어져야 한다"는 리뷰 원칙을 함께 다룬다.

## 9.2 핵심 동작
- **게이지 오버라이드**: `RuntimeDataTimeSlow.FocusGauge` 소모를 억제하는 On/Off 모드. On 상태에서는 시간 정지를 유지해도 게이지가 줄지 않음.
- **이벤트 전용 접근 원칙(리뷰 반영)**: `ActivateSlow()`/오버라이드 On·Off는 [06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md)만 호출할 수 있는 경로로 제한한다. 현재 시간 정지 시스템이 `CharacterLifetimeScope`(플레이어) 하위에 종속돼 있어, 플레이어와 무관하게 전투 필드 전체에 자동 발동시켜야 하는 3단계 요구사항과 구조적으로 맞지 않을 가능성이 있다 — 필요 시 플레이어로부터 독립된 시스템으로 분리하는 것을 구현 단계에서 검토한다.

## 9.3 사용자 조작 흐름
1. 보스 HP 50% 도달 → 시퀀서가 자동으로 시간 정지를 발동(유저 입력 없음).
2. 유저는 이미 발동된 시간 정지 상태에서 조준·속성 부여·크기 확대 조작만 수행.
3. 시퀀서가 3단계 종료를 판단하면 게이지 오버라이드를 해제.

## 9.4 시각/청각 효과
- 자동 발동 시: 기존 수동 발동과 동일한 흑백 정지 필터 + 투사체 컬러 강조가 즉시 적용(별도의 "자동 발동 전용" 연출 차별화는 없음).
- 게이지 무제한 구간: HUD 포커스 게이지가 항상 가득 찬 상태로 고정.

## 9.5 예외/실패 케이스
- 오버라이드가 걸리지 않은 일반 전투 중 시간 정지를 유지하면, 게이지가 정상적으로 소모되어 게이지가 0이 되는 순간 시간 정지가 강제 해제된다(기존 동작 유지).
- 유저가 3단계 도중 수동으로 시간 정지를 해제하려고 시도해도(만약 입력이 막히지 않는다면), 시퀀서가 관리하는 자동 발동 구간에서는 이 조작이 무시되어야 한다 — 정확한 입력 차단 범위는 확인 필요 항목으로 남긴다.

## 9.6 체크리스트
- [ ] 3단계 자동 시간 정지 구간에서 유저가 시간 정지를 오래 유지해도, 포커스 게이지가 줄어들지 않고 계속 가득 찬 상태로 유지된다.
- [ ] 보스 체력이 50%에 도달하면, 유저가 아무 입력도 하지 않았는데도 화면이 이미 흑백 정지 필터와 투사체 컬러 강조 상태로 전환돼 있다.
- [ ] (예외) 오버라이드가 적용되지 않는 일반 전투 구간에서 유저가 시간 정지를 유지하면, 게이지가 정상적으로 소모되어 게이지가 0이 되는 순간 시간 정지가 강제 해제된다.
