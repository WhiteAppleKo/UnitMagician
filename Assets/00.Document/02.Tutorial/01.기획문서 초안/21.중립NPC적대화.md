# 21. 중립 NPC 적대화 — 3번 연속 공격받으면 `Enemy` (기획서 초안)

> 작성일: 2026-10-10 · 상태: Goal 작성 완료(§6 가정은 추천안, 변경 가능)
> 형식: `코드_작업_기획서_가이드라인_v1.0.md`
> 선행: 16-C(`IFactionSettable`, Goal 33), 16-D(`BodyNeutral`/`AttackNeutral` 레이어, Goal 35).
> 사용자 확정(세션 12): NPC는 항상 스탯을 가지며 기본 진영은 아군 `Ally` 또는 중립 `Neutral`(상인 등)이다. **중립 NPC는 3번 연속으로 공격을 받으면 `Enemy`가 된다.**

---

## 1. 작업 개요 및 유형
**비시청각**(Pure Data / Logic). 진영이 바뀌면 몸체 레이어와 충돌 규칙이 자동으로 따라가는 데이터 경로는 16번에서 이미 만들었다(`RuntimeStatData.CurrentFaction`, `OnFactionChanged`, 몸체 레이어 갱신). 이 작업은 **"언제 진영을 바꾸는가"의 트리거 규칙**을 추가한다.

## 2. 핵심 요구사항
피격 처리 결과 신호(`OnDamageProcessed`)를 구독해 중립 피격자별로 연속 피격 수를 세고 임계 횟수에 도달하면 `CurrentFaction`을 `Enemy`로 바꾸게 하여, 코드 수정 없이 NPC별로 횟수/유효 시간을 조정할 수 있게 한다.

## 3. 데이터 정의 및 흐름

### 3-1. 데이터
- `PureStatData`(캐릭터 공통, 조정 가능): `hostileHitThreshold`(int, 기본 3, 0 이하면 적대화 안 함), `hostileHitWindowSeconds`(float, 기본 10 — 연속으로 인정되는 피격 간 최대 간격).
- `IHostilityRule`(신규, `Assets/PipeLine/Combat/`): `int HostileHitThreshold`, `float HostileHitWindowSeconds` — `CharacterStatComponent`가 `PureStatData` 값으로 구현.
- `RuntimeDataHostility`(신규, `03.InteractionSystem/00.Data/`, 순수 C#): 피격자별 `{ int HitCount, float LastHitTime }` 보관(`Dictionary<GameObject, HostilityState>`), 피격자 파괴/소멸 시 정리.

### 3-2. 흐름
1. `NeutralHostilityLogicSystem`(신규, `03.InteractionSystem/01.Logic/`, 순수 C#)이 `IInteractionService.OnDamageProcessed(DamageContext)`를 구독한다.
2. 카운트 대상 피격: `context.Victim`의 진영이 **`Neutral`** 이고(`IFactionProvider`), `context.Attacker`(발사자)가 `Neutral`이 아닌 진영(`IFactionProvider`)이며, 실제로 맞은 피격(`HitRegistered`)일 때. (무적 등으로 데미지가 무효여도 피격 판정이 있었다면 센다 — 가정, §6)
3. 연속 판정: 직전 피격으로부터 `HostileHitWindowSeconds` 이내이면 `HitCount++`, 초과하면 `HitCount = 1`로 다시 시작. `HitCount >= HostileHitThreshold`이면 피격자의 진영을 `Enemy`로 바꾼다(`IFactionSettable.SetFaction`; `CharacterStatComponent`가 `RuntimeStatData.CurrentFaction` 설정으로 구현) 후 해당 피격자의 카운터를 지운다.
4. 한번 `Enemy`가 되면 자동으로 `Neutral`로 돌아가지 않는다(되돌림 규칙은 이 작업 범위 밖).
5. 진영이 바뀌면 16번 경로로 몸체 레이어가 `BodyNeutral`→`BodyEnemy`로 이동하고 `OnFactionChanged`가 발행된다(추가 코드 없음).

### 3-3. 시청각
- 이번 작업은 규칙만 추가한다. 적대화 시 별도 연출(경고 표시, 적 하이라이트 변화 등)은 없다. 단, 진영이 `Enemy`가 되면 기존 규칙대로 락온 대상이 되고(`IsEnemy`) 공격 판정이 적 진영으로 처리된다.

## 5. 체크리스트
1. [ ] `Neutral` NPC가 플레이어편(Player/Ally) 공격에 3번 연속(유효 시간 이내) 맞으면 `CurrentFaction`이 `Enemy`로 바뀌고, 몸체 레이어가 `BodyNeutral`→`BodyEnemy`로 이동하며 `OnFactionChanged`가 1회 발행된다.
2. [ ] 2번 맞은 뒤 `HostileHitWindowSeconds`가 지나 다시 맞으면 카운트가 1부터 다시 시작해 `Neutral`을 유지한다.
3. [ ] `hostileHitThreshold`/`hostileHitWindowSeconds`를 PureStatData에서 바꾸면(예: 1) 코드 수정 없이 반영된다. 0 이하이면 적대화되지 않는다. 임계값/시간이 코드에 박혀 있지 않다(grep).
4. [ ] 중립이 아닌 피격자(`Ally`/`Enemy`/`Player`)와 `Neutral` 발사자(자기 편)의 피격은 카운트되지 않는다.
5. [ ] 피격자가 파괴/비활성화돼도 카운터가 누수되지 않는다(`RuntimeDataHostility` 정리). 투사체 풀링 재사용 시 이전 피격 기록이 새 판정에 영향을 주지 않는다.
6. [ ] 13~20 회귀(락온, 3단계 판정, 풀링, 컨텍스트 스택), 콘솔 에러 0건. 검증에 쓴 중립 NPC/값은 디스크에 남기지 않는다(씬에 중립 NPC가 없으므로 검증은 런타임에서 진영을 바꾼 NPC로 수행).

## 6. 가정 (사용자 미확정 — 추천안으로 작성, 변경 가능)
1. "3번 연속" = **유효 시간(기본 10초) 이내로 이어진 피격 3회**. 다른 대상 공격 여부와 무관, 중간에 시간이 지나면 리셋.
2. 카운트 대상 공격자는 **Neutral이 아닌 모든 진영**(플레이어, 아군, 적). 플레이어만 한정하려면 알려 주세요.
3. 피격 판정이 있었으면 데미지 무효(무적 등)여도 센다.
4. 적대화는 되돌리지 않는다.
