# 4. 파괴 가능 환경 오브젝트 시스템

> 분류: 신규 · 관련 단계: 1단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 세션 3 논의로 구체화: `IDamageable` 인터페이스 + 전용 경량 피격 파이프라인(속성 게이트 → 데미지 게이트)으로 설계 확정.

## 4.1 시스템 개요
1단계의 핵심 목표물인 "돌문"처럼, HP를 가진 캐릭터가 아니라 **파괴 가능한 환경 오브젝트**가 투사체 충돌로 파괴되는 판정/연출을 담당한다. 기존 상호작용·피격 시스템(`CharacterDamagePipeLine`)은 `ICharacterStatService`를 가진 캐릭터만 대상으로 하므로, 돌문 같은 비-캐릭터 대상은 별도 처리 경로가 필요하다.

## 4.2 핵심 동작 (설계 확정)

### 공격/피격 파이프라인 분리
기존 단일 고정 파이프라인을 **공격 파이프라인(공격자 스탯 기반 산출)** ↔ **피격 파이프라인(피격자별로 스텝을 다르게 구성)**으로 분리한다. 캐릭터는 기존처럼 회피→방어→치명타→차단→적용의 무거운 피격 파이프라인을 쓰고, 돌문 같은 단순 오브젝트는 `IDamageable`을 구현해 훨씬 가벼운 전용 피격 파이프라인을 쓴다.

### `IDamageable` — 돌문 전용 2단 게이트 피격 파이프라인
1. **1차 게이트 — 속성(온도) 체크**: 공격 데이터(투사체)의 온도 단위 값이 "얼음" 판정 임계치를 만족하는지 확인한다. **불만족 시 즉시 무효 처리** — 데미지 계산 자체에 들어가지 않고, 기존 "튕겨나감" 이펙트만 재생한다(기획서의 "흠집도 나지 않고 튕겨 나감"과 정확히 일치).
2. **2차 게이트 — 데미지 크기 체크 (1차 통과 시에만 진입)**: 최종 데미지를 계산해 돌문의 파괴 임계값(HP)과 비교한다.
   - 최종 데미지 = 기본 데미지 × 질량 비율(`RuntimeDataUnit.CurrentValue / OriginalValue`) — [07.단위마법조작시스템확장_온도단위및조준연출보강.md](./07.단위마법조작시스템확장_온도단위및조준연출보강.md)의 `MassUnitApplicatorSO`가 스케일 계산에 쓰는 것과 **동일한 비율을 재사용**해 별도 공식을 새로 만들지 않는다.
   - 예: 돌문 HP=100, 기본(무속성) 투사체 데미지=70 → 얼음 속성만 부여하고 크기를 키우지 않으면 70 < 100이라 파괴 실패. 크기를 확대해 질량 비율을 키우면 데미지가 100을 넘어서는 순간 파괴된다.
   - **판정 결과가 HP 미만이면**: 데미지는 적용되지 않고(파괴 실패), 대신 **문에 일시적으로 금이 갔다가 다시 복구되는 이펙트**를 재생해 "속성 부여만으로는 부족하고 크기도 더 키워야 한다"는 것을 플레이어에게 명확히 피드백한다.
3. **누적 없음(중요)**: 돌문의 "HP 100"은 여러 번의 타격이 누적되는 지속 체력이 아니라, **매 충돌마다 독립적으로 판정되는 파괴 임계값**이다. 실패한 타격의 데미지는 다음 타격에 이월되지 않는다 — 그렇지 않으면 무속성 투사체가 반복 명중해 우연히 문이 부서지는 상황이 생겨, 퍼즐 의도(반드시 얼음+확대 조작을 해야 함)가 깨진다.

### 피격 판정과 데미지 판정 분리
파이프라인은 `HitContext`를 누적하며 진행된다 — "피격 판정(충돌 발생) O" 플래그는 1차 게이트 이전에 이미 세팅되고, "데미지 판정(파괴 성공) O/X"는 2차 게이트 결과로 별도 기록된다. 이 패턴은 [08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md](./08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)의 "무적 상태에서도 피격 신호는 발행"과 동일한 구조를 재사용한다.

## 4.3 사용자 조작 흐름
1. 유저가 1단계 진행 흐름(시간 정지 → 얼음 속성 부여 → 크기 확대)을 완료한 채로 시간 정지를 해제한다.
2. 거대해진 얼음 투사체가 자연스럽게 날아가 돌문과 충돌한다(유저의 추가 조작 불필요, 물리 시뮬레이션에 위임).
3. 충돌과 동시에 1차(속성) → 2차(데미지) 게이트가 순차 판정되고, 결과에 따라 파괴 / 파손→복구 / 무반응 중 하나의 연출이 재생된다.

## 4.4 시각/청각 효과
- 파괴 순간(2차 게이트 통과): 돌문 분열 애니메이션 + 얼음 파편/암석 파편 파티클 동시 분출 + 저음의 파괴 충격음.
- 파손→복구(1차 통과, 2차 미달): 문 표면에 금이 가는 이펙트 + 짧은 진동 → 곧바로 금이 다시 메워지는 복구 파티클과 함께 사운드 재생.
- 완전 무반응(1차 게이트 실패): 기존 1단계 초반과 동일한 "튕겨나감" 스파크 이펙트 + 금속성 타격음.

## 4.5 예외/실패 케이스
- 유저가 얼음 속성만 부여하고 크기를 확대하지 않은 채 충돌시키면, 1차 게이트는 통과하지만 2차 게이트(데미지)에서 미달 판정 → 파손→복구 이펙트만 재생되고 문은 원상태로 돌아간다(재시도 유도).
- 유저가 시간 정지 없이 방치하면 일반(무속성) 투사체가 1차 게이트에서 계속 걸러져 문은 영원히 열리지 않는다([02.아군NPC전투지원행동시스템.md](./02.아군NPC전투지원행동시스템.md)와 동일한 "무한 대기" 상태).

## 4.6 체크리스트
- [ ] 얼음 속성이 부여되고 크기가 충분히 확대된 투사체가 시간 정지 해제 후 돌문에 충돌하면, 돌문이 파괴되며 통로가 열리고 얼음 파편이 사방으로 흩날린다.
- [ ] 크기를 확대하지 않은 일반(무속성) 투사체가 돌문에 부딪히면, 돌문은 아무 반응 없이 기존처럼 투사체만 튕겨나가는 스파크 이펙트가 재생된다.
- [ ] 얼음 속성만 부여하고 충분히 확대하지 않은 투사체가 돌문에 부딪히면, 문에 금이 갔다가 곧바로 복구되는 이펙트가 재생되고 문은 파괴되지 않는다.
- [ ] (예외) 유저가 투사체 조작 없이 시간 정지만 걸었다가 해제하면, 투사체는 원래 크기 그대로 날아가 돌문에 흠집 없이 튕겨 나간다.
- [ ] (예외) 얼음 속성+확대에 한 번 실패해 파손→복구 연출이 나온 뒤에도, 돌문은 다음 시도를 위해 항상 원상태(HP 100)에서 다시 판정된다 — 이전 실패의 데미지가 누적되어 남아있지 않다.
