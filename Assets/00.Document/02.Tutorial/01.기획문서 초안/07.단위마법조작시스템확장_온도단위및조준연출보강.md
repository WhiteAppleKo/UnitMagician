# 7. 단위 마법 조작 시스템 확장 — 온도 단위 및 조준/연출 보강

> 분류: 기존 확장(단위 마법 조작 시스템) · 관련 단계: 1단계, 4단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 리뷰 반영: 원래 목록의 "원소 속성 부여 시스템(신규)"과 "투사체 락온 판정 보강(확장)" 두 항목을 이 문서 하나로 통합.

## 7.1 시스템 개요
1·4단계의 핵심 조작인 "투사체 조준 → 얼음 속성 부여 → 크기 확대"를 하나의 흐름으로 지원한다. 얼음 속성은 별도 시스템이 아니라 기존 단위(질량/부피/방향벡터) 개념의 연장인 **온도(Temperature) 단위**로 구현하며, 락온 판정은 대상이 시간 정지로 완전히 멈춰 있으므로 기존 로직을 그대로 사용한다.

## 7.2 핵심 동작
- **조준(락온)**: 시간 정지 중에는 대상이 정지해 있으므로, 기존 `MagicLockOnComponent`/`UnitCasterSystem`의 화면 중심 스피어캐스트 락온 로직을 그대로 재사용한다. 별도의 고속 이동체 판정 로직은 불필요(리뷰로 확정).
- **온도 단위 적용**: `PureDataUnit`/`RuntimeDataUnit`에 온도 값을 추가하고, 값이 음수 방향으로 커질수록 "얼음" 강도가 강해지는 것으로 정의한다(양수 방향은 추후 불 속성 확장 여지로 남김). 적용 시 기존 `UnitVisualApplicatorSO` 계열과 동일한 방식으로 `TemperatureUnitApplicatorSO` 같은 별도 적용자가 텍스처/머티리얼 교체와 파티클 재생을 담당한다.
- **크기 확대**: 기존 `MassUnitApplicatorSO`(질량비 → 스케일 세제곱근 변환)를 그대로 사용하되, 스케일 변화가 발생하는 순간에 VFX(마법 링 회전 + 팽창 이펙트)를 재생하는 훅을 추가한다.
- **데미지 공식 재사용(세션 3 확정)**: `MassUnitApplicatorSO`가 스케일 계산에 쓰는 질량 비율(`CurrentValue / OriginalValue`)은 [04.파괴가능환경오브젝트시스템.md](./04.파괴가능환경오브젝트시스템.md)의 파괴 데미지 계산(`최종 데미지 = 기본 데미지 × 질량 비율`)에도 그대로 재사용된다 — 크기와 데미지가 같은 값에서 파생되므로 별도 수치 체계를 새로 만들 필요가 없다.
- **조준 입력 방식(리뷰 반영)**: 초기 탑뷰 전제의 "방향 직접 조작" 개념 대신, 현재는 유저가 마우스로 목표 도착 지점을 지정하는 방식을 기본으로 한다(기존 `TopViewMouseCastingStrategy`의 클릭 캐스팅 방향과 일치).

## 7.3 사용자 조작 흐름
1. 시간 정지로 멈춘 투사체를 마우스/조준으로 락온한다.
2. 온도 단위를 낮추는 조작(얼음 속성 인챈트)을 실행한다 → 투사체가 얼음 속성으로 전환.
3. 크기 확대 조작을 실행한다 → 투사체가 거대 얼음 창으로 팽창.
4. 시간 정지를 해제해 확대된 투사체를 목표로 날려보낸다.

## 7.4 시각/청각 효과
- 락온 시: 대상 외곽선 하이라이트 + 조준 사운드.
- 온도(얼음) 적용 시: 표면 텍스처가 얼음으로 전환 + 서리 파티클 + 파지직(크랙) 사운드.
- 크기 확대 시: 마법 링 회전 이펙트 + 즉각 팽창(스케일 튐) 애니메이션 + 확대 사운드.

## 7.5 예외/실패 케이스
- 온도 단위를 적용하지 않고 크기만 확대하면, 투사체는 커지지만 얼음 이펙트 없이 원래 재질 그대로 확대된다 — [04.파괴가능환경오브젝트시스템.md](./04.파괴가능환경오브젝트시스템.md)의 "서리 자국만 남기고 튕김" 분기로 이어진다.
- 락온 대상이 시간 정지 해제로 다시 움직이기 시작한 뒤에는 온도/크기 조작이 불가능해야 한다(조작 가능 시간이 시간 정지 지속시간으로 한정됨).

## 7.6 체크리스트
- [ ] 시간 정지로 멈춰있는 투사체를 조준(락온)하면, 투사체 외곽선이 강조 표시되며 조작 가능한 대상임을 알리는 하이라이트가 나타난다.
- [ ] 락온된 투사체에 얼음 속성(온도 단위 인챈트)을 적용하면, 투사체 표면 텍스처가 얼음으로 바뀌고 서리 파티클과 파지직 효과음이 재생된다.
- [ ] 얼음 속성이 적용된 투사체의 크기를 확대 조작하면, 마법 링이 회전하며 투사체가 즉각 부풀어 오르는 팽창 이펙트와 확대 사운드가 함께 재생된다.
- [ ] (예외) 얼음 속성을 부여하지 않고 크기만 확대하면, 투사체는 커지지만 얼음 이펙트(서리/파지직) 없이 원래 재질 그대로 확대된다.
