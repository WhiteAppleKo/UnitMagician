# 5. 광역 상태이상(빙결 폭발) 시스템

> 분류: 신규 · 관련 단계: 4단계
> 전체 개요/리뷰 반영 사항: [00_Overview.md](./00_Overview.md)
> 세션 3 논의로 구체화: "보스 핵 명중"이라는 전용 히트박스/판정을 없애고, [06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md)가 (이 보스 + 회복 페이즈 상태 + 피격 파이프라인의 속성 게이트 결과)를 조합해 결정타 여부를 판단하는 구조로 변경.

## 5.1 시스템 개요
4단계 피니시 연출 — 거대 얼음 투사체가 불타는 보스를 꿰뚫으며 발생하는 **대규모 빙결 폭발과 주변 지형 동결**을 담당한다. "핵"은 이제 순수 연출(VFX가 시작되는 지점)일 뿐, 별도의 전용 히트박스나 물리 판정이 필요하지 않다 — 보스 몸통 어디에 맞아도 되고, 실제 성공/실패 판정은 이벤트 시퀀서가 상태 조합으로 결정한다.

## 5.2 핵심 동작
- **트리거**: 보스에 대한 피격 파이프라인이 완료되며 `HitContext`(피격 판정 O/X, 온도 속성 게이트 통과 여부)를 발행한다.
- **조건(이벤트 시퀀서가 판단)**: 아래 세 조건이 동시에 만족될 때만 "결정타"로 판정한다.
  1. 대상이 이 튜토리얼의 보스 인스턴스인가
  2. 보스가 현재 [03.보스AI페이즈시퀀스시스템.md](./03.보스AI페이즈시퀀스시스템.md)의 회복(무적) 페이즈 상태인가
  3. 해당 피격의 `HitContext`에서 온도(얼음) 속성 게이트가 통과됐는가 — [08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md](./08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)에서 설명하듯, 무적 상태라 실제 데미지는 적용되지 않았어도(데미지 판정 X) "피격 판정 O" + "속성 게이트 통과"는 `HitContext`에 그대로 남아있으므로 이 판단에 사용할 수 있다.
- **결과**: 세 조건이 모두 만족되면 이벤트 시퀀서가 이 시스템에 발동 신호를 보내고, 명중 지점을 중심으로 반경 내 대상(보스, 인근 지형 오브젝트)에 빙결 상태 이펙트를 순차 적용한 뒤 보스 AI 시스템에 "처치" 신호를 전달한다.
- **설계 검토 사항**: [04.파괴가능환경오브젝트시스템.md](./04.파괴가능환경오브젝트시스템.md)와 동일하게, 광역으로 여러 대상(보스+지형)에 동시에 효과를 적용해야 하므로 공격/피격 파이프라인 분리 구조에서 "하나의 공격 파이프라인 결과를 다수의 피격 파이프라인에 브로드캐스트"하는 형태로 자연스럽게 확장 가능 — 이 시스템 구현 시점에 함께 검토.

## 5.3 사용자 조작 흐름
1. 유저가 4단계에서 락온 → 얼음 속성 인챈트 → 크기 확대까지 마친 투사체를 보스 방향으로 유도(시간 정지 해제 시 자연 비행).
2. 투사체가 보스 몸통 어디에든 명중하는 순간, 유저의 추가 조작 없이 이벤트 시퀀서가 조건을 판단한다.
3. 조건이 모두 만족되면 광역 빙결 연출이 자동 재생되고, 연출 종료 후 자동으로 승리 화면([06.이벤트시퀀서시스템.md](./06.이벤트시퀀서시스템.md) 소관)으로 전환된다.

## 5.4 시각/청각 효과
- 명중 순간: 화면 전체 임팩트 프레임(짧은 화이트아웃/슬로우) + 얼음 폭발 파티클(방사형) + 저음 폭발음.
- 확산: 보스 표면과 주변 사화산 지형에 얼음 텍스처/셰이더가 순차적으로 덮이는 프리징 웨이브 연출.
- 종료: 정적인 얼음 조각상이 된 보스 위로 카메라가 서서히 줌아웃.

## 5.5 예외/실패 케이스
- 보스가 회복(무적) 페이즈가 아닐 때(예: 평상시 BasicAttack 상태) 얼음 속성 투사체가 명중해도, 조건 2(페이즈 상태)가 불만족이라 광역 빙결은 발동하지 않고 일반 피격 이펙트만 재생된다.
- 얼음 속성 게이트를 통과하지 못한 투사체(온도 단위가 중립이거나 부족)가 회복 페이즈 중 보스에 명중하면, `HitContext`에 "피격 판정 O / 속성 게이트 X"가 기록되어 이벤트 시퀀서가 이를 **실패**로 판정 — [03.보스AI페이즈시퀀스시스템.md](./03.보스AI페이즈시퀀스시스템.md)의 체력 60% 회복 분기로 이어진다.
- 투사체가 보스에 아예 명중하지 않고(완전히 빗나감) 회복 페이즈 지속시간이 끝나면, `HitContext` 자체가 발행되지 않으므로 이벤트 시퀀서는 타임아웃으로 동일하게 실패 처리한다.

## 5.6 체크리스트
- [ ] 보스가 회복 페이즈 중일 때 얼음 속성이 부여되고 확대된 투사체가 보스에 명중하면, 명중 지점에서 대규모 빙결 폭발 이펙트가 퍼지며 보스와 주변 사화산 지형이 일제히 얼어붙는다.
- [ ] 빙결 폭발이 발생하면, 보스는 즉시 얼음 조각상 형태의 사망 모션으로 전환되고 화면이 승리 연출로 넘어간다.
- [ ] (예외) 보스가 회복 페이즈가 아닐 때 얼음 속성 투사체가 명중하면, 광역 빙결 폭발이 발생하지 않고 일반 피격 이펙트만 재생된다.
- [ ] (예외) 회복 페이즈 중 얼음 속성이 아닌 투사체가 명중하거나 투사체가 완전히 빗나가면, 광역 빙결 폭발 없이 보스 체력이 60%로 회복되는 재도전 연출이 시작된다.
