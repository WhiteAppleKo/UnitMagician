## Goal
(1) 공격 판정체 레이어 이름을 투사체에 한정되지 않게 `AttackAlly`/`AttackEnemy`로 바꾸고, (2) 중립 진영용 `BodyNeutral`/`AttackNeutral`을 추가해 중립 발사자가 자기 몸이나 다른 중립 NPC를 맞히는 문제를 구조적으로 없앤다.

## 범위
### 포함
1. **조사 먼저**: `ProjectileAlly`/`ProjectileEnemy`/`GetProjectileLayer` 사용처 전수(코드, `TagManager`, 씬/프리팹, 문서), `FactionRelation`의 `GetSide`/`IsSameSide`/`IsHostile` 사용처, 중립(`Neutral`) 진영이 현재 어디에 쓰이는지(돌문 등 비캐릭터 포함)를 읽고 기획서 §6-2와 다른 점이 있으면 구현 전에 보고한다.
2. **레이어**: `ProjectSettings/TagManager.asset`에서 10번 `ProjectileAlly`→`AttackAlly`, 11번 `ProjectileEnemy`→`AttackEnemy`로 **이름만** 바꾸고(번호 유지 — 씬/프리팹 레이어 참조가 깨지지 않음을 확인), 12번 `BodyNeutral`, 13번 `AttackNeutral`을 추가한다(3번 이름 없는 레이어는 건드리지 않는다).
3. **`FactionRelation`**: 레이어 목적의 중립 편(`NeutralSide`)을 추가하고 `IsSameSide(Neutral, Neutral)`을 true로 한다. **`IsHostile`의 결과는 변하지 않는다**(Neutral은 누구에게도 적대적이지 않음 — 기존 `RuntimeStatData.IsHostile` 위임 결과가 모든 쌍에서 같은지 확인).
4. **`FactionLayers`**: `GetProjectileLayer`→`GetAttackLayer`로 개명, 이름 상수 갱신, `Neutral` → `BodyNeutral`/`AttackNeutral` 변환 추가(단 **비캐릭터 오브젝트(돌문 등)는 몸체 레이어를 적용하지 않으므로 `Default` 유지** — 몸체 레이어 적용은 기존대로 `CharacterStatComponent`만), 시작 시 충돌 매트릭스가 `IsSameSide` 쌍(`AttackAlly↔BodyAlly`, `AttackEnemy↔BodyEnemy`, `AttackNeutral↔BodyNeutral`) 3개만 끄도록 한다.
5. **호출부/문서**: `CollisionDamageTrigger.SetFaction` 등 개명된 메서드의 호출부, 코드 주석, 16번 기획서 외 관련 문서 표기(`Projectile*` 레이어명 언급)를 정리한다.

### 제외 (건드리지 않는다)
- 충돌 규칙의 다른 변경, `IgnoreAttack` 레이어(Goal 38), 중립 NPC 배치/적대화(Goal 40), 진영 변경 경로(33번), 레이어 번호 재배치.

## 완료 기준
- [ ] `TagManager` 레이어 8~13 = `BodyAlly`, `BodyEnemy`, `AttackAlly`, `AttackEnemy`, `BodyNeutral`, `AttackNeutral`. 코드/에셋/문서에 옛 이름(`ProjectileAlly`, `ProjectileEnemy`, `GetProjectileLayer`) 잔존 0건(grep). 이름 변경 후에도 씬/프리팹의 기존 오브젝트가 같은 레이어 번호에 있다.
- [ ] 충돌 매트릭스 전수 열거에서 꺼진 쌍이 정확히 3개(`AttackAlly↔BodyAlly`, `AttackEnemy↔BodyEnemy`, `AttackNeutral↔BodyNeutral`).
- [ ] 런타임에 아군 NPC의 `CurrentFaction`을 `Neutral`로 바꾸면 몸체 레이어가 `BodyNeutral`이 되고(루트+자식 모두), 그 NPC가 쏜 투사체가 `AttackNeutral`이 되어 **자기 몸과 다른 중립 몸체를 맞히지 않고**, 아군/적 몸체와 `Default`(돌문 포함)는 맞힌다. 아군/적 투사체는 중립 몸체를 맞힌다. 진영을 `Enemy`/`Ally`로 바꾸면 레이어가 따라간다(검증 후 복원, 디스크에 남기지 않음).
- [ ] 돌문(비캐릭터, `Neutral` 진영)이 `Default`에 남아 아군 샷에 대한 1·2차 게이트가 기존대로 동작한다. 16-B의 같은 편 통과(아군 샷↔플레이어 20/20), 3단계 판정, 보스 샷→플레이어 명중, 풀 재사용 시 레이어 복원이 회귀 없이 동작한다.
- [ ] `RuntimeStatData.IsHostile` 결과가 변경 전과 모든 진영 쌍에서 같다. 콘솔 에러 0건, `DynamicsManager.asset` 디스크 불변, `TagManager` 변경이 위 레이어 정의뿐.

## 검증 절차
1. `unity command recompile` → `recompile_status` + 어셈블리 mtime 교차 확인(스테일 DLL 주의). `clear_console` 후 `console --level error` 0건.
2. Play Mode 실측. `Physics.GetIgnoreLayerCollision` 전수 열거, `eval`로 루트/자식 콜라이더 레이어 열거. 입력 주입이 필요한 항목은 Game 뷰 포커스 후 `InputSystem.QueueStateEvent`, 안 되면 UNVERIFIED로 명시.
3. `git diff --stat`/`git status`로 범위 확인(이전 세션 미커밋분과 구분).
