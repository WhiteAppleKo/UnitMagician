## Goal
돌문 사격의 시작·중단을 시퀀서가 방송하는 확정 신호(`1단계 시작`, `돌문 파괴`)로 옮기고, 돌문이 파괴되면 길을 막던 아군 NPC가 옆으로 비켜서게 한다.

## 범위
### 포함
1. **조사 먼저**: `TutorialSequencerLogicSystem`의 Stage1 처리, `AllySupportTriggerLogicSystem.Tick()`, `IDestructibleTargetStatus`/`DestructibleDoorComponent`의 파괴 알림 유무, 씬에서 NPC의 위치와 길(통로)·돌문의 지오메트리, `INpcCombatActor.MoveTo`/`OnMoveCompleted` 동작을 확인해 보고한다. 기획서와 다르면 임의 판단 말고 "결정 필요"로.
2. **신호**: `IEventSequencer`에 `1단계 시작`, `돌문 파괴` 신호를 추가(기존 신호 시그니처 불변)하고 시퀀서가 확정 시점에 정확히 1회 방송한다. 아군은 이 신호로 사격 시작/중단 — 자체 시작, `Tick()`의 `IsDestroyed` 폴링 제거.
3. **NPC 비켜서기**: `돌문 파괴` 신호를 받으면 NPC가 길을 막던 자리에서 옆으로 비켜선다(`MoveTo`). 목적지(방향·거리)는 이벤트 SO(`PureDataTutorialSequence`)의 조정값, 초기값은 개발이 지오메트리를 보고 정해 근거 보고. 사격 주기(현재 `AllySupportSystemLifetimeScope`의 `attackIntervalSeconds` 3.5)도 이벤트 SO에서 조정되게 하되 기존 값을 유지.
4. **문서**: 06번 기획서의 1단계 트리거/신호 서술, 02번(아군 NPC 지원 사격), 22번 구현 결과를 정정.

### 제외
- 3단계 NPC의 `L` 이동, 사운드, `L`이 벽 밖으로 나가는 문제, 돌문 샷 전용 SO 신설, 돌문 샷의 속도·데미지·부여 마법 값 변경, 평상시 값 이동, `ProjectSettings/DynamicsManager.asset`(md5 `803bedbcc15227e788d4fcc3332d80b4` 불변), 새 `*LifetimeScope.cs` 파일. 방어 로직 과다·커밋 금지.

## 완료 기준 (24번 §5)
- [ ] 씬 시작 시 아군이 `1단계 시작` 신호 이후에만 사격을 시작한다.
- [ ] 돌문 파괴 시 `돌문 파괴`가 1회 방송되고 사격이 멈춘다. 폴링 제거 확인.
- [ ] NPC가 비켜서고 플레이어가 통과 가능(NPC 위치 변화, 플레이어 이동으로 확인).
- [ ] 돌문 샷 동작·3단계 이벤트 회귀 없음. 이벤트 SO 값 변경이 동작에 반영(원복).
- [ ] 컴파일/콘솔 에러 0, 씬 Missing Script 0 · Missing Reference 기존 1건 불증가, md5 불변.

## 검증 절차 (이벤트/반복은 필요한 만큼만)
수정 전 기록 → 구현 → recompile + recompile_status + 어셈블리 mtime 교차 → 콘솔 에러 0. 돌문 파괴는 실제 경로(시간 정지 + 마법 투사체 명중, 불가하면 API로 데미지 부여)로 발생. QA는 개발과 분리해 독립 재측정, 한계(하드웨어 마우스/실제 입력) 명시.
