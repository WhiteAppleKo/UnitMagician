## Goal
`Time.timeScale`/`Time.fixedDeltaTime`을 쓰는 곳을 `TimeSlowVisualizer` 한 곳으로 모으고, 시간정지·이벤트 감속의 요청 배율과 UI들(Option, 인벤토리)의 일시정지 요청을 `RuntimeDataTimeScale`에서 합성해 유효 배율을 정한다. 어떤 순서로 메뉴를 열고 닫아도 정지가 풀리거나 영구 정지되지 않게 한다.

## 범위
### 포함
1. **조사 먼저**: `Time.timeScale`/`fixedDeltaTime`을 읽고 쓰는 곳 전수(`TimeSlowVisualizer`, `OptionUIComponent`(+`CameraOptionUIController` 상속), `UnitInventoryUIComponent`, 그 외), `TimeSlowLogicSystem`(`HandleSlowStateChanged`, `ProcessTimeSlow`의 이벤트 감속 매 프레임 쓰기, 포커스 소모/회복 틱), `ITimeSlowVisualizer`, `CharacterLifetimeScope`의 등록, Option/UnitSystem 스코프의 부모 체인(Option→Locomotion→Character, UnitSystem→Locomotion→Character)을 읽고 기획서 §3과 다른 점이 있으면 구현 전에 보고한다.
2. **데이터/서비스(§3-1, §3-2)**: `RuntimeDataTimeScale`(요청 배율, 요청자 집합(멱등), `IsPaused`/`EffectiveScale`, 변경 이벤트), `ITimeScaleService`/`TimeScaleLogicSystem`을 만들고 `CharacterLifetimeScope`에 Singleton 등록한다(인터페이스로만 노출, 새 LifetimeScope 파일은 만들지 않는다).
3. **쓰기 일원화**: `TimeSlowLogicSystem`이 요청 배율을 `RuntimeDataTimeScale`에 설정하게 바꾸고, 유효 배율이 바뀔 때 `TimeSlowVisualizer`의 배율 적용 메서드(`ITimeSlowVisualizer`에 추가)가 `Time.timeScale`/`fixedDeltaTime`을 쓴다. 기존 `SetTimeSlowEffect`의 부수 효과(`OnSlowStateChanged`, 오디오, VFX)와 `OnDisable` 복원은 유지한다.
4. **UI 전환**: `OptionUIComponent`, `UnitInventoryUIComponent`에서 `s_cachedTimeScale`/`s_pauseRefCount`/`Time.timeScale` 직접 쓰기를 삭제하고 `ITimeScaleService`를 주입받아 열 때 `SetPaused(this, true)`, 닫을 때 `SetPaused(this, false)`만 호출한다. 입력 컨텍스트 Push/Pop은 그대로 둔다.
5. **포커스 게이지**: `IsPaused`인 동안 `ProcessTimeSlow`의 포커스 소모/회복 틱을 건너뛴다.

### 제외 (건드리지 않는다)
- 시간정지/이벤트 감속의 곡선·수치·판정, 입력 컨텍스트 전환 로직, Cinemachine 독립 시간 설정, ESC UX, 인벤토리의 이벤트 중 차단 규칙(그대로 유지), 새 메뉴 추가.

## 완료 기준 (기획서 §5)
- [ ] 코드 전체에서 `Time.timeScale =`/`Time.fixedDeltaTime =` 대입이 `TimeSlowVisualizer`에만 있고 `s_cachedTimeScale`/`s_pauseRefCount`가 없다(grep).
- [ ] 인벤토리→Option→인벤토리 닫기→Option 닫기 순서와 반대 순서, 같은 메뉴 중복 Open 모두에서 중간에 정지가 풀리지 않고 마지막에 정확히 복귀한다(영구 정지 없음). 실제 입력(Esc/`I`)으로 확인을 시도하고 안 되면 API 호출로 확인 후 UNVERIFIED 명시.
- [ ] 수동 시간정지 중 Option 열고 닫기: 0 유지, 시간정지 상태 유지.
- [ ] 3단계 이벤트 감속 중 Option 열기: `timeScale` 0 유지(곡선이 덮어쓰지 않음), 닫으면 곡선 값으로 이어지고 이벤트가 정상 종료·판정된다. 정지 잔존 없음.
- [ ] 일시정지 중 포커스 게이지가 변하지 않는다.
- [ ] 13~16번 회귀(락온 팝업, 큐 1회 발동, 전환점, 풀링, 컨텍스트 스택 Player 복귀), 시간정지 오디오/VFX/`OnSlowStateChanged` 유지, 콘솔 에러 0건.
- [ ] DLV/VContainer 규칙, 기획서 §4 경로 준수. 디스크에 임시 코드 잔존 없음.

## 검증 절차
1. `unity command recompile` → `recompile_status` + 어셈블리 mtime 교차 확인(스테일 DLL 주의). `clear_console` 후 `console --level error` 0건.
2. Play Mode 실측(`Time.frameCount`가 멈추면 `editor_focus`, 안 되면 Game 뷰 포커스 후 `InputSystem.QueueStateEvent`). 정지 상태를 `Time.timeScale`/`Time.frameCount` 변화로 직접 측정한다.
3. `git diff --stat`/`git status`로 범위 확인(이전 세션 미커밋분과 구분).
