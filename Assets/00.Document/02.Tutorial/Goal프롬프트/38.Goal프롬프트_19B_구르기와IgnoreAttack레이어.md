## Goal
Space를 누르면 구르기, Shift+Space는 점프가 되도록 입력을 재배치하고, 지면에서 WASD 방향(없으면 바라보는 방향)으로 구르는 이동 상태를 추가한다. 구르기의 무적 구간 동안 플레이어를 `IgnoreAttack` 레이어로 옮겨 모든 공격 판정체를 통과시키고, 끝나면 그 시점의 진영에 맞는 몸체 레이어로 복원한다.

## 범위
### 포함
1. **조사 먼저**: `InputSystem_Actions.inputactions`(Jump=Space, Sprint=LeftShift 바인딩)와 생성 코드(`Controls`), Synty `InputReader`(`OnJump`/`OnSprint`), `LocomotionLogicSystem`(점프·달리기·접지·상태 구조), `ILocomotionVisualizer`/`LocomotionVisualizer`(`CharacterController` 이동), `CharacterStatComponent`(몸체 레이어 적용, `OnFactionChanged`), `FactionLayers`, 입력 컨텍스트 게이팅(`IInputContextManager`)을 읽고 기획서와 다른 점이 있으면 구현 전에 보고한다.
2. **입력(§3-2)**: Space를 누른 **그 프레임에 Shift 상태로 분기** — Shift 없음 → `onRollPressed`, Shift 누름(달리는 중) → 점프(`onJumpPerformed`). 한 번의 입력으로 둘이 동시에 발동하지 않는 구현 방식은 개발이 선택하고 근거를 보고한다. `.inputactions`와 생성 코드를 일관되게 갱신한다.
3. **구르기 상태(§3-2)**: 시작 조건 = 지면 접촉(공중 불가) + 구르기 중 아님 + 입력 컨텍스트 `Player`(Tactical/UI/Event/시간정지 중 불가) + `TryUseStamina(rollStaminaCost)` 성공(소모는 시작 시 1회, 부족하면 시작 안 함·소모 없음). 방향 = Space를 누른 시점의 WASD를 카메라 기준 월드 방향으로 변환, **입력이 없으면 캐릭터가 현재 바라보는 수평 방향**. `rollDuration` 동안 `CharacterController`로 `rollDistance`만큼 이동(기본 등속), 구르기 중 다른 이동/점프/달리기 입력 차단, 종료 시 `IsRolling=false`. 수치는 `PureDataLocomotion`(`rollStaminaCost`/`rollDistance`/`rollDuration`/`rollInvincibleStart`/`rollInvincibleEnd`)에서 읽는다 — 코드에 숫자를 박지 않는다. 애니메이션 연결은 하지 않는다(클립 확보 후).
4. **`IgnoreAttack` 레이어(§3, 16번 §6-3)**: `TagManager`에 `IgnoreAttack`(첫 빈 번호, 14번 예상)을 정의하고 `FactionLayers`에서 충돌 매트릭스 `IgnoreAttack↔AttackAlly`/`AttackEnemy`/`AttackNeutral`을 추가로 끈다(이 3쌍 외 변경 없음 — 벽·지면·몸체끼리 충돌 유지). 무적 구간(`rollInvincibleStart`~`rollInvincibleEnd`)에 플레이어 루트+모든 자식 콜라이더를 `IgnoreAttack`으로 옮기고(`ILocomotionVisualizer.SetAttackIgnored(bool)` → `CharacterStatComponent`의 몸체 레이어 오버라이드 경유), 구간이 끝나면 **저장해 둔 레이어가 아니라 그 시점의 `CurrentFaction`에 맞는 몸체 레이어**로 복원한다. 오버라이드 중에는 `OnFactionChanged` 반응이 몸체 레이어를 덮어쓰지 않아야 하고, 구르기가 중단되는 모든 경로(피격 경직, 사망, 컴포넌트 비활성/파괴)에서 복원이 보장되어야 한다.
5. **겹침 위험 실측**: 공격 판정체가 플레이어와 겹친 채 무적 구간이 끝날 때(충돌 재개) 접촉 이벤트가 새로 발생하는지 실측해 보고한다. 문제가 되면 가장 단순한 유예 방식을 제안만 하고 **임의로 추가하지 않는다**(사용자 확인).

### 제외 (건드리지 않는다)
- 구르기 애니메이션 클립/Animator 연결, 플레이어 공격 구현, 락온 전용 8방향 구르기 규칙, 구르기 후 콤보, 비충돌 피해원 무적, 지면 판정 로직/마스크 변경, `IsInvincible` 변경.

## 완료 기준 (기획서 §5)
- [ ] Space(Shift 없음)로 지면에서 입력 방향으로 구르고 스태미나가 `rollStaminaCost`만큼 줄어든다. WASD 없이 Space만 누르면 현재 바라보는 방향으로 구른다. 공중에서는 시작되지 않는다. 스태미나 부족 시 시작되지 않고 스태미나가 변하지 않는다.
- [ ] Shift+Space(달리는 중)는 구르기가 아니라 점프이며, Space 한 번에 구르기와 점프가 동시에 일어나지 않는다. 입력 컨텍스트가 Tactical/UI/Event이거나 시간정지 중이면 구르기가 시작되지 않는다.
- [ ] 무적 구간 동안 플레이어 루트와 모든 자식 콜라이더(CharacterController 포함)가 `IgnoreAttack` 레이어에 있고, 그 사이 보스 투사체가 플레이어를 통과해 HP가 줄지 않으며 투사체는 소비되지 않고 지나간다(반복 10회 이상). 구간이 끝나면 `CurrentFaction`에 맞는 몸체 레이어로 돌아와 다시 맞는다. 구르기를 중단시키는 경로(경직 대용 호출, 사망, 비활성)에서도 레이어가 복원된다. 구르기 중 `CurrentFaction`을 바꿔도 종료 후 바뀐 진영의 몸체 레이어로 복원된다(검증 후 복원).
- [ ] 충돌 매트릭스 전수 열거에서 `IgnoreAttack` 관련 꺼진 쌍이 정확히 3개이고, 기존 3개(Goal 35의 쌍)가 유지된다. 몸체끼리·`Default`(벽/지면/돌문)와의 충돌은 구르기 중에도 유지된다.
- [ ] 겹침 위험 실측 결과가 보고된다(접촉 이벤트 발생 여부).
- [ ] 지면 판정(서기/점프/낙하/경사/앉기) 회귀 없음, 달리기 스태미나(Goal 37) 동작 유지, 13~18 회귀, 콘솔 에러 0건, 디스크에 임시 코드/값 잔존 없음. `DynamicsManager.asset` 디스크 불변.

## 검증 절차
1. `unity command recompile` → `recompile_status` + 어셈블리 mtime 교차 확인(스테일 DLL 주의). `clear_console` 후 `console --level error` 0건.
2. Play Mode 실측. 입력은 Game 뷰 포커스 후 `InputSystem.QueueStateEvent`(Space, Shift+Space, WASD)로 주입한다. 보스 투사체를 구르기 중 플레이어에게 쏘게 해 통과를 확인한다. 안 되는 항목은 UNVERIFIED로 명시.
3. `git diff --stat`/`git status`로 범위 확인(이전 세션 미커밋분과 구분, `TagManager` 변경이 `IgnoreAttack` 정의뿐인지 확인).
