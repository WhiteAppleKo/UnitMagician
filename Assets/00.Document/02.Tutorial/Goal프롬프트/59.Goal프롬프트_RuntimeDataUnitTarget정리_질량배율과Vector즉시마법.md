## Goal
32번 기획서대로 다음을 구현한다.
- `CurrentMass`를 스케일 배율로 바꾼다(초기 1, Mass 배율 합산).
- Mass 마법은 `프리팹 기본 Scale × CurrentMass`가 되고, Rigidbody 질량도 같은 배율로 바뀐다.
- 정리 대상: `MassRatio`, `baseMass`·`baseVectorSpeed`, `UnitMassBaker`, 세제곱근 변환, Vector 상태, `GetApplied`
- Vector는 적용 목록에 남지 않는 즉시 마법(`IsInstant`, `ApplyInstant`)으로 만든다.
- 기즈모 UI를 전부 삭제한다.

## 사용자 확정 (32번 머리말)
- Mass 마법 = 프리팹 기본 Scale × `CurrentMass`(스케일 배율). `MassRatio`는 필요 없다.
- setter(`SetMass`·`SetTemperature`)는 유지한다. 마법 전용 대상 데이터와 대상 자신의 데이터는 분리한다.
- Vector는 한 번 적용하면 되돌릴 필요가 없으므로 목록에 남기지 않는다.
- 기즈모 관련 내용은 일단 전부 지운다.
