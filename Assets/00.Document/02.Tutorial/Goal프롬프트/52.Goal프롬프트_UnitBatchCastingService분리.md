## Goal
`UnitBatchCastingService.cs`의 값 변환·마나 비용 규칙을 대상과 시전 방식에 무관한 `IUnitCastRuleService`/`UnitCastRuleService`로 분리하고, `UnitBatchCastingService`는 시간 정지 락온 큐 일괄 시전만 맡게 한다. **동작은 분리 전과 완전히 같아야 한다.**

## 범위
### 포함
1. **조사 먼저**: `IUnitBatchCastingService` 모든 멤버의 호출자(비-레거시/레거시)와 호출되는 오버로드를 확인한다(특히 목록 기반 `ExecuteBatchCast(targets…)` 3종과 `CalculateTotalCost(targets…)`가 실제로 호출되는지, `UnitCasterSystem.CalculateNewValueForUnit`가 쓰이는지). 기획서와 다르면 임의 판단하지 말고 "결정 필요"로 보고.
2. **분리**: 26번 §3대로 `UnitCastRuleService`(규칙 본문을 그대로 이동, 의존성 없음)를 만들고 `UnitBatchCastingService`는 큐 전용으로 정리(규칙은 위임). 규칙 중복 금지.
3. **호출자 정리**: 규칙만 쓰는 비-레거시 호출자는 `IUnitCastRuleService`를 주입받아 쓰고, 큐 호출은 `IUnitBatchCastingService` 유지. 레거시(`99.Legacy`) 호출자는 컴파일 유지에 필요한 **최소 수정만**(동작 불변).
4. **등록**: `UnitSystemLifetimeScope`에 `UnitCastRuleService` 싱글턴 등록(`IUnitCastRuleService`). 새 `*LifetimeScope.cs` 금지.
5. **문서**: 26번 기획서에 구현 결과를 추가하고, 21번 기획서 §8/42번 Goal의 파일 목록을 분리 결과(파일 수 18→19, `UnitCastRuleService`는 `00.Common`, `UnitBatchCastingService`는 `02.TimeStop`)로 갱신.

### 제외
- 퀵슬롯 무기 적용 시전, 폴더 이동(Goal 42), 레거시 오버로드·레거시 파일 삭제, 규칙(변환·비용) 자체 변경, 로그 메시지의 불필요한 변경, `ProjectSettings/DynamicsManager.asset`(md5 `803bedbcc15227e788d4fcc3332d80b4` 불변). 설정 실수 방어 로직 추가 금지. 커밋·`git add` 금지.

## 완료 기준 (26번 §5)
- [ ] 규칙이 `UnitCastRuleService` 한 곳에만 있고 큐 일괄 시전은 그 서비스에 위임한다.
- [ ] 분리 전/후로 같은 입력의 결과가 같다: 시간 정지 → 락온 → 팝업 → 지정(예: 얼음+질량) → 해제 → 큐 1회 시전의 대상 값 변화와 마나 차감 합계(MP 변화)가 일치. 마나 예상 비용 HUD와 변화 미리보기 수치가 일치(전/후 같은 조합 비교).
- [ ] 3단계 보스 이벤트 1회(성공) 회귀 없음.
- [ ] 컴파일 에러 0(DLL mtime 교차, 레거시 컴파일 유지), 콘솔 에러 0, 씬 Missing Script 0 · Missing Reference 기존 1건 불증가, md5 불변, 신규 `Find*`/LifetimeScope 없음.

1. 수정 전: 대표 조합(얼음+질량 등)의 변환 결과·마나 차감·예상 비용·미리보기 값을 기록 → 분리 → recompile + recompile_status + 어셈블리 mtime 교차 → 동일 조합으로 재측정해 비교.
2. 실제 입력 주입(T → 호버 → 클릭 → 팝업 → W/E → T)으로 시전하고, 불가하면 사유를 명시. 보스 이벤트는 HP를 API로 내려 실제 경로로 1회.
