## Goal
`Assets/02.System/01.UnitSystem/01.Logic`의 **19개 파일**을 UnitSystem의 두 가지 마법 사용 방식(퀵슬롯 / 시간 정지)과 공용 기반에 따라 하위 폴더 3개(`00.Common`, `01.QuickSlot`, `02.TimeStop`)로 에디터 에셋 이동(GUID 유지)해, 퀵슬롯과 시간 정지 마법 사용이 폴더로 구분되게 한다.

## 사용자 확정 기준
- 마법 사용 방식은 두 가지: **퀵슬롯**(손에 든 무기에 시간 정지 없이 빠르게 적용) / **시간 정지 상태에서 쓰는 마법**(락온 큐 일괄 시전). 결정적 차이는 **무엇이 대상이 되는가**(무기 / 락온 대상)이고, 마법 적용 기반은 공용. `Casting`/`Caster` 같은 비슷한 이름의 폴더를 따로 두지 않는다.

## 범위
### 포함
1. **조사 먼저**: `01.Logic`의 현재 파일 목록(19개, `Strategy/` 폴더 없음 — Goal 52로 `UnitCastRuleService` 추가)이 기획서 §8 표와 일치하는지 확인하고, 이동 직전 파일별 GUID·경로를 scratchpad에 기록한다. 기획서와 다른 점(새 파일 등)이 있으면 임의로 분류하지 말고 보고하며, 표에 없는 파일은 이동하지 않는다.
2. **이동(21번 §8 표)**: 에디터 API(`AssetDatabase.CreateFolder`, `AssetDatabase.MoveAsset`)로만 이동한다(파일 시스템 `mv`로 `.meta`를 따로 옮기지 않는다).
