## Goal
`Assets/02.System/01.UnitSystem/01.Logic`의 20개 파일을 기능별 하위 폴더 5개(`00.Catalog`, `01.QuickSlot`, `02.TimeStopCasting`, `03.Casting`, `04.CasterStrategy`)로 에디터 에셋 이동(GUID 유지)해, 퀵슬롯과 시간정지 마법 사용 등 기능이 폴더로 구분되게 한다.

## 범위
### 포함
1. **조사 먼저**: `01.Logic`의 현재 파일 목록(20개)이 기획서 §3 표와 일치하는지 확인하고, 이동 직전 파일별 GUID·경로를 scratchpad에 기록한다. 기획서와 다른 점(새 파일 등)이 있으면 임의로 분류하지 말고 보고하고, 표에 없는 파일은 이동하지 않는다.
2. **이동(§3 표)**: 에디터 API(`AssetDatabase.CreateFolder`, `AssetDatabase.MoveAsset`)로만 이동한다(파일 시스템 `mv`로 `.meta`를 따로 옮기지 않는다). `Strategy/` 안의 2개는 `04.CasterStrategy/`로 옮기고, 비는 `Strategy/` 폴더는 폴더와 `.meta`째 제거한다(다른 파일이 남아 있으면 지우지 말고 보고).
3. **문서**: 변경 후 구조를 `Assets/00.Document/98.System/04.UnitSystem.md`(UnitSystem 시스템 분석 문서)가 폴더 구조를 서술하고 있다면 해당 서술만 갱신한다(없으면 생략하고 보고).

### 제외 (건드리지 않는다)
- 코드 내용·클래스명·네임스페이스·using 변경, 파일 이름 변경, `00.Data`/`02.Visualizer`/`03.UI`/다른 기능 폴더, 기능 로직 변경, 씬/프리팹 저장(이동만으로 참조는 유지됨 — 씬이 dirty해지면 저장하지 말고 보고).
