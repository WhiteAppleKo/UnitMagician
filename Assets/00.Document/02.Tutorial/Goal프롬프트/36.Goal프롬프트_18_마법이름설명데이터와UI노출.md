## Goal
`PureDataUnit`에 설명 데이터를 추가하고, 인벤토리에는 이름과 설명을, 습득 팝업에는 이름과 아이콘만, 시간정지 선택 팝업에는 이름만(설명 없이) 보이게 한다. 온도 유닛 이름의 따옴표를 정리한다.

## 범위
### 포함
1. **조사 먼저**: `UnitInventoryUIComponent`(`BuildUnitElement`, `RefreshInventory`, 클릭/우클릭/배지/장착 테두리, 이벤트 중 차단·모달·`timeScale` 처리 방식), 인벤토리 UXML/스타일, `UnitUnlockPopupUIComponent`, `MagicSelectionPopupUIComponent`(W/E/F 라벨, Q 목록 항목), `PureDataUnit`/`PureDataUnitEditor`, `PureDataUnit_*.asset`의 `unitName` 값을 읽고 기획서와 다른 점이 있으면 구현 전에 보고한다.
2. **데이터**: `PureDataUnit.description`(`string`, `[TextArea]`, 기본 빈 문자열) + `Description` 프로퍼티, `PureDataUnitEditor`에 필드 노출. 에셋 `PureDataUnit_Temperature.asset`의 `unitName` `'"Frost"'` → `Frost`(따옴표 제거). **설명 문구는 에셋에 넣지 않는다**(사용자가 작성; 검증에는 메모리상/임시 값만 쓰고 디스크에 남기지 않는다).
3. **인벤토리(A안)**: 목록을 행 형태로 바꿔 각 행에 아이콘(48px) + 이름 + 설명(최대 2줄 말줄임) + 장착 상태를 표시한다. 기존 동작은 유지한다 — 아이콘 클릭=장착/해제, 우클릭=즐겨찾기 등록(W→E→F 순환·교체 정책), 즐겨찾기 배지(`[W]` 등), 장착 테두리 강조, 장착 불가 표시, 이벤트 중 열기 차단. 행에 마우스를 올리면(호버) 모달 우측 상세 패널에 이름 + 아이콘 + 전체 설명을 표시한다. 설명이 비어 있으면 설명 요소/상세 설명 영역을 만들지 않는다.
4. **습득 팝업/시간정지 선택 팝업**: 설명이 노출되지 않는지 확인만 한다(현행 유지; 필요한 경우가 아니면 코드 변경 없음).

### 제외 (건드리지 않는다)
- 다국어, 리치 텍스트, 마법 수치 UI 표시, 습득 팝업 연출, 인벤토리의 기능 변경(장착 규칙·요구 스탯 게이팅·키), `timeScale` 처리(Goal 34), 설명 문구 작성.

## 완료 기준 (기획서 §5)
- [ ] `PureDataUnit` 인스펙터에 설명 입력란(여러 줄)이 나타나고 값이 직렬화된다. 온도 마법 이름이 따옴표 없이 `Frost`다.
- [ ] 임시로 설명을 넣은 마법은 인벤토리 행에 이름+설명(2줄 말줄임)이 보이고 호버 시 상세 패널에 전체 설명이 보인다. 설명이 빈 마법은 설명 영역 없이 기존과 같은 모습이다.
- [ ] 클릭 장착/해제, 우클릭 즐겨찾기 등록·배지, 장착 테두리, 장착 불가 표시, 이벤트 중 인벤토리 차단이 변경 전과 똑같이 동작한다(실제 입력 주입으로 확인을 시도하고 안 되면 UNVERIFIED 명시).
- [ ] 습득 팝업에는 이름과 아이콘만, 시간정지 선택 팝업(W/E/F, Q 목록)에는 설명이 보이지 않는다.
- [ ] 13~19 회귀(락온마다 팝업, 큐 1회 발동, 인벤토리 모달 열림/닫힘), 콘솔 에러 0건, 디스크에 테스트용 설명 문구/임시 코드가 남지 않는다.

## 검증 절차
1. `unity command recompile` → `recompile_status` + 어셈블리 mtime 교차 확인(스테일 DLL 주의). `clear_console` 후 `console --level error` 0건.
2. Play Mode 실측. UI 상태는 `eval`로 `VisualElement` 트리를 열거해 확인한다(행 구성, 상세 패널 표시). 호버/클릭은 Game 뷰 포커스 후 `InputSystem.QueueStateEvent`로 시도하고 안 되면 UNVERIFIED로 명시.
3. `git diff --stat`/`git status`로 범위 확인(이전 세션 미커밋분과 구분, 에셋 변경이 `unitName` 한 줄뿐인지 확인).
