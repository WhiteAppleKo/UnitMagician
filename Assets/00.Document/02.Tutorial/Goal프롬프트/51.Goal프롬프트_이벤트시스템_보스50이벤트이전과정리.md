## Goal
보스 체력 50% 이벤트(플레이어의 카메라 + 시간 정지를 강제하는 **강 이벤트**)를 `PureDataEvent` 에셋으로 정의해 범용 이벤트 시스템(Goal 50)에서 동작시키고, 하드코딩된 `Tutorial*` 시퀀서와 고정 신호 5개를 대체하며, 이벤트 연출에 쓰이는 수치 전부를 이벤트 SO에서 조정하게 한다.

## 사용자 확정 (25번 §1-1·§7, 22번 §11)
- 이벤트 흐름: 보스 HP 50% → 발사 지점 설정(보스–플레이어 직선 기준 플레이어 우측 약 120°, 시야각 밖, 각도·거리는 이벤트 SO) → **특수 NPC를 발사 지점으로 순간이동**(돌문 이벤트의 일반 `BlockerNPC`와 다른 NPC) → 투사체 발사 사운드(사운드 시스템은 범위 밖)와 함께 시퀀서의 시간 개입(감속)이 시작되고 1인칭 이벤트 카메라가 천천히 투사체를 따라 돈다(시선=카메라→투사체) → 플레이어가 락온·마법 지정 → 스치는 순간 `timeScale` 최저(투사체 속도는 곧 판단 시간) → 성공/실패. 실패하면 보스 HP 회복, **아군 즉시 재발사 없음**, 50%에 다시 도달해야 이벤트가 재시작(`rearmOnFail=true`).
- 이벤트 투사체의 속도·데미지는 이벤트 SO가 정한다(아군 NPC 자체의 값은 이 이벤트에서 의미 없음, 돌문 샷·보스 샷 값은 변경 없음).
- **모든 이벤트 값은 이벤트 SO에서 조정**. 선행 조건: 보스 이벤트는 돌문 이벤트 완료 후 활성(`requiresCompleted`).

## 범위
### 포함
1. **조사 먼저**: 이벤트 연출 수치의 현재 위치·값 전수 조사 — `PureDataTutorialSequence`(HP 임계값, 발사 각도·거리, 요구 데미지 등), `PureDataTimeSlow`/`IEventTimeSlowSettings`(최저 timeScale·곡선), `PureDataCameraSetting`/`IEventCameraSettings`(블렌드·FOV·눈 높이), `PureDataBossPattern`(`reviveHpRatioOnFail` 0.6, `healPerSecond`, 무적 페이즈 타임아웃, `BossPhaseLogicSystem.InvulnerableHealingHpThresholdRatio` 상수), `ProjectileAttackBehavior_Dummy`·`PureDataNpcActor_*`의 투사체 속도(12)/데미지(60, 보스 10; 공유 에셋이므로 **이벤트 샷 값만 이벤트 SO로** 분리, 돌문 샷·보스 샷 값은 변경 금지), 카메라 블렌드 곡선(EaseInOut 하드코딩), `EventFlightTrackerComponent.playerAnchorOffset`. 목록과 현재 값을 보고한다.
2. **동작 SO + 핸들러**: `EventProjectileLaunchAction`(각도·거리·속도·데미지, 기존 `EventFlightLogicSystem`·`IEventFlightTracker` 재사용), `NpcTeleportAction`(`INpcCombatActor`에 `TeleportTo` 추가), `TimeSlowOverrideAction`(최저 timeScale·접근/이탈 곡선), `CameraOverrideAction`(블렌드 시간·곡선·FOV·눈 높이·추적 높이 오프셋), `InputLockAction`, `BossRecoverAction`(회복 비율·속도·타임아웃), `BossInvulnerableAction`. 핸들러는 소유 시스템의 `01.Logic`(카메라 `00.Movement/01.Logic/01.CameraMovement`, 감속 `02.CharacterSystem/01.Logic`, NPC `07.NpcSystem/01.Logic`, 보스 `11.BossPhaseSystem/01.Logic`)에 둔다.
3. **완료 판정**: `CoreHitCompletion`(필요 데미지, 속성 게이트·크기 게이트 요구) — 현재 `TutorialSequencerLogicSystem.HandleDamageProcessed`의 판정과 투사체 소실 안전망을 일반화. 판정 대상은 **이벤트 투사체**로 한정(기존 규칙 유지).
4. **보스 50% 이벤트 에셋**: trigger=`BossHpRatioTrigger`(비율은 이벤트 SO, **보스 페이즈 임계값 상수를 이 값으로 단일화**), requiresCompleted=[돌문 이벤트], onStart/onSuccess/onFail은 25번 §3-3대로, `rearmOnFail=true`.
5. **대체/정리**: `TutorialSequencerLogicSystem`·`TutorialStage`·`RuntimeDataTutorialSequence`·`PureDataTutorialSequence`와 고정 신호(`OnBoss50Percent`, `OnCoreHitSuccess/Fail`, `OnEventFlightChanged`, `OnEventFlightTurnaround`) 구독을 이벤트 시스템의 범용 신호/핸들러로 전환하고, 기존 구독자(`EventCameraTriggerLogicSystem`, `TimeSlowLogicSystem`, `AllySupportTriggerLogicSystem`, `BossPhaseLogicSystem`, `EventCastTriggerLogicSystem`)를 맞춰 고친다. 대체가 끝난 `Tutorial*` 클래스는 `99.Legacy`로 이동(GUID 유지). `AllySupportTriggerLogicSystem`의 `HandleBoss50Percent`와 실패 시 즉시 재발사는 제거되어 있어야 한다. 기존 에셋 값은 유실 없이 옮기고 이전/이후 값을 비교해 보고(`FormerlySerializedAs` 등).
6. **문서**: 06·02·03·09·13번, 22번 구현 결과, 25번 §6 이행 결과를 정정.

### 제외
- 사운드, `L`이 벽 밖으로 나가는 문제의 해결, 각도·거리 안전 범위 제한, 카메라 블렌드 시간의 "천천히" 값 결정(사용자 결정 대기, 현재 0.5초 유지), 돌문 이벤트 변경, 평상시 값 이동, 감속 곡선 형태·마법 발동 로직의 동작 변경, `ProjectSettings/DynamicsManager.asset`(md5 `803bedbcc15227e788d4fcc3332d80b4` 불변), 새 `*LifetimeScope.cs` 파일. 방어 로직 과다·커밋·`git add` 금지.
- 기획서에 없는 판단은 임의로 정하지 말고 최종 보고에 "결정 필요"로.

## 완료 기준 (25번 §5의 3·4·5번)
- [ ] 보스 이벤트가 `PureDataEvent` 에셋으로 동작: 돌문 이벤트 완료 후 보스 HP가 SO 비율 이하가 되면 시작, 발사 지점 L이 `P→B` 수평 기준 시계 방향 SO 각도(120)·SO 거리, 특수 NPC가 L로 순간이동해 발사, 투사체 속도/데미지는 이벤트 SO 값, 감속·최저 timeScale·1인칭 이벤트 카메라 추적(오차 <0.1°)·락온·마법 지정·전환점 발동이 이전과 동일하게 동작(회귀 없음).
- [ ] 성공: 이벤트 완료(성공) 1회, 이벤트 투사체 총 1발. 실패(마법 미지정): 보스 HP 이벤트 SO 비율로 회복, **아군 추가 발사 0건**, 일정 시간(≥10초) 이벤트 재시작 없음, HP를 다시 임계값 아래로 내리면 이벤트 정확히 1회 재시작.
- [ ] **임계값 단일 원천**: 이벤트 SO의 HP 비율을 0.7로 바꾸면 이벤트 시작과 보스의 무적·회복 페이즈 진입이 같은 70% 근처에서 일어난다(원복 후 0.5 정상).
- [ ] 이벤트 연출 수치(HP 비율, 발사 각도·거리, 이벤트 투사체 속도·데미지, 최저 timeScale·곡선, 카메라 블렌드·곡선·FOV·눈 높이, 보스 회복 비율·속도·타임아웃, 추적 높이 오프셋)가 이벤트 SO 한 곳에서 조정되고 각각 값을 바꾸면 실제 동작이 바뀐다(대표 값 실측 후 원복, 디스크 에셋 값 불변). 코드에 이벤트 수치 하드코딩이 없다. 기존 값 유실 없음(이전/이후 비교표).
- [ ] 돌문 샷·보스 일반 공격의 속도·데미지·동작 변경 없음. 돌문 이벤트 회귀 없음.
- [ ] `Tutorial*` 시퀀서·고정 신호 대체 완료 및 `99.Legacy` 이동(GUID 유지). 컴파일 에러 0(DLL mtime 교차), 콘솔 에러 0(Animator `Hash 468800000` 기존 경고 제외), 씬 Missing Script 0 · Missing Reference 기존 1건 불증가, md5 불변.

## 검증 절차 (테스트 이벤트는 케이스당 1회)
케이스: ① 성공(마법 지정) ② 실패(마법 미지정) → 회복·추가 발사 0·재시작 없음 확인 ③ 실패 후 HP를 다시 임계값 아래로 내려 재시작 1회 ④ 시작 시선 3가지(보스 방향/반대/옆)에서 L 각도·카메라 회전량·시선 스냅(°/프레임) ⑤ 이벤트 SO 값 변경(HP 비율, 각도, 블렌드 시간, 최저 timeScale, 이벤트 투사체 속도, 회복 비율) 반영 확인 후 원복. 이벤트는 보스 HP를 API로 내려 실제 경로로 발생(시퀀서 이벤트 억지 발화 금지), 돌문 이벤트는 완료 상태로 둔다. 스크린샷은 scratchpad 절대경로. QA는 개발과 분리해 독립 재측정하고 한계(하드웨어 마우스/Locked 커서 락온, 실제 공격으로 HP를 내리는 흐름 미검증)를 명시한다.
