## Goal
`Neutral` 진영 NPC가 일정 시간 안에 정해진 횟수만큼 연속으로 공격받으면 `CurrentFaction`이 `Enemy`로 바뀌게 하는 트리거 규칙을 추가한다. 이후의 몸체 레이어 이동과 충돌 규칙 변화는 16번에서 만든 경로가 자동으로 처리한다.

## 범위
### 포함
1. **조사 먼저**: `IInteractionService.OnDamageProcessed` 발행 위치와 `DamageContext`(`Attacker`/`Victim`/`HitRegistered`), `IFactionProvider`/`IFactionSettable`(33번 결과), `RuntimeStatData.CurrentFaction`/`OnFactionChanged`, `CharacterStatComponent`의 provider 구현, `InteractionSystemLifetimeScope`의 등록 방식, 씬의 중립 NPC 유무(없음 예상)를 읽고 기획서와 다른 점이 있으면 구현 전에 보고한다.
2. **데이터(§3-1)**: `PureStatData`에 `hostileHitThreshold`(int, 기본 3, 0 이하면 적대화 안 함)/`hostileHitWindowSeconds`(float, 기본 10), `IHostilityRule`(`Assets/PipeLine/Combat/`, 신규)과 `CharacterStatComponent` 구현, `RuntimeDataHostility`(`03.InteractionSystem/00.Data/`, 피격자별 `HitCount`/`LastHitTime`, 피격자 파괴/소멸 시 정리).
3. **로직(§3-2)**: `NeutralHostilityLogicSystem`(`03.InteractionSystem/01.Logic/`, 순수 C#)이 `OnDamageProcessed`를 구독 — 피격자 진영이 `Neutral`이고 발사자 진영이 `Neutral`이 아닌 실제 피격(`HitRegistered`)만 카운트, 유효 시간 이내면 `HitCount++` 아니면 1로 재시작, 임계 도달 시 `IFactionSettable.SetFaction(Enemy)` 후 카운터 제거. `CharacterStatComponent`가 `IFactionSettable`(`RuntimeStatData.CurrentFaction` 설정)을 구현한다. `InteractionSystemLifetimeScope`에 등록한다(구독 해제 포함 Dispose).

### 제외 (건드리지 않는다)
- 적대화 연출/경고 UI, 적대화된 NPC의 AI 행동, 적대화 해제, 중립 NPC 배치/상인 기능, 기존 아군/적/플레이어 동작 변경.

## 완료 기준 (기획서 §5)
- [ ] 런타임에 `Neutral`로 바꾼 NPC(씬에 중립 NPC가 없으므로 아군 NPC의 진영을 검증용으로 변경)를 플레이어편 공격으로 유효 시간 이내 3번 맞히면 `CurrentFaction`이 `Enemy`로 바뀌고 몸체 레이어가 `BodyNeutral`→`BodyEnemy`로 이동하며 `OnFactionChanged`가 1회 발행된다.
- [ ] 2번 맞은 뒤 유효 시간이 지나 다시 맞으면 카운트가 1부터 다시 시작해 `Neutral`을 유지한다.
- [ ] `hostileHitThreshold`/`hostileHitWindowSeconds`를 PureStatData에서 바꾸면(예: 1) 코드 수정 없이 반영된다. 0 이하이면 적대화되지 않는다. 코드에 임계값/시간 숫자가 없다(grep).
- [ ] `Neutral`이 아닌 피격자와 `Neutral` 발사자의 피격은 카운트되지 않는다. 피격자 파괴/비활성화 후 카운터 누수가 없고, 풀링 재사용 투사체가 이전 피격 기록에 영향을 주지 않는다.
- [ ] 13~20 회귀(락온, 3단계 판정, 풀링, 컨텍스트 스택), 콘솔 에러 0건. 검증용으로 바꾼 진영/수치는 원복하고 디스크에 남기지 않는다.
