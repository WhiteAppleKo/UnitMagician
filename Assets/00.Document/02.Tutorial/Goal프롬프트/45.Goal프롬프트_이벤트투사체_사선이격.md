# Goal 45: 이벤트 투사체 비행 경로 — 플레이어가 사선에 놓이지 않도록 이격 (44번보다 먼저 진행)

> 작성일: 2026-10-13

## 현재 상태 (코드 확인)
- `EventFlightLogicSystem.cs:72`: `L = P − axis × EventLaunchDistance`, axis = normalize(`B − P`) → `L`, `P`, `B`가 **한 직선**이고 플레이어가 사선 위에 있다.
- 접근/이탈 판정은 `s = dot(X − P, axis)`(음→양 = 전환점), 접근 구간 `t = dot(X − L, axis) / approachLength`(`EventFlightLogicSystem.cs:149`).

## Goal
발사 지점 `L`에 **플레이어 사선에서 옆으로 이격하는 값**을 추가해, 투사체 경로(`L`→`B`)가 플레이어에게서 충분히 떨어져 지나가게 한다. 전환점(= 시간 속도가 최저인 순간)은 **투사체가 플레이어에게 가장 가까워지는 순간**이 되도록 판정 기준을 맞춘다.

## 범위
### 포함
1. **조사 먼저**: `EventFlightLogicSystem`의 `L` 결정·접근/전환점/이탈 판정, `EventFlightTrackerComponent.BeginFlight`(NPC 이동/발사 예약), NPC가 투사체를 어느 방향으로 쏘는지(보스를 조준하는지, `L`→`B` 직선 비행인지), 투사체가 플레이어와 충돌하는지(`ignorePlayerCollision` 등)를 확인해 보고한다. 기획서와 다른 점이 있으면 임의 판단 말고 보고한다.
2. **이격 값**: `PureDataTutorialSequence`에 이격 거리(부호가 좌우, 조정 가능)를 추가한다. 코드에 하드코딩 금지. 초기값은 개발이 정하되 근거와 함께 보고하고, 사용자가 인스펙터에서 조정한다. `L = P − axis × EventLaunchDistance + (수평 수직 방향) × 이격 거리`로 하고 `L`→`B` 직선이 플레이어에서 이격되게 한다.
3. **판정 정합**: 비행 방향이 `normalize(B − L)`이 되므로, 접근/이탈 판정과 곡선 `t`가 이 방향 기준으로 동작해 (a) 전환점이 투사체-플레이어 최근접 순간과 일치하고 (b) 접근 구간에서 `timeScale`이 단조 하강, 이탈 구간에서 1.0까지 상승하는 13번 요구가 유지되게 한다. 방식은 개발이 13번을 근거로 정하고 보고한다(기획서 §3 "축 전제"와 어긋나는 부분 명시).
4. **문서**: 13번 기획서의 해당 서술(`L,P,B 한 직선`, 축 전제, 발사 지점 정의, 체크리스트)을 이 정정에 맞게 고친다.

### 제외
- 카메라(44번), 감속 곡선 형태·마법 발동·판정 로직의 다른 부분, NPC 이동/발사 구현의 기존 동작(경로만 바뀌며 동작 방식은 그대로), 투사체 풀링, `ProjectSettings/DynamicsManager.asset`.

## 완료 기준
- [ ] 이벤트 중 투사체 경로의 플레이어까지 최소 거리가 이격 값 이상이다(프레임 단위 수치 로그, 실제 3단계 경로). 투사체가 플레이어에게 맞지 않는다.
- [ ] 전환점 프레임에서 투사체-플레이어 거리가 구간 내 최소이고, 그때 `timeScale`이 최저(`EventSlowMinTimeScale`)다. 접근 구간 `timeScale` 단조 하강, 이탈 구간 1.0까지 상승, 전환점에서 마법 발동이 정확히 한 번(마나 소모 0, 이중 발동 없음).
- [ ] 이격 값의 부호를 반대로 해도(좌↔우) 위 조건이 성립한다. 이격 값이 SO에서 조정된다.
- [ ] NPC가 새 `L`로 이동해 쏘고, 성공/실패 두 판정 경로 모두 정상(보스 명중), 이벤트 3회 반복 회귀 없음.
- [ ] 컴파일 에러 0, Missing Script 0, 콘솔 에러 0(Animator `Hash 468800000` 기존 경고 제외), `DynamicsManager.asset` md5 `803bedbcc15227e788d4fcc3332d80b4` 불변.

## 검증 절차
1. 수정 전 상태 기록 → 구현 → `unity command recompile` + `recompile_status` + 어셈블리 mtime 교차 → 콘솔 에러 0.
2. 실제 3단계 경로(보스 HP 50%)로 이벤트를 발생시키고, 투사체·플레이어·`timeScale`·`EventFlightPhase`를 프레임 단위로 로깅한다. 시퀀서 이벤트를 억지로 호출하지 않는다. 스크린샷은 scratchpad 절대경로.
3. QA 에이전트는 개발 에이전트와 분리하고 위 수치를 독립 재측정한다.
