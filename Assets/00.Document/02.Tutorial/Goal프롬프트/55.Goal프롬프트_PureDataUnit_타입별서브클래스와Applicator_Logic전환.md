## Goal
28번 기획서대로 다음을 구현한다.
- `PureDataUnit`을 공통 메타데이터만 가진 abstract SO로 바꾸고 타입별 서브클래스(Mass·Temperature, 보존용 Volume·Vector)로 나눈다. 연출 에셋은 서브클래스로 옮긴다.
- Applicator를 `01.Logic/00.Common`의 상태 없는 순수 C# 클래스(타입당 하나, `UnitApplicator<TData>`)로 바꾸고, 호출은 이벤트 경로 하나(Logic → `IUnitTargetVisualizer`)로 합친다.
- BaseDamage를 쓰는 모든 런타임 주체(충돌 데미지 오브젝트, NPC 전투 주체)의 데미지를 공용 `RuntimeDataAttackDamage`(BaseDamage·CurrentDamage)로 옮긴다. 모든 Applicator에 비어 있는 데미지 계산 자리(`ApplyDamage`)를 두고, Mass만 계산식(`BaseDamage × ValueRatio`)을 넣는다. 데미지 게이트는 저장된 `CurrentDamage`와 `ValueRatio`만 읽는다.
- 유저가 보는 결과와 판정 수치는 변경 전과 같아야 한다(이펙트 이중 스폰만 1회로 바뀜).

## 사용자 확정 (28번 머리말·§6)
- 같은 타입의 마법은 하나의 Applicator로 적용하고, 마법마다 다른 값과 연출은 데이터(에셋)로만 구분한다. 필드가 비어 있는 타입도 서브클래스를 만든다.
- `unitType` 직렬화 필드 제거, 서브클래스가 고정값 반환. `UnitType` enum은 유지.
- Applicator는 Logic이며 순수 C#이다. PureData는 Applicator를 참조하지 않는다.
- Apply는 이벤트 경로로만 호출한다. `ApplyUnitChangeStep`·`UnitChangeService` 폴백의 직접 호출은 제거한다.
- 질량 비율은 `RuntimeDataUnit.ValueRatio`. 별도 Rule 클래스는 만들지 않는다. 세제곱근 함수는 `MassUnitApplicator`의 정적 함수.
- 마법 적용 시 CurrentDamage를 투사체 RuntimeData에 저장한다. BaseDamage가 있는 모든 RuntimeData는 CurrentDamage를 가진다. 데미지 계산식은 각 Applicator의 비어 있는 자리에 넣는 구조이며, 여러 계산식의 결합 규칙은 정하지 않는다. 공용 데미지 클래스는 `Assets/PipeLine/Combat/`.
- Torus Mass 에셋은 `PureDataMassUnit`으로 보존. 에셋은 `m_Script`만 교체(GUID 유지). 클래스 이름은 `PureData[타입]Unit` / `[타입]UnitApplicator` / `UnitApplyLogicSystem`.
- Applicator 호출은 VContainer 등록 순수 C# `UnitApplyLogicSystem`이 `RuntimeDataUnitGroup`의 정적 이벤트(`UnitApplyTarget` 포함)를 구독해 수행한다. `UnitTargetLogicSystem`(MonoBehaviour)은 씬·프리팹 3곳에서 제거하고 삭제한다.
- 이펙트는 `IUnitTargetVisualizer.SpawnEffect(prefab)`로 Visualizer가 자기 위치에 스폰한다. 기즈모 UI 검사는 `CurrentUnitData is PureDataVectorUnit`.

## 범위
### 포함
1. **조사 먼저**: 28번 §3-1 표·§4 경로가 현재 코드와 일치하는지 확인하고, PureData 에셋 5개·Applicator 에셋 4개의 GUID와 직렬화 값(연출 에셋 참조 포함), 씬·프리팹의 `CollisionDamageTrigger.baseDamage` 값, `UnitTargetLogicSystem` 부착 위치를 scratchpad에 기록한다. 기획서와 다른 점은 임의로 판단하지 말고 보고한다.

5. **데미지**: `CollisionDamageTrigger`(RuntimeData 보관·`RawDamage = CurrentDamage`), `NpcProjectile`(`Initialize`), `RuntimeDataNpcActor`·`NpcAttackBehaviorSO`·`ProjectileAttackBehaviorSO`·NPC 전달 경로, `AttributeGateStep`(곱셈 제거)·`SizeGateStep`(`ValueRatio`).
