# 튜토리얼 예상 플레이 흐름 (구현 완료 가정)

> 작성일: 2026-09-18
> 근거: `01.기획문서 초안/` 10개 시스템 문서(00_Overview~10) + `튜토리얼 씬 기획서.md`
> 목적: 아직 코드 구현 전이지만, 10개 시스템 문서대로 전부 구현됐다고 가정했을 때 플레이어가 씬 진입부터 승리 화면까지 실제로 겪게 될 순간순간의 흐름을 미리 시뮬레이션한다. 각 beat 끝의 괄호는 관여하는 시스템 문서 번호. 이 시뮬레이션 과정에서 문서 간 아직 확정되지 않은 지점 몇 개를 발견해 맨 끝 "확인 필요" 절에 정리했다.

---

## 0. 씬 진입

1. 씬이 로드되면 [06.이벤트시퀀서시스템.md](./01.기획문서 초안/06.이벤트시퀀서시스템.md)가 `TutorialStage.Stage1`로 초기화된다.
2. 동시에 [10.이동카메라시스템확장_이벤트타겟추적카메라.md](./01.기획문서 초안/10.이동카메라시스템확장_이벤트타겟추적카메라.md)가 신호를 받아 카메라를 **고정 쿼터뷰 프리셋**으로 전환 — 아군, 돌문, 투사체 궤적이 한 화면에 들어오는 구도로 고정된다.
3. [02.아군NPC전투지원행동시스템.md](./01.기획문서 초안/02.아군NPC전투지원행동시스템.md)의 로컬 타이머가 활성화되어 3~4초 간격 반복 발사를 시작한다.

## 1단계: 보스방 진입 퍼즐

1. 아군 NPC가 3~4초마다 무속성 투사체를 돌문을 향해 발사한다. 실제 이동·발사 실행은 [01.NPC전투액터공통프레임워크.md](./01.기획문서 초안/01.NPC전투액터공통프레임워크.md)가 담당하고, "언제 쏠지"는 02번의 로컬 타이머가 결정한다.
2. 투사체가 돌문에 명중하면 [04.파괴가능환경오브젝트시스템.md](./01.기획문서 초안/04.파괴가능환경오브젝트시스템.md)의 피격 파이프라인이 돈다 — 1차 게이트(온도 속성)에서 무속성이라 **항상 걸러짐** → 스파크 이펙트만 재생, 문은 무반응. 플레이어가 개입하지 않는 한 1~2가 무한 반복된다(의도된 대기 상태).
3. 플레이어가 원하는 타이밍에 시간 정지를 발동한다 → 날아가던 투사체가 공중에 완전히 멈추고, 화면이 흑백 정지 필터로 전환되며 투사체만 컬러로 강조된다(기존 시간 정지 마법 시스템).
4. 정지된 투사체를 조준(락온)한다 — 대상이 완전히 멈춰 있으므로 기존 `MagicLockOnComponent` 락온 로직이 그대로 작동하며 별도 판정 로직이 필요 없다. 투사체 외곽선이 하이라이트된다([07.단위마법조작시스템확장_온도단위및조준연출보강.md](./01.기획문서 초안/07.단위마법조작시스템확장_온도단위및조준연출보강.md)).
5. 온도 단위를 낮추는 조작(얼음 속성 인챈트)을 실행 → 투사체 표면이 얼음으로 전환되고 서리 파티클 + 파지직 사운드 재생(07).
6. 크기 확대 조작을 실행 → 마법 링 회전 + 즉각 팽창 이펙트(07). 이때 계산되는 질량 비율은 뒤에서 04번의 데미지 공식에도 그대로 재사용된다.
7. 시간 정지를 해제 → 확대된 얼음 투사체가 자연스럽게 날아가 돌문과 충돌한다.
8. 04번 피격 파이프라인 재실행: 1차 게이트(온도) 통과 → 2차 게이트(최종 데미지 = 기본 70 × 질량 비율 vs 돌문 HP 100) 판정.
   - **데미지 ≥ 100**: 돌문 파괴 애니메이션 + 얼음/암석 파편 파티클 + 파괴음. 통로 개방 → 06이 `TutorialStage.Stage2`로 전환.
   - **데미지 < 100**: 문에 금이 갔다가 곧바로 복구되는 이펙트만 재생, 문은 원상태(HP 100)로 유지 → 플레이어는 아군의 다음 투사체를 기다려 4번부터 재시도해야 한다.

## 2단계: 보스 등장 및 전반부 전투

1. 통로가 열리고 보스방에 진입하면 06이 `Stage2`로 전환하며 [03.보스AI페이즈시퀀스시스템.md](./01.기획문서 초안/03.보스AI페이즈시퀀스시스템.md)의 FSM이 `Idle → BasicAttack` 상태로 진입한다.
2. `BasicAttack` 상태 동안 보스 FSM이 주기적으로 01번 프레임워크(보스 액터)의 `Attack(player)`를 호출해 사전 정의된 공격 패턴을 실행시킨다.
3. 플레이어는 일반 공격/기본 마법으로 응전하고 회피하며 보스 HP를 깎아나간다(기존 전투·마법 시스템 그대로 사용).

## 3단계: 보스 50% 회복 기믹 및 아군 개입

1. 보스 HP가 50%에 도달하는 순간, **두 시스템이 각자 독립적으로** 이 이벤트를 구독해 반응한다(단일 이벤트 소스에 대한 정상적인 발행-구독 구조이며, 이전 세션에서 지적된 "동일 서비스 중복 등록" 버그와는 다른 종류다):
   - 03(보스 FSM): 자체 상태를 `Invulnerable+Healing`으로 전환 — [08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md](./01.기획문서 초안/08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)의 무적 플래그 On 호출 + `Heal()` 호출 시작.
   - 06(이벤트 시퀀서): `OnBoss50Percent`를 방송해 아래를 동시에 트리거.
     - [02](./01.기획문서 초안/02.아군NPC전투지원행동시스템.md): `ally.Attack(boss)` 1회 호출 — 짧은 카메라 컷과 함께 지원 투사체 발사.
     - [10](./01.기획문서 초안/10.이동카메라시스템확장_이벤트타겟추적카메라.md): 카메라가 아군 발사 지점→보스 궤적을 비추는 구도로 자동 전환, 마우스 회전/줌 입력 차단.
     - [09](./01.기획문서 초안/09.시간정지마법시스템확장_게이지오버라이드.md): 유저 입력 없이 시간 정지 자동 발동 — 흑백 필터 + 투사체 컬러 강조 즉시 적용.
     - [08](./01.기획문서 초안/08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)/09: 마나·포커스 게이지 무제한 오버라이드 On.
2. 보스는 전신 화염 이펙트에 휩싸인 채 체력바가 서서히 차오른다(03).
3. 플레이어는 (이미 시간이 멈춘 상태에서) 날아오는 아군 지원 투사체를 조준한다 — 카메라가 이미 투사체 쪽을 향하고 있어 마우스 조준점이 자연스럽게 투사체 위에 위치한다(10).
4. 1단계와 동일하게 온도(얼음) 인챈트 → 크기 확대를 수행한다. 이 구간에서는 마나/게이지가 전혀 줄지 않는다(08/09 오버라이드).

## 4단계: 단위 조작 결정타 및 피니시

1. 시간 정지를 해제하면 확대된 얼음 투사체가 보스를 향해 날아간다.
2. 투사체가 보스 몸통 어디든 명중하면, 캐릭터용 5스텝 피격 파이프라인이 실행된다 — 피격 판정 O 기록 → 온도 게이트 통과 여부 기록 → **무적 상태라 데미지 적용 단계만 무효화**되고 파이프라인이 종료되며 `HitContext`가 발행된다(08).
3. 06(이벤트 시퀀서)이 `HitContext`를 구독해 판정한다.
   - **성공** (이 보스 + 회복 페이즈 상태 + 온도 게이트 통과, 3조건 모두 만족) → `OnCoreHitSuccess` 방송:
     - [05.광역상태이상빙결폭발시스템.md](./01.기획문서 초안/05.광역상태이상빙결폭발시스템.md): 명중 지점 중심 대규모 빙결 폭발, 보스와 주변 사화산 지형이 일제히 동결.
     - 03: `Dead` 상태 전환, 얼음 조각상 사망 모션.
     - 08/09: 오버라이드 Off.
     - 06: `Stage_승리`로 전환 → 승리 화면.
   - **실패** (회복 페이즈 중 온도 게이트 불통과 피격, 또는 완전히 빗나가 타임아웃) → `OnCoreHitFail` 방송:
     - 03: HP 60%로 재설정, 무적 해제, `BasicAttack`으로 복귀.
     - 02: 아군이 즉시 `ally.Attack(boss)`를 재호출 — 재도전 기회 제공.
     - 06: 재도전 루프로 복귀(성공할 때까지 반복 가능, 페널티 누적 없음).

## 발견된, 구현 전 확인이 필요한 지점

이 문서를 순서대로 따라가 보면서 시스템 문서들 사이에 아직 명시적으로 안 정해진 두 지점을 발견했다 — 임의로 결론 내리지 않고 여기 남긴다.

1. **실패 후 재도전 시, 오버라이드가 다시 켜지는가?**
   4단계에서 `OnCoreHitFail`이 발생하면 06번 문서는 "오버라이드 Off"라고 명시하는데, 그 직후 02가 아군에게 즉시 재발사를 시키는 재도전 루프가 다시 시작된다. 이때 마나/게이지 무제한 오버라이드(08/09)와 자동 시간 정지·카메라 전환(09/10)이 **재도전 때마다 다시 켜지는지**가 문서에 명시돼 있지 않다. 만약 재도전 시 오버라이드가 다시 켜지지 않으면, 재시도가 첫 시도보다 훨씬 빡빡해져서(마나 소모, 수동 시간정지 필요) 기획서의 "지루한 재전투 없이 즉각 재도전"이라는 의도와 어긋날 수 있다. → **재도전 루프도 `OnBoss50Percent`와 동일한 번들(카메라+시간정지+오버라이드)을 다시 트리거해야 하는지 확인 필요.**
2. **1단계 파괴 실패 후, 재도전에 조건 변화가 있는가?**
   1단계에서 "파손→복구"가 발생한 뒤에는 그냥 다음 아군 투사체를 다시 기다리는 것으로 문서에 나와 있는데, 이때 돌문이나 아군 발사 주기에 어떤 페널티나 변화도 없다는 것을 한 번 더 명시적으로 확인하고 싶다 — 즉 1단계는 몇 번을 실패해도 완전히 동일한 조건으로 무한 재시도 가능한 게 맞는지.

이 두 가지만 확정되면 지금 문서 세트로 바로 구현 착수가 가능해 보인다.
