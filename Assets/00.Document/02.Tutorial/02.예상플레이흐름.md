## 사전 준비: 마법 얻기·장착·등록

1. 플레이어는 시작 시 기본 유닛(Volume)만 가지고 있다. 얼음(온도)과 크기 확대(질량) 마법은 **바닥에 떨어진 아이템**을 주워서 얻는다(다크소울 방식, 아이템은 모두 같은 외형, 14번). 가까이 가면 줍기 프롬프트가 뜨고 `E`로 줍는다. 일반 플레이 컨텍스트에서만 가능하며 시간정지/메뉴/이벤트 중에는 줍지 못한다. **[구현·검증 완료]**
2. 줍는 순간 아이템이 사라지고 "Unit Acquired: 이름" 팝업이 뜬다. 습득과 장착은 별개라 자동 장착되지 않는다. **[구현·검증 완료]** — 팝업/아이템 이름 표기 통일(따옴표 등)은 후속 정리 대상.
3. 인벤토리(`I`)는 화면 중앙 모달로 열리고 마법 이름과 장착 상태가 보인다. 마법을 클릭해 장착/해제한다(11번). 장착된 마법을 우클릭하면 즐겨찾기 슬롯 W→E→F 순으로 등록되고 아이콘에 배지가 표시된다(12번). **[구현 완료, 우클릭 UI 클릭 경로는 [미검증]]**
4. 시간정지가 아닐 때는 마우스 휠로 퀵슬롯이 순환한다(카메라 줌은 휠에 쓰이지 않음). **[구현·검증 완료]**

## 1단계: 보스방 진입 퍼즐

1. 아군 NPC가 3~4초마다 **무속성 투사체**(기본 데미지 60)를 돌문을 향해 발사한다. 투사체는 오브젝트 풀링으로 재사용되며(15번) 명중/빗나감 모두 풀로 반환된다. 아군 투사체는 **플레이어와 같은 편이라 플레이어를 맞히지 않고 통과**한다(진영 레이어, 16번). **[구현·검증 완료]**
2. 투사체가 돌문에 명중하면 [04](../01.기획문서 초안/04.파괴가능환경오브젝트시스템.md)의 피격 파이프라인이 돈다 — 1차 게이트(온도 속성)에서 무속성이라 항상 걸러짐 → 스파크 이펙트만. 플레이어가 개입하지 않는 한 무한 반복된다(의도된 대기). **[구현·검증 완료]**
3. 플레이어가 `T`로 시간정지를 발동한다 → 투사체가 멈추고 흑백 필터로 전환되며 투사체만 컬러로 강조된다. **[구현·검증 완료]**
4. **정지된 투사체를 좌클릭해 락온할 때마다 선택지 팝업이 뜬다**(락온마다 매번, 12/13번). 팝업은 Q(장착 마법 전체 목록)/W/E/F(즐겨찾기) 네 선택지다. 선택은 **그 락온 대상에 마법을 지정하는 것**이며(시간정지 해제나 즉시 시전이 아님) 락온을 이어가며 다른 대상에 다른 마법을 지정하거나, 같은 대상에 마법을 여러 개 쌓을 수 있다(예: 투사체 A엔 얼음, B엔 크기, C엔 둘 다). 지정한 (대상, 마법)마다 적용 전 변화 미리보기가 표시되고, HUD 마나 바에 이번 발동의 **예상 총 비용**이 표시된다. **[구현·검증 완료]** — 미리보기 고스트의 시각적 완성도는 **[미검증]**.
5. `T`로 시간정지를 해제하면 쌓인 모든 지정이 **그 순간 한 번만** 적용된다(`UnitCasterSystem.ExecuteBatchCast()`): 마나는 장착된 마법의 `BaseCost` 합을 한 번에 차감하고, **마나가 부족하면 전부 실패**한다. 적용된 투사체는 자연스럽게 날아가 돌문과 충돌한다. **[구현·검증 완료]**
6. 04번 피격 파이프라인 재실행: 1차 게이트(온도) 통과 → 2차 게이트(최종 데미지 = 60 × 질량 비율 vs 돌문 HP 100). 크리티컬이 없어 결과는 항상 같다. **[구현·검증 완료]**
   - **얼음+크기 확대(×2) = 120 ≥ 100**: 돌문 파괴 애니메이션 + 파편 + 파괴음. 통로 개방 → 06이 `Stage2`로 전환. 아군 타이머는 돌문 `IsDestroyed` 이후 영구 정지.
   - **얼음만 = 60 < 100**: 금이 갔다가 복구되는 이펙트만(속성만으로는 부족하다는 피드백), 문은 원상태 → 다음 투사체를 기다려 4번부터 재시도.
   - 무속성 또는 크기만: 1차 게이트에서 걸러져 스파크만.

## 2단계: 보스 등장 및 전반부 전투

1. 통로가 열리고 보스방에 진입하면 06이 `Stage2`로 전환하며 [03](../01.기획문서 초안/03.보스AI페이즈시퀀스시스템.md)의 FSM이 `Idle → BasicAttack`으로 진입한다. **[구현·검증 완료]**
2. `BasicAttack` 동안 보스 FSM이 주기적으로 01번 프레임워크의 `Attack(player)`를 호출한다. 현재 보스는 **전용 공격 패턴이 없어 임시로 투사체 공격 전략을 쓴다**(전략 SO만 교체하면 코드 수정 없이 바뀌는 구조). 보스 투사체는 플레이어의 가슴 높이를 조준하며 적(Enemy) 진영이라 플레이어에게 명중해 HP가 감소한다. **[구현·검증 완료]** — 회피(구르기) 무적/보스의 플레이어 처치 처리는 **[미구현]**.
3. 플레이어는 일반 공격/기본 마법으로 응전한다(기존 시스템, 이번 튜토리얼 작업 범위 밖). **[기존 시스템]**

## 3단계: 보스 50% 회복 기믹 및 아군 개입

1. 보스 HP가 50%에 도달하면 두 시스템이 독립적으로 반응한다. **[구현·검증 완료]**
   - 03(보스 FSM): `Invulnerable+Healing` 전환 — 무적 플래그 On + 회복 시작(60% 상한). 이때 보스의 **피격 플래그가 `AttributeGate` 단독으로 전환**된다(16번, 해제 시 `Evasion|Defense`로 원복).
   - 06: 이벤트 비행 시작을 알리고(발사 지점을 플레이어-보스 축 위에 고정) `OnBoss50Percent`를 방송 → 02: 아군 지원 투사체 1발 발사 / 10: 숄더 카메라가 투사체를 몸으로 가리므로 카메라가 이벤트 전용 1인칭 가상 카메라(캐릭터 눈 위치, 몸/머리 렌더 숨김)로 짧게 블렌드 전환되어 시선이 매 프레임 눈→날아오는 이벤트 투사체 방향으로 돌고(22번 §8·§10, 별도 `CameraMode`는 아님) 마우스 회전/줌 입력 차단, 이벤트가 끝나면 숄더 카메라로 이전 시선 그대로 복귀 / 09: 시간 **감속** 시작 / 포커스 게이지·마나 무제한 On.
2. **감속은 시간이 아니라 투사체의 위치로 구동된다**(13번): 투사체가 플레이어에게 접근하는 구간에서 `timeScale`이 점점 강하게 내려가고(접근), 플레이어를 지나치면서 다시 올라가 정상 속도로 돌아온다(이탈). 플레이어와 투사체의 상대 위치 부호가 음→양으로 바뀌는 순간이 **전환점(최저 `timeScale`)** 이다. 06의 타임아웃 실패 판정은 **제거**됐다 — 아군이 반드시 쏘므로 판정은 명중 결과로만 난다. **[구현·검증 완료]**
3. 이벤트 동안에도 락온과 마법 선택 팝업은 1단계와 똑같이 열린다. 단, **수동 시간정지 해제(`T`)와 인벤토리(`I`)는 차단**된다(감속 중 해제 버그 방지, 13번). 마법 지정은 큐에만 쌓이고 **전환점에서 한 번만 일괄 발동**된다(발동 후 지정 창은 닫힘). 보스는 전신 화염 속에서 체력바가 60% 상한까지 차오른다. **[구현·검증 완료]**
4. 얼음 인챈트 + 크기 확대를 같은 투사체에 지정한다. 이 구간의 포커스 게이지와 마나는 줄지 않는다. 지정이 늦어 전환점을 지나면 그 지정은 적용되지 않고 투사체가 그대로 날아가 실패한다. **[구현·검증 완료]**

## 4단계: 단위 조작 결정타 및 피니시

1. 이벤트 투사체가 보스를 향해 날아간다(아군 편이라 플레이어는 맞히지 않고 지나친다). **[구현·검증 완료]**
2. 보스 명중 시 피격 파이프라인이 실행된다 — 피격 판정 O 기록 → 속성 게이트(얼음) → `FinalDamage = 60 × 질량 비율` 계산 → 무적이라 데미지 적용만 무효화되고 `DamageContext`가 발행된다(08). **[구현·검증 완료]**
3. 06이 `DamageContext`를 구독해 판정한다(이벤트 투사체의 명중만 판정 대상). **[구현·검증 완료]**
   - **성공** = 이 보스 + 회복 페이즈 + 얼음 게이트 통과 + `FinalDamage ≥ 100`(얼음+크기 확대 = 120) → `OnCoreHitSuccess`: 05 광역 빙결 / 03 `Dead` + HP를 0까지 감소 + 사망 모션 / 게이지·마나 오버라이드 Off / `Stage4Success`. 승리 화면은 만들지 않으며 사망 모션이 마지막 연출이다.
   - **실패** = 마법 없음 / 크기만 / 얼음만(60 < 100) / 투사체가 명중 없이 소실(소프트락 안전망) → `OnCoreHitFail`: 03 HP 60% 재설정·무적 해제·`BasicAttack` 복귀 / 02 아군 즉시 재발사 / 06 재도전 루프 — 재도전 때마다 3단계 진입 때와 동일하게 `OnBoss50Percent` 번들이 다시 트리거된다.

## 알려진 미구현/미해결 항목 (임의로 채우지 않고 명시)

1. **승리 화면/씬 전환**: 범위 제외(보스 사망까지가 목표, 사망 연출 보강은 나중). `TutorialStage.Victory`는 미사용.
2. **3단계 판정 구조 개편(예정)**: 지금 성공 판정은 "얼음 게이트 통과 + 최종 데미지 ≥ 기준치"다. 어떤 마법이 적용됐는지(속성/크기)와 최종 데미지를 모두 개별 확인하는 구조(`SizeGate`, 게이트별 결과 플래그)와 돌문과의 통일은 별도 기획서로 진행 예정.
3. **구르기 무적 프레임 [미구현]**: 구르기 입력/애니메이션/스태미나 없음(별도 조사·기획 예정).
4. **중립 NPC 적대화 규칙 [미구현]**: 진영이 런타임에 바뀌어도 충돌 규칙이 따라가는 데이터 경로까지만 있음(3번 연속 피격 시 적대화 규칙은 기획 예정).
5. **NPC가 길을 막고 돌문이 부서지면 비켜 길이 열리는 연출 [미확인]**: 몸체 충돌은 유지되도록 구현돼 있으나 NPC 이동 연출은 확인된 바 없음.
6. **Option 메뉴/인벤토리와 시간정지 `timeScale` 상호작용**: Option과 인벤토리가 각자 `timeScale`을 저장했다 복원하는 구조라 동시에 열면 꼬일 수 있고, 이벤트 감속 중 Option을 열면 감속 구동이 `timeScale`을 매 프레임 다시 쓰므로 정지가 유지되지 않는다(기존 문제, 후속).
7. **진영 레이어 후속 사항**: 시전 실패 시에도 투사체 진영이 바뀌는 문제(성공 시에만 바꾸도록 수정 예정), 중립 진영 발사자가 자기 몸체를 맞히는 문제(중립 전용 투사체 레이어 예정).
8. **씬은 통합 테스트 수준**: 실제 최종 아트/레벨이 아니라 대역 오브젝트로 구성. 로직/신호 흐름 검증은 끝났지만 비주얼 완성도는 별개다.
9. **로그/경고**: 이벤트 전환 때 애니메이터 `Parameter 'Hash 468800000' does not exist` 경고가 찍힌다(오류 아님, 원인 미추적).
