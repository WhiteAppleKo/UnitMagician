## 1단계: 보스방 진입 퍼즐

1. 아군 NPC가 3~4초마다 무속성 투사체를 돌문을 향해 발사한다. 실제 이동·발사 실행은 [01.NPC전투액터공통프레임워크.md](../01.기획문서 초안/01.NPC전투액터공통프레임워크.md)가 담당하고, "언제 쏠지"는 02번의 로컬 타이머가 결정한다. **[구현·검증 완료]** — 씬에 보스(`EnemyTest`)와 아군(`NpcCombatActor_Dummy`)이 동시에 존재할 때 `NpcSystemLifetimeScope`가 하나만 DI 주입하던 실제 버그를 통합 조립 중 발견해 수정(`RegisterComponent().Keyed()` 방식으로 전환) — 이 수정 전에는 아군이 투사체를 스폰해도 데미지 처리가 통째로 무동작이었다.
2. 투사체가 돌문에 명중하면 [04.파괴가능환경오브젝트시스템.md](../01.기획문서 초안/04.파괴가능환경오브젝트시스템.md)의 피격 파이프라인이 돈다 — 1차 게이트(온도 속성)에서 무속성이라 **항상 걸러짐** → 스파크 이펙트만 재생, 문은 무반응. 플레이어가 개입하지 않는 한 1~2가 무한 반복된다(의도된 대기 상태). **[구현·검증 완료]**
3. 플레이어가 원하는 타이밍에 시간 정지를 발동한다 → 날아가던 투사체가 공중에 완전히 멈추고, 화면이 흑백 정지 필터로 전환되며 투사체만 컬러로 강조된다(완전 정지 모드, 기존 시간 정지 마법 시스템). **[구현·검증 완료]** — `PlayerLockOnController`가 시간정지 이벤트 구독을 놓치는 실제 버그(`Construct()` 시점 `isActiveAndEnabled` 타이밍 문제)를 통합 조립 중 발견해 수정. 이 버그가 있었을 때는 시간정지를 켜고 꺼도 락온 오브젝트 전환 자체가 전혀 자동으로 일어나지 않았다.
4. 정지된 투사체를 조준(락온)한다 — 시간정지 시 `PlayerLockOnController`가 `MagicLockOn` 자식 오브젝트를 활성화하고 입력 컨텍스트를 Tactical로 전환, `MagicLockOnComponent`가 마우스 호버/클릭으로 다중 락온을 누적한다([07.단위마법조작시스템확장_온도단위및조준연출보강.md](../01.기획문서 초안/07.단위마법조작시스템확장_온도단위및조준연출보강.md)). **[구현·검증 완료]** — 실제 활성 경로가 `AimLockOnCastingStrategy`(Strategy 폴더)가 아니라 `PlayerLockOnController`→`MagicLockOnComponent`→`UnitCasterSystem`이라는 것도 이번에 확인됨(`AimLockOnCastingStrategy`는 다크소울3식 숄더뷰에서 채택된 적 없는 죽은 코드였고, 그런데도 같은 이벤트를 구독해 데이터를 건드릴 위험이 있어 제거).
5. 온도 단위를 낮추는 조작(얼음 속성 인챈트)을 실행 → 투사체 표면이 얼음으로 전환되고 서리 파티클 + 파지직 사운드 재생(07). **[구현 완료, 세부 연출 미검증]**
6. 크기 확대 조작을 실행 → 마법 링 회전 + 즉각 팽창 이펙트(07). 이때 계산되는 질량 비율은 뒤에서 04번의 데미지 공식에도 그대로 재사용된다. **[구현 완료, 세부 연출 미검증]**
7. 시간 정지를 해제 → 확대된 얼음 투사체가 자연스럽게 날아가 돌문과 충돌한다. 이 시점에 `UnitCasterSystem.ExecuteBatchCast()`가 자동 호출되어 락온된 대상에 선택 단위가 일괄 적용되고 마나가 소모된다(`ICharacterStatService.UseMP()` 경유). **[구현·검증 완료]** — `UnitCasterSystem`이 실제로는 `RuntimeStatData`를 직접 건드려 마나무제한 게이트를 우회하던 버그를 통합 조립 중 발견해 수정(`ICharacterStatService.UseMP()` 경유하도록 변경).
8. 04번 피격 파이프라인 재실행: 1차 게이트(온도) 통과 → 2차 게이트(최종 데미지 = 기본 70 × 질량 비율 vs 돌문 HP 100) 판정. **[구현·검증 완료]**
   - **데미지 ≥ 100**: 돌문 파괴 애니메이션 + 얼음/암석 파편 파티클 + 파괴음. 통로 개방 → 06이 `TutorialStage.Stage2`로 전환. 아군의 반복 발사 타이머는 돌문의 `IsDestroyed` 값을 확인해 이 시점 이후 영구 정지한다(02번 구현 시 04번에 추가한 프로퍼티).
   - **데미지 < 100**: 문에 금이 갔다가 곧바로 복구되는 이펙트만 재생, 문은 원상태(HP 100)로 유지 → 플레이어는 아군의 다음 투사체를 기다려 4번부터 재시도해야 한다.

## 2단계: 보스 등장 및 전반부 전투

1. 통로가 열리고 보스방에 진입하면 06이 `Stage2`로 전환하며 [03.보스AI페이즈시퀀스시스템.md](../01.기획문서 초안/03.보스AI페이즈시퀀스시스템.md)의 FSM이 `Idle → BasicAttack` 상태로 진입한다. **[구현·검증 완료]**
2. `BasicAttack` 상태 동안 보스 FSM이 주기적으로 01번 프레임워크(보스 액터)의 `Attack(player)`를 호출해 사전 정의된 공격 패턴을 실행시킨다. **[구현·검증 완료]**
3. 플레이어는 일반 공격/기본 마법으로 응전하고 회피하며 보스 HP를 깎아나간다(기존 전투·마법 시스템 그대로 사용). **[기존 시스템, 이번 튜토리얼 작업 범위 밖]**

## 3단계: 보스 50% 회복 기믹 및 아군 개입

1. 보스 HP가 50%에 도달하는 순간, **두 시스템이 각자 독립적으로** 이 이벤트를 구독해 반응한다(단일 이벤트 소스에 대한 정상적인 발행-구독 구조). **[구현·검증 완료]** — 통합 조립 중 04개 시스템(02/03/09/10)이 **동시에** 같은 신호로 정상 반응하는지까지 실제로 확인한 것은 이번이 처음이며(그전엔 각 시스템을 개별로만 테스트), 실제로 전부 정상 동작함을 확인했다.
   - 03(보스 FSM): 자체 상태를 `Invulnerable+Healing`으로 전환 — [08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md](../01.기획문서 초안/08.캐릭터스탯상태시스템확장_무적플래그및오버라이드.md)의 무적 플래그 On 호출 + `Heal()` 호출 시작(60% 상한 있음, 아래 참고).
   - 06(이벤트 시퀀서): `OnBoss50Percent`를 방송해 아래를 동시에 트리거.
     - [02](../01.기획문서 초안/02.아군NPC전투지원행동시스템.md): `ally.Attack(boss)` 1회 호출 — 지원 투사체 발사.
     - [10](../01.기획문서 초안/10.이동카메라시스템확장_이벤트타겟추적카메라.md): 카메라가 아군 발사 지점→보스 궤적을 비추는 구도로 자동 전환(같은 3인칭 숄더뷰 거리감 유지, 바라보는 대상만 전환), 마우스 회전/줌 입력 차단.
     - [09](../01.기획문서 초안/09.시간정지마법시스템확장_게이지오버라이드.md): 유저 입력 없이 시간 정지 **자동 발동 — 1단계의 "완전 정지"와 다른 감속(슬로우 모션)** 모드. 흑백 필터 + 투사체 컬러 강조는 동일하게 적용되지만 시간은 완전히 멈추지 않고 느리게 흐른다.
     - **[08/09 포커스 게이지 무제한 오버라이드]**: On. **[구현·검증 완료]**
     - **[08 마나 무제한 오버라이드]**: **[미구현]** — 아래 "알려진 미구현/미해결 항목" 1번 참고. 이 구간에서 마법을 시전하면 마나가 정상적으로 소모된다(무제한 아님).
2. 보스는 전신 화염 이펙트에 휩싸인 채 체력바가 서서히 차오른다(03). **[구현·검증 완료]** — 회복은 60%(`ReviveHpRatioOnFail`) 상한을 넘지 않도록 캡이 걸려 있다(원래는 상한이 없어 타임아웃 전에 100%까지 회복해버리는 버그가 있었고, 통합 조립 중 발견해 수정).
3. 플레이어는 (이미 감속된 시간 속에서) 날아오는 아군 지원 투사체를 조준한다 — 카메라가 이미 투사체 쪽을 향하고 있어 마우스 조준점이 자연스럽게 투사체 위에 위치한다(10). **유저가 아무 조작도 하지 않으면, 이 감속은 06번의 회복 페이즈 지속시간(`coreHitTimeoutSeconds`)에 맞춰 점차 원래 속도(1.0배)로 되돌아온다** — 시간이 다시 정상 속도가 되는 순간이 곧 "이 기회를 놓쳤다"는 시청각적 신호이며, 그 시점에 06이 타임아웃으로 `OnCoreHitFail`을 방송한다(09/06절 참고). **[구현·검증 완료]**
4. 1단계와 동일하게 온도(얼음) 인챈트 → 크기 확대를 수행한다. 이 구간에서는 포커스 게이지는 전혀 줄지 않지만(08/09 오버라이드), **마나는 정상적으로 소모된다(위 미구현 항목 참고)**. 감속-복귀 타이머가 계속 흐르고 있으므로, 조작이 오래 걸리면 그만큼 시간이 빨라져 조준이 점점 어려워진다(의도된 긴장감). **[구현·검증 완료, 마나 소모 부분 제외]**

## 4단계: 단위 조작 결정타 및 피니시

1. 시간 정지를 해제하면 확대된 얼음 투사체가 보스를 향해 날아간다. **[구현·검증 완료]**
2. 투사체가 보스 몸통 어디든 명중하면, 캐릭터용 피격 파이프라인이 실행된다 — 피격 판정 O 기록 → 온도 게이트 통과 여부 기록 → **무적 상태라 데미지 적용 단계만 무효화**되고 파이프라인이 종료되며 `DamageContext`(구 "HitContext")가 발행된다(08). **[구현·검증 완료]**
3. 06(이벤트 시퀀서)이 `DamageContext`를 구독해 판정한다. **[구현·검증 완료]**
   - **성공** (이 보스 + 회복 페이즈 상태 + 온도 게이트 통과, 3조건 모두 만족) → `OnCoreHitSuccess` 방송:
     - [05.광역상태이상빙결폭발시스템.md](../01.기획문서 초안/05.광역상태이상빙결폭발시스템.md): 명중 지점(실제로는 보스 위치) 중심 반경 내 대상에 순차 빙결 이펙트, 보스와 주변 지형이 동결. **[구현·검증 완료]**
     - 03: `Dead` 상태 전환 + **HP를 실제로 0까지 강제 감소**(`RuntimeData.ReduceHP`로 무적 게이트 우회) + 사망 모션. **[구현·검증 완료]** — 최초 구현 시 `Dead` 전환은 되지만 HP가 0이 안 되던 버그를 QA가 발견해 수정.
     - 08/09(포커스 게이지): 오버라이드 Off. **[구현·검증 완료]**
     - 06: `Stage4Success`로 전환 → **승리 화면 전환은 [미구현]**(아래 2번 참고).
   - **실패** (회복 페이즈 중 온도 게이트 불통과 피격, 또는 감속이 원래 속도로 다 돌아올 때까지 유효 피격이 없는 타임아웃) → `OnCoreHitFail` 방송:
     - 03: HP 60%로 재설정, 무적 해제, `BasicAttack`으로 복귀. **[구현·검증 완료]**
     - 02: 아군이 즉시 `ally.Attack(boss)`를 재호출 — 재도전 기회 제공. **[구현·검증 완료]**
     - 06: 재도전 루프로 복귀 — **재도전 시 3단계 진입 시점과 완전히 동일하게 `OnBoss50Percent` 번들이 매번 다시 트리거된다.** **[구현·검증 완료]** — 최초 구현 시 `TutorialStage`가 `Stage4Fail` 이후 영구히 `>= Stage3`로 남아 재도전 시 신호가 다시는 안 나가던 버그를 통합 조립 중 발견해 수정(`Stage2`로 되돌리는 처리 추가).

## 알려진 미구현/미해결 항목 (임의로 채우지 않고 명시)

1. **마나 무제한 오버라이드 트리거 자체가 없음**: `ICharacterStatService.SetManaUnlimited(bool)` API와 `UseMP()` 내부 게이트는 정상 구현·검증됐지만, 06의 신호(`OnBoss50Percent`/`OnCoreHitSuccess`/`OnCoreHitFail`)에 맞춰 이 API를 자동으로 켜고 끄는 호출 자체가 아직 어디에도 연결돼 있지 않다. 09(TimeSlowLogicSystem)가 담당하는 게 배선 비용상 가장 간단하다는 논의까지는 했으나 실제 구현/검증은 안 됨.
2. **승리 화면/씬 전환 미구현**: `TutorialStage.Victory`가 enum에 정의만 되어 있고, 06/03/05 어디에도 이 값으로 전환하는 코드가 없다 — 4단계 성공 시 실제로는 `Stage4Success`에서 멈춘다. 승리 UI/연출/씬 전환을 담당하는 시스템 자체가 존재하지 않는다.
3. **3단계 감속 중 수동 시간정지 해제 처리 미구현**: 감속(`IsEventTriggered`) 진행 중 플레이어가 수동으로 `ToggleSlow()`를 호출하면 `IsSlowActive`만 꺼지고 감속 램프/게이지 오버라이드는 그대로 남는 문제가 QA 중 발견됐다(별도 후속 작업으로 분리해뒀고 아직 착수 전).
4. **씬은 통합 테스트 수준**: 실제 최종 아트/레벨(사화산 지형, 진짜 돌문·보스 모델)이 아니라 대역 오브젝트로 구성돼 있다. 로직/신호 흐름 검증은 끝났지만 실제 비주얼 완성도는 별개다.
