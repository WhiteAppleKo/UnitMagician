# 04. 반응형 턴제 시간정지 마법 및 타깃팅 시스템

## 1. 작업 개요 및 유형
* **기능 요약**: 실시간 액션과 턴제 전술의 장점을 결합하여, 평상시에는 손에 든 무기 속성 인챈트 위주로 빠르게 전투하고, 시간 정지 상태에서는 넉넉한 시간 속에서 마법과 대상을 차례로 선택 및 예약하여 연쇄 발동하는 33원정대 스타일의 반응형 턴제 마법 시스템을 구축합니다.
* **작업 유형**: 시청각 및 로직 복합 영역 (조작계 개편, 전술 UI/UX 구축, 마법 예약 및 순차 발동 로직)

---

## 2. 기존 문제점 및 개편 배경

### 1) 실시간 피지컬 과부하
* 실시간 전투 중에 이동, 회피, 숫자 퀵슬롯 선택, 마우스 조준을 동시에 수행해야 해서 손이 꼬이고 조작 피로도가 극심했습니다.

### 2) 단위 조작의 본질 퇴색
* 마법과 단위를 계산하고 전략을 세울 여유가 없어, 깊이 있는 마법 플레이 대신 단순 난사 액션으로 전락하는 문제가 있었습니다.

### 3) 퀵슬롯의 역할 모호함
* 손에 쥔 무기를 강화하는 조작과 원거리 투사체 및 지형을 조작하는 마법이 하나의 퀵슬롯에 섞여 있어 직관성이 떨어졌습니다.

---

## 3. 핵심 요구사항 및 상세 설계

### 1) 역할 분리: 좌하단 단일 퀵슬롯과 휠 순회 (내 손 무기 인챈트 전담)
* **다크소울3 스타일의 단일 퀵슬롯 UI**:
  * 화면 좌하단에 단 하나의 메인 퀵슬롯 UI를 배치합니다.
  * 마우스 휠 스크롤을 통해 등록된 속성 마법 리스트를 위아래로 부드럽게 순회합니다.
* **평상시 실시간 액션 유지**:
  * 숫자키를 손가락으로 찾아 누를 필요 없이, 마우스 휠 조작만으로 내 손에 든 무기에 부여할 속성(불, 얼음 등)을 즉시 교체합니다.
  * 이동과 공격의 템포를 전혀 끊지 않고 빠른 속성 전환이 가능합니다.

### 2) 시간 정지 전술 모드: 시간 무제한 및 예상 마나 연동 예약
* **시간 무제한 정지**:
  * T키 입력 시 시간이 완전 정지되며, 유저가 메뉴를 둘러보고 대상을 고민하는 동안 시간제한이나 자연 감소가 전혀 없습니다.
* **예상 마나 소모량 계산 및 예약 차단**:
  * 마법을 고르고 대상을 지정할 때마다 '예상 마나 소모량'이 실시간으로 누적 계산됩니다.
  * 화면 마나 게이지에 예약에 필요한 소모량이 반투명 예고선으로 실시간 표시됩니다.
  * 보유한 마나를 초과하는 마법을 추가로 예약하려 하면 마나 부족 상태가 되어 더 이상 예약 도장이 찍히지 않도록 원천 차단합니다.
* **순차 조작 흐름**:
  1. **마법 선택**: 전술 원형 메뉴 또는 스킬 슬롯에서 사용할 마법(얼음 창, 크기 팽창, 속성 변환 등)을 선택합니다.
  2. **대상 지정**: 마우스를 움직여 적용할 대상을 클릭하여 타깃으로 지정합니다.
  3. **연쇄 예약**: 보유 마나가 허용하는 한 연속으로 [마법 선택 $\rightarrow$ 대상 지정]을 누적 예약합니다.
  4. **실행**: T키를 다시 누르거나 실행 키를 누르면 시간 정지가 풀리며, 예약된 마법들이 순서대로 전광석화처럼 연쇄 발동하고 실제 마나가 차감됩니다.

## 4. 조작 및 연출 흐름도

```
[평상시 : 실시간 액션 모드]
    ├─ 이동 (WASD) 및 기본 무기 공격 (마우스 좌클릭)
    └─ 무기 인챈트 퀵슬롯 : 좌하단 단일 슬롯, 마우스 휠로 속성 순회 장착

[T키 입력 : 시간 정지 전술 모드 진입]
    ├─ 배경 흑백 전환 및 대상 하이라이트
    │
    ├─ 1단계: 전술 마법 메뉴 표출 (원형 UI)
    │   └─ 사용할 단위 조작 마법 선택 (예: 크기 확대, 얼음 속성)
    │
    ├─ 2단계: 대상 순차 지정 (마우스 클릭)
    │   └─ 대상 머리 위에 [1st], [2nd] 예약 인디케이터 표시
    │
    └─ 3단계: 예약 실행 (T키 재입력 또는 실행 버튼)
        └─ 시간 정상화 복귀 $\rightarrow$ 예약된 마법 순차 격발 $\rightarrow$ 연쇄 피격 연출
```

## 5. DLV 아키텍처 파일 설계
* **LifetimeScope**: `Assets/02.System/06.TacticalCommand/TacticalCommandLifetimeScope.cs`

### [D] 데이터 그룹
* **Pure Data**: `Assets/02.System/06.TacticalCommand/00.Data/PureDataTacticalCommand.cs`
  * 최대 예약 가능 슬롯 수, 예약 슬롯별 마나 소모 기준, 실행 딜레이 간격 불변 데이터
* **Runtime Data**: `Assets/02.System/06.TacticalCommand/00.Data/RuntimeDataTacticalQueue.cs`
  * 현재 예약된 마법 명령 큐 보관, 대상 타깃 리스트 관리, 실행 대기 이벤트 발행

### [L] 로직 그룹
* **Logic System**: `Assets/02.System/06.TacticalCommand/01.Logic/TacticalCommandLogicSystem.cs`
  * T키 진입 시 전술 모드 전환 판단
  * 마법 및 대상 유효성 검증
  * 마나 잔여량에 따른 예약 가능 여부 판정
  * 큐에 쌓인 마법들의 순차 발동 스케줄링 관리

### [V] 비주얼 그룹
* **Visual Interface**: `Assets/02.System/06.TacticalCommand/02.Visual/ITacticalCommandVisualizer.cs`
  * 전술 원형 메뉴 및 오버레이 노출/숨김
  * 타깃 머리 위 예약 번호 인디케이터 및 궤적 연결선 표시
  * 실행 시 연쇄 타격 이펙트 호출 규격
* **World Visualizer**: `Assets/02.System/06.TacticalCommand/02.Visual/TacticalCommandVisualizer.cs`
  * LineRenderer 기반 궤적 연결선 렌더링
  * 타깃팅 조준선 및 순서 뱃지([1st], [2nd] 등) 시각 연출 처리
* **UI View**: `Assets/02.System/06.TacticalCommand/02.Visual/TacticalCommandUIView.cs`
  * 화면 UI Toolkit 기반 전술 HUD 및 예상 마나 소모량 게이지 렌더링

## 6. DLV 3대 원칙 준수 확인
- [x] **Everything is Data**: 모든 예약 설정 및 타이밍을 Pure Data 객체로 정의 완료
- [x] **Blind Logic**: 로직 시스템이 비주얼 구체 컴포넌트를 직접 참조하지 않고 ITacticalCommandVisualizer 인터페이스를 통해 지시
- [x] **Immutable Data**: Pure Data는 불변 유지, Runtime Data는 private set과 전용 변경 메서드로 캡슐화 완료
