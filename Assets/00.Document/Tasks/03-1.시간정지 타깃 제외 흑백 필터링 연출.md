# 03-1. 시간 정지 타깃 제외 흑백 필터링 연출

## 1. 작업 개요 및 유형
* **기능 요약**: 시간 정지 발동 시 마법 락온이 가능한 타깃 물체와 플레이어만 원래 색상을 유지하고, 그 외의 모든 배경과 물체는 흑백으로 변환하여 대상의 시인성을 극대화합니다.
* **작업 유형**: 시청각 영역 (화면 효과 및 그래픽 연출)

---

## 2. 핵심 요구사항 및 위험 요소 분석

### 1) 핵심 연출 요구사항
* **흑백 전환**: 시간 정지 진입 시 화면 전체가 0.3초 동안 부드럽게 흑백 톤으로 변경됩니다.
* **타깃 컬러 보존**: 락온 가능한 마법 대상 물체와 플레이어는 원래 색상을 그대로 유지합니다.
* **컬러 복귀**: 시간 정지가 해제되면 다시 원래의 풀컬러 화면으로 부드럽게 복귀합니다.

### 2) 프로젝트 적용 위험 요소 및 해결 방안
1. **물리 충돌 및 레이캐스트 꼬임 위험**:
   * 타깃 물체의 레이어를 임의로 변경하면 기존 지형이나 물리 충돌 판정이 망가질 수 있습니다.
   * **해결 방안**: 기존 물리 레이어를 건드리지 않고, 그래픽 렌더러 컴포넌트를 스텐실 도장 패스에 직접 등록하거나 전용 렌더 마스크 레이어만 안전하게 활용합니다.
2. **시간 정지 시 화면 전환 멈춤 버그**:
   * 시간 정지 시 게임 시간 배율이 0이 되거나 느려지면 애니메이션이 멈출 수 있습니다.
   * **해결 방안**: 게임 시간의 영향을 받지 않는 현실 시간(`Time.unscaledDeltaTime`) 기준으로 전환 수치를 변경합니다.
3. **머티리얼 원본 에셋 손상 방지**:
   * 에셋 파일의 수치를 직접 건드리면 프로젝트 설정이 영구 오염됩니다.
   * **해결 방안**: 전역 셰이더 변수(`Shader.SetGlobalFloat`)를 사용하여 씬이나 파일 훼손 없이 안전하게 수치를 제어합니다.
4. **반투명 물체 마스킹 누락**:
   * 불투명 물체 렌더링 직후에 스텐실 도장을 찍어 반투명 이펙트가 타깃의 윤곽을 가리지 않도록 렌더 순서를 고정합니다.

## 3. 전체 렌더링 파이프라인 흐름

```
[1] 기본 씬 렌더링
    └─ 배경, 지형, 플레이어, 타깃 물체가 풀컬러로 정상 렌더링됨
               ↓
[2] Render Objects 패스 (스텐실 도장 찍기)
    ├─ 타깃 물체만 다시 검사
    └─ 화면 색상은 칠하지 않고, 스텐실 메모리에만 [값 = 1] 도장 기록
               ↓
[3] Full Screen Pass (흑백 필터 셰이더)
    ├─ 화면 전체 픽셀 검사
    ├─ 스텐실 값이 1인 픽셀 (타깃) : 원래 색상 유지
    └─ 스텐실 값이 1이 아닌 픽셀 (배경) : 흑백으로 덮어쓰기
               ↓
[최종 결과] 타깃만 선명한 컬러 + 주변 모든 배경은 흑백 필름 톤
```

## 4. DLV 아키텍처 파일 설계

### [D] 데이터 그룹
* **Pure Data**: `Assets/02.System/02.CharacterSystem/00.Data/PureDataTimeSlowFilter.cs`
  * 전환 시간(기본 0.3초), 흑백 대비 수치, 셰이더 프로퍼티 이름 보관
* **Runtime Data**: `Assets/02.System/02.CharacterSystem/00.Data/RuntimeDataPlayerState.cs`
  * 기존 플레이어 상태 데이터(시간 정지 진입 및 해제 이벤트 활용)

### [L] 로직 그룹
* **Logic System**: `Assets/02.System/02.CharacterSystem/01.Logic/TimeSlowFilterLogicSystem.cs`
  * 시간 정지 상태 진입 및 해제 이벤트를 감지하여 화면 연출 시작 명령 전달
  * 렌더링 기능을 직접 호출하지 않고 비주얼 인터페이스를 통해 위임

### [V] 비주얼 그룹
* **Visual Interface**: `Assets/02.System/02.CharacterSystem/02.Visualizer/ITimeSlowFilterVisualizer.cs`
  * `SetFilterIntensity(float intensity)`
  * `PlayFilterTransition(bool isEnter)`
* **World Visualizer**: `Assets/02.System/02.CharacterSystem/02.Visualizer/TimeSlowFilterVisualizer.cs`
  * 현실 시간(`Time.unscaledDeltaTime`) 기반 화면 흑백 전환 애니메이션 실행
  * 전역 셰이더 프로퍼티를 갱신하여 렌더러에 전달
* **Custom Shader**: `Assets/03.Shaders/GrayscaleExcludeTarget.shader`
  * 스텐실 1번 영역을 제외하고 배경만 흑백으로 변환하는 풀스크린 셰이더
* **Material**: `Assets/03.Shaders/M_GrayscaleExcludeTarget.mat`
  * URP Full Screen Pass 렌더러 피처에 장착할 머티리얼

## 5. DLV 3대 원칙 준수 확인
- [ ] **Everything is Data**: 전환 시간 및 필터 수치를 Pure Data 객체로 정의
- [ ] **Blind Logic**: 로직 시스템이 셰이더나 머티리얼을 직접 만지지 않고 인터페이스를 통해 연출 요청
- [ ] **Immutable Data**: 런타임에 원본 에셋을 수정하지 않고 전역 변수와 인스턴스 데이터만 갱신

---

## 6. QA 검증 및 테스트 가이드
* **컴파일 검사**: 유니티 에디터 컴파일 에러 0건
* **테스트 케이스**:
  1. **시간 정지 진입**: T키를 눌러 시간 정지에 들어가면 0.3초 동안 배경이 흑백으로 바뀌고, 타깃 물체와 플레이어는 원래 색을 유지하는지 확인
  2. **시간 정지 해제**: 다시 T키를 눌러 시간 정지를 풀면 원래의 풀컬러 화면으로 부드럽게 복구되는지 확인
  3. **물리 및 마법 작동**: 흑백 상태에서도 타깃 락온 및 마법 적용, 물리 충돌이 정상 동작하는지 확인
