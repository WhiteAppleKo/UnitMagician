# [02-2] 단위 마법 - 일반 전투 락온과 시간 정지 마법 락온 시스템 분리

## 1. 개요
* **목적**: 
    * 일반 상태에서 적만을 타겟팅하는 **일반 전투 락온(Combat Lock-On)**과, 시간 정지 상태에서 마법 변환이 가능한 대상만을 타겟팅하는 **마법 시전 락온(Magic Lock-On)**의 대상을 명확히 분리하여 락온 대상 혼선을 방지한다.
* **배경**:
    * 기존에는 일반 이동 락온에 사물 오브젝트가 섞여 들어가거나, 시간 정지 마법 락온에 마법 변환 컴포넌트가 없는 적이 섞이는 문제가 발생함.
    * 두 시스템의 타겟팅 조건과 역할을 엄격히 분리하여 완성도를 확보한다.

## 2. 세부 요구사항

### 1) 일반 상태 전투 락온
* **주체**: `LocomotionLogicSystem` (이동 및 기본 전투)
* **타겟팅 대상**: **오직 적 캐릭터(`CharacterStatComponent.IsEnemy() == true`)만 허용**
* **차단 대상**: 사물 오브젝트(`RuntimeDataUnitGroup`)는 일반 전투 락온 후보에서 **완전 제외**
* **작동 방식**: 
    * 플레이어 주변 25m 스캔 시 적대 캐릭터만 수집
    * 카메라 중심 시야각 + 플레이어 거리 가중치로 최적 적을 1순위 선정하여 락온 마커 점등 및 카메라 추적

### 2) 시간 정지 상태 마법 시전 락온
* **주체**: `AimLockOnCastingStrategy` (1인칭 / 3인칭 숄더뷰 시간 정지 마법)
* **타겟팅 대상**: **오직 마법 변환이 가능한 유효 대상만 허용**
    * `RuntimeDataUnitGroup` 컴포넌트를 보유하고 있어야 함
    * `IsTargetable == true` 상태여야 함
    * 현재 선택된 마법 단위(`CurrentSelectedUnit.UnitType`)를 지원(`HasUnit == true`)해야 함
* **차단 대상**: 
    * `RuntimeDataUnitGroup`이 없는 단순 캐릭터 및 비적대 캐릭터
    * `IsTargetable == false`인 사물
    * 선택된 마법 단위를 지원하지 않는 사물/캐릭터
* **작동 방식**:
    * 시간 정지(T키) 중 화면 중심 조준선(`SphereCast`)에 닿은 유효 마법 대상만 다중 락온 누적
    * 시간 정지 해제 시 락온된 대상에게 일괄 마법 변환 실행

## 5. QA 검증 및 테스트 가이드
* **컴파일 검사**: `dotnet build` 에러 0건
* **테스트 케이스**:
    * **일반 전투 락온 정상 동작**:
        * 일반 상태에서 적대 진영(`Enemy`) 캐릭터 조준/접근 시 일반 락온 마커가 정상 점등되는지 확인
        * 일반 상태에서 사물 오브젝트(`RuntimeDataUnitGroup`)에는 일반 락온 마커가 절대 점등되지 않는지 확인
        * 아군(`Ally`/`Player`) 및 중립 진영 캐릭터에는 일반 락온이 절대 걸리지 않는지 확인
    * **시간 정지 마법 락온 정상 동작**:
        * 시간 정지(T키) 중 마법 변환 가능 대상(`RuntimeDataUnitGroup` 보유 + `IsTargetable == true` + 선택 단위 보유) 조준 시 붉은색 마법 락온 마커가 점등되고 락온 목록에 누적되는지 확인
        * `RuntimeDataUnitGroup`이 없는 적 캐릭터를 조준했을 때는 마법 락온 마커가 일체 뜨지 않고 누적에서 제외되는지 확인
        * 현재 선택된 단위(예: `Mass`)를 지원하지 않는 사물/적 조준 시 마법 락온이 걸리지 않는지 확인
        * `IsTargetable == false`인 사물 조준 시 마법 락온이 걸리지 않는지 확인
        * 시간 정지 해제 시 유효하게 락온된 마법 대상들에게만 일괄 변환이 실행되고 마나가 정상 차감되는지 확인
        * 다중 락온 대상이 0개일 때 시간 정지 해제 시 마법 미발동 및 마나 미소모 확인
