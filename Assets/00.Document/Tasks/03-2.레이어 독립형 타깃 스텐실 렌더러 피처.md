# 03-2. 레이어 독립형 타깃 스텐실 렌더러 피처

## 1. 작업 개요 및 유형
* **기능 요약**: 유니티 기본 Render Objects의 레이어 강제 문제를 해결하고, 물체의 물리 레이어를 1%도 건드리지 않은 채 마법 대상과 플레이어에게만 스텐실 도장을 찍어주는 전용 렌더러 피처를 구현합니다.
* **작업 유형**: 시청각 영역 (렌더링 파이프라인 확장 및 그래픽 도장 자동화)

---

## 2. 핵심 요구사항 및 기술 분석

### 1) 핵심 요구사항
* **물리 레이어 100% 보존**: 지형, 장애물, 적, 플레이어의 기존 물리 레이어를 절대 변경하지 않습니다.
* **컴포넌트 기반 자동 도장**: 레이어가 아닌 마법 타깃 컴포넌트(`RuntimeDataUnitGroup`)와 플레이어 렌더러만 골라내어 스텐실 1번을 기록합니다.
* **비활성화 시 비용 제로**: 평소에는 연산을 완전히 끄고, 시간 정지 연출이 켜질 때만 스텐실 도장 패스를 실행하여 성능 낭비를 막습니다.

### 2) URP 커스텀 렌더러 피처 구조
1. **`TargetStencilRendererFeature`**:
   * URP 파이프라인에 등록되는 확장 컴포넌트입니다.
   * `After Rendering Opaques` 시점에 스텐실 도장 패스를 주입합니다.
2. **`TargetStencilPass`**:
   * 등록된 타깃 오브젝트들의 메쉬를 화면 색상 없이 스텐실 메모리에만 [값 = 1]로 기록합니다.
   * 벽 뒤에 숨은 물체는 가려지도록 기존 깊이 검사(`LessEqual`)를 적용합니다.
3. **`TargetStencilMask.shader`**:
   * 픽셀 색상 출력(`ColorMask 0`)을 완전히 꺼서 성능 부담이 없고, 스텐실 도장만 찍는 초경량 셰이더입니다.

---

## 3. 전체 렌더링 파이프라인 흐름

```
[1] 기본 씬 렌더링
    └─ 모든 배경과 물체가 기존 물리 레이어 그대로 풀컬러 렌더링됨
               ↓
[2] TargetStencilRendererFeature (커스텀 도장 패스)
    ├─ 물리 레이어 검사 없이, 타깃 목록의 메쉬만 가볍게 순회
    ├─ 색상 연산 없이 깊이 검사 통과 픽셀에 [스텐실 = 1] 기록
    └─ 벽 뒤에 숨은 부위는 깊이 검사로 도장 제외
               ↓
[3] Full Screen Pass (기본 내장 흑백 필터)
    ├─ 스텐실 == 1 (타깃) : 풀컬러 유지
    └─ 스텐실 != 1 (배경) : 흑백으로 덮어쓰기
               ↓
[최종 결과] 물리 레이어 깨짐 없이 타깃만 선명한 컬러 유지
```

## 4. DLV 아키텍처 파일 설계

### [D] 데이터 그룹
* **Pure Data**: `Assets/02.System/05.TimeSlowFilter/00.Data/PureDataStencilMask.cs`
  * 스텐실 참조 번호(기본 1), 렌더링 이벤트 시점(`AfterRenderingOpaques`) 보관

### [L] 로직 그룹
* **Logic System**: `Assets/02.System/05.TimeSlowFilter/01.Logic/TargetStencilService.cs`
  * 인터페이스 `ITargetStencilService` 구현
  * 씬에 존재하는 마법 타깃 렌더러 목록을 수집하고 렌더러 피처에 전달하는 가교 역할
  * MonoBehaviour 상속 배제, 순수 C# 서비스로 동작

### [V] 비주얼 그룹
* **Visual Feature**: `Assets/02.System/05.TimeSlowFilter/02.Visual/TargetStencilRendererFeature.cs`
  * URP 렌더러 피처 구현체
  * `PC_Renderer.asset`에 등록되어 스텐실 패스를 실행
* **Mask Shader**: `Assets/02.System/05.TimeSlowFilter/02.Visual/Shaders/TargetStencilMask.shader`
  * `ColorMask 0`, `ZWrite Off`, `ZTest LEqual`, `Stencil { Ref 1 Comp Always Pass Replace }` 초경량 셰이더
* **Mask Material**: `Assets/02.System/05.TimeSlowFilter/02.Visual/Shaders/M_TargetStencilMask.mat`
  * 렌더러 피처에서 사용할 도장 전용 머티리얼

## 5. DLV 3대 원칙 준수 확인
- [ ] **Everything is Data**: 스텐실 번호 및 패스 옵션을 Pure Data로 관리
- [ ] **Blind Logic**: 렌더러 피처와 로직이 구체 클래스 대신 인터페이스를 통해 대상을 식별
- [ ] **Immutable Data**: 런타임에 렌더러 피처 에셋 설정을 오염시키지 않고 메모리 패스로 안전 구동

---

## 6. QA 검증 및 테스트 가이드
* **컴파일 검사**: 유니티 에디터 컴파일 에러 0건
* **테스트 케이스**:
  1. **레이어 보존 검사**: 모든 타깃 물체(장애물, 적 등)의 인스펙터 레이어가 `Default`나 기존 레이어 그대로 유지되는지 확인
  2. **물리 충돌 유지**: 흑백 연출이 켜진 상태에서도 타깃 물체와 캐릭터의 물리 충돌, 마법 레이캐스트가 100% 정상 작동하는지 확인
  3. **스텐실 마스킹 검증**: 시간 정지 발동 시 물리 레이어가 그대로인 타깃들만 정확히 원래 색상을 유지하는지 확인
