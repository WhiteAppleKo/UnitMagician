HP 요구 사항
PureStatData안에 정의된 요소 중 하나
1. Clamp된 int 요소로 Min값에 도달한 경우 이벤트 발송해서 사망 사실을 알려야함.
2. Max Value를 조정할 수 있어야함.(최대 생명력 증가 및 감소)
3. Increase, Reduce 메서드가 정의되어 전투 시스템에서 CurrentValue를 조정할 수 있어야함.
4. Update가 아닌, 변화를 감지해(이벤트) CurrentValue가 반영되는 UI가 UI Toolkit을 통해 필요함

MP 요구 사항
PureStatData안에 정의된 요소 중 하나
UnitChangeService 스크립트에서 마나 소모 연산이 존재한다고 알고있는데 확인 후, 존재한다면 Player의 RuntimeStatData와 연동하여 계산할 것.
1. HP와 같은 Clamp 클래스를 상속 받으며 Min, Max, CurrentValue에 대한 데이터를 보유함
2. HP와 마찬가지로 Increase, Reduce를 가짐
3. HP와 다르게 Min값에 도달한 경우 이벤트를 발송하는 것이 아닌, 사용해야하는 마나가 100인데 100이 없을때, 마나가 모자랄 때 이벤트를 발송함
4. HP와 묶여서 CurrentValue가 반영되는 UI가 필요함. 

무기 슬롯 요구 사항
Weapon 클래스를 상속 받은 무기들을 보관 가능한 슬롯.
1. 캐릭터 입장에서 어떤 무기인지 알 필요 없음.
2. WeaponSlot에 Fire 클래스 호출 > 무기 사용 성공/실패 판정 진행 > 피드백 반환으로 이어지는 구조
3. 현재 구현된 UnitSystem의 단위 조작 마법들이 각각 하나의 Weapon으로 정의되면 좋을듯.
4. 플레이어가 사용되는 Weapon의 경우, CurrentWeapon 현재 장착된 마법에 대한 UI가 UI Toolkit으로 제작 되어야함.
