# 2026-08-12 UI Toolkit 설계 및 상호작용 가이드라인

## 1. 시각 영역 - 포인터 감지 영역 일치

> **원칙**: 실제 시각 형태 점유 영역만 포인터 감지 영역 설정.

### 상세 규칙
투명 패널, 빈 컨테이너, 불필요 여백 등 비노출 영역 클릭 방해 차단.

### 권장 설정
입력 불필요 투명 패널 / 레이아웃 요소: `Picking Mode` -> `Ignore` 설정.

---

## 2. UI - 인게임 상호작용 분리

> **원칙**: 마우스 클릭 입력 UI 클릭 또는 인게임 월드 상호작용 중 단일 역할 수행.

### 상세 규칙
UI 클릭 시 백그라운드 레이캐스트 중복 발생 차단.

### 구현 표준 (Unity 6 / New Input System)
1. 씬 내 `EventSystem` 배치 (`InputSystemUIInputModule` 탑재).
2. 레이캐스트 실행 최상단 `EventSystem.current.IsPointerOverGameObject()` 검사.
3. UI 감지 시 레이캐스트 실행 중단.

### 구현 예시

```csharp
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.InputSystem;

public class PlayerInteraction : MonoBehaviour
{
    [SerializeField] private Camera mainCamera;

    public void OnPrimaryAction(InputAction.CallbackContext context)
    {
        // 1. 입력 시작 순간 처리
        if (!context.started) return;

        // 2. UI 요소 검사 및 인게임 레이캐스트 차단
        if (EventSystem.current != null && EventSystem.current.IsPointerOverGameObject())
        {
            return; 
        }

        // 3. 인게임 월드 상호작용 실행
        PerformInGameRaycast();
    }

    private void PerformInGameRaycast()
    {
        Ray ray = mainCamera.ScreenPointToRay(Mouse.current.position.ReadValue());
        if (Physics.Raycast(ray, out RaycastHit hit))
        {
            // 월드 오브젝트 상호작용 로직
        }
    }
}
```
