* **날짜**: 2026-08-12

## 2. 문제 · 변경 · 성과 (Before - After + Why)

### 2-1. UI Toolkit 상호작용 및 3D 레이캐스트 간섭 차단
* **Before**: 화면 우측 상단 `APPLY VECTOR` UI 버튼 클릭 시 3D 레이캐스트가 동시에 발동되어 조준 방향이 우측 상단으로 오염되는 현상 및 기존 uGUI `EventSystem.current.IsPointerOverGameObject()` 사용 시 UI Toolkit 패널 미감지 문제 발생.
* **After**: UI Toolkit 순수 표준 API (`rootVisualElement.pickingMode = PickingMode.Ignore`, `panel.Pick(RuntimePanelUtils.ScreenToPanel(...))`) 적용 및 UI 가이드라인 3항(가변형 UI) 반영 (`PointerDownEvent`, `PointerMoveEvent`, `PointerUpEvent`, `BringToFront()`, USS `style.translate` 이동, `Mathf.Clamp` 화면 이탈 방지).
* **Why**: UI 조작과 3D 월드 조준 레이캐스트의 역할을 100% 명확히 분리하여 조준 오염을 차단하고 팝업 창의 자유로운 드래그 이동을 보장하기 위함.

### 2-2. 3D Ghost Preview 컴포넌트 의존성 제거 트러블슈팅
* **Before**: 고스트 클론 복제 시 물리/충돌체 컴포넌트 삭제 과정에서 `Can't remove RuntimeDataUnitGroup because UnitTargetLogicSystem depends on it` 유니티 에러 발생.
* **After**: `StripPhysicsComponents()` 내부 컴포넌트 및 MonoBehaviour 스크립트 삭제 알고리즘을 의존성 역순(Reverse Loop) 방식으로 전환.
* **Why**: `RequireComponent`로 결합된 종속 스크립트(`UnitTargetLogicSystem`)를 피의존 컴포넌트(`RuntimeDataUnitGroup`)보다 먼저 안전하게 제거하여 엔진 삭제 차단 에러를 근본적으로 해결하기 위함.

### 2-3. CharacterSystem `RuntimeStatData.MP` & `UnitMagicPipeLine` 연동
* **Before**: 마법 발동 시 파이프라인 검증 없이 직접 물리 수치를 적용하거나 `CasterStatData` 전달 누락으로 파이프라인 마나 검증 실패 및 MP 바 미감소 현상 발생.
* **After**: `UnitMagicContext`에 플레이어 `RuntimeStatData`를 전달하고 `ManaCheckStep`에서 `CasterStatData.TryConsumeMP(RequiredMana)`를 실시간 실행. MP 차감 시 `mp.OnValueChanged` 전파를 통해 `CharacterHUDUIView` MP 바 및 텍스트 즉시 연동 감소 반영.
* **Why**: 플레이어 캐릭터의 런타임 자원(MP)과 단위 마법 시스템, HUD UI 뷰 간의 데이터 흐름을 100% 동기화하고 자원 부족 시 마법 발동을 안전하게 차단하기 위함.

## 3. 상세 사용 가이드

### 3-1. Vector Gizmo 조준 및 마법 발동
1. 타깃 오브젝트 마법 발동 조준 시 `UnitVectorGizmoUIComponent` 팝업 창 표시.
2. 팝업 창 제목 영역 드래그 시 USS `translate` 기반 창 위치 이동 가능 (화면 밖 이탈 자동 차단).
3. 마우스 클릭 위치 기준 3D 조준 방향 및 슬라이더 속도 조절 후 `APPLY VECTOR` 클릭.
4. `UnitMagicPipeLine` (`ManaCheckStep` -> `TargetValidStep` -> `ApplyUnitChangeStep`) 순차 비동기 파이프라인 실행.
5. 플레이어 MP 차감 및 `CharacterHUDUIView` 상단 MP 바 실시간 감소 표출.

## 4. 문제 재현 및 검증 방법
1. **마나 차감 디버그 확인**: 유니티 씬 실행 후 마법 발동 시 유니티 콘솔 창에서 `<color=cyan>[RuntimeStatData] MP Consumed: ...</color>` 및 `<color=green>[ManaCheckStep] MP Deducted Successfully! ...</color>` 로그 출력 확인.
2. **마나 부족 차단 확인**: 플레이어 MP 수치보다 큰 `RequiredMana` 요구 시 `<color=red>[ManaCheckStep] Insufficient Mana ...</color>` 경고 로그와 함께 마법 발동 100% 차단 확인.
