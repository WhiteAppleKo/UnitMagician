# [일일 작업 일지]2026-08-10

## 작업 개요
Unit System 비트 플래그 아키텍처 개편. 
질량-스케일 연산 무결성 확보 및 자동 굽기(Bake) 시스템 구축.

## 문제·변경·성과 (Before-After + Why)

### 1. 비트 플래그 기반 다중 선택 구조 개편
* **Before**: `List` 기반 단위 추가 구조. 각 단위별 수동 수치 기입 번거로움 존재.
* **Why**: 다중 속성(질량, 부피 동시 보유 등) 객체 관리 편의성 극대화 목적. 검증 로직 최적화.
* **After**: `UnitType` 내부 `[System.Flags]` 적용. `RuntimeDataUnitGroup` 내부 리스트 삭제. 단일 체크박스 플래그 변수 교체.

### 2. 질량 굽기(Bake) 자동화 툴 생성
* **Before**: 객체 초기 질량값 에디터 인스펙터 수동 기입.
* **Why**: 게임 실행 실시간 부피 연산 부하 제거. 씬 배치 객체 실제 부피(Volume) 기반 정확한 질량 자동 산출 목적.
* **After**: `UnitMassBaker` 에디터 툴 신규 제작. (Mesh 순수 크기 * Transform.lossyScale) 기반 정확한 월드 부피 도출. 직렬화 변수(`bakedMassValue`) 자동 저장 구현.

### 3. 질량 마법 스케일 왜곡 버그 수정
* **Before**: 마법 피격 시 비율(목표 질량 / 원본 질량) 도출 후 물체 스케일 직접 곱셈 적용. 부피 기하급수적 파괴(밀도 붕괴) 증상 유발.
* **Why**: 물리적 밀도 보존 및 시각적 부피 정상 확장을 위해 선형 길이 비율(세제곱근) 적용 필수.
* **After**: `MassUnitApplicatorSO` 내부 비율 세제곱근 연산(`Mathf.Pow(ratio, 1f/3f)`) 로직 교체. 물리 질량 및 시각 크기 무결성 완벽 동기화 달성.

## 상세 사용 가이드
1. 타겟 객체 인스펙터 진입.
2. `RuntimeDataUnitGroup` 컴포넌트 내부 `Supported Units` 플래그 속성 체크. (Mass, Volume 등 다중 선택)
3. 에디터 상단 메뉴 `Tools` -> `UnitMagician` -> `Bake Mass Values` 클릭.
4. 콘솔 로그 굽기 성공 메세지 확인. 씬 배치 형태 기준 질량 세팅 자동 완료 확인.

## 문제 재현 방법 (수정 전 축소 버그 원리)
1. 큐브(순수 크기 1) 생성. 인스펙터 스케일 50 강제 팽창 배치.
2. 타겟 목표 마법 질량 2배 공격 적용.
3. (수정 전 Baker 결함): 객체 로컬 스케일 50 무시. 원본 부피 1 추출.
4. (수정 전 Applicator 결함): 부피 스케일 비율 변환 없이 단순 곱셈 연산 강행. 
5. 관측 결과: 스케일 50 큐브 객체 -> 스케일 1.26 극단적 축소 발생. (유저 제보 수치 26 오타 발생 원인)
6. (현재 해결 상태): lossyScale 곱셈 및 세제곱근 수학 공식 완벽 도입. 스케일 63 팽창 정상 도출 완료.
