# 06. InteractionSystem (상호작용 시스템)

---

## 1. VContainer 주입 관계

```mermaid
classDiagram
    direction TB

    class InteractionSystemLifetimeScope {
        +Configure(IContainerBuilder builder)
    }

    class InteractionSystem {
        -CharacterDamagePipeLine damagePipeLine
        -UnitMagicPipeLine unitMagicPipeLine
        +InteractionSystem(CharacterDamagePipeLine, UnitMagicPipeLine)
    }

    class CollisionDamageTrigger {
        -IInteractionService interactionService
        -int baseDamage
        -GameObject owner
        +Construct(IInteractionService interactionService)
    }

    class IInteractionService {
        <<interface>>
        +ProcessDamageAsync(DamageContext context) UniTask
        +ProcessUnitMagicAsync(UnitMagicContext context) UniTask
        +event Action~DamageContext~ OnDamageProcessed
    }

    InteractionSystemLifetimeScope ..> InteractionSystem : Register Scoped (As IInteractionService, AsSelf)
    InteractionSystem ..|> IInteractionService
    CollisionDamageTrigger --> IInteractionService : 메서드 주입 (Construct)
```

---

## 2. 데이터 흐름 및 호출 시퀀스

```mermaid
sequenceDiagram
    autonumber
    actor TargetObj as 충돌체
    participant CDT as CollisionDamageTrigger
    participant IS as InteractionSystem
    participant PIPE as CharacterDamagePipeLine
    participant STAT as CharacterStatComponent

    TargetObj->>CDT: OnTriggerEnter(Collider other)
    CDT->>CDT: 쿨다운 및 피격 대상 레이어 검증
    CDT->>CDT: DamageContext 데이터 객체 생성
    CDT->>IS: ProcessDamageAsync(context)
    IS->>PIPE: Run(context) 비동기 파이프라인 가동
    PIPE->>PIPE: 방어력 계산 및 크리티컬 연산 수행
    PIPE-->>IS: 최종 연산 결과 주입 (context.FinalDamage)
    IS->>STAT: TakeDamage(context.FinalDamage)
    STAT->>STAT: 체력 감소 및 사망 여부 판정
    IS-->>CDT: OnDamageProcessed 이벤트 발행
```

## 3. 인터페이스 명세 및 Public 메서드 연결점

```mermaid
classDiagram
    class IInteractionService {
        <<interface>>
        +event Action~DamageContext~ OnDamageProcessed
        +event Action~DamageContext~ OnHealProcessed
        +event Action~UnitMagicContext~ OnUnitMagicProcessed
        +ProcessDamageAsync(DamageContext context) UniTask
        +ProcessUnitMagicAsync(UnitMagicContext context) UniTask
    }

    class CollisionDamageTrigger {
        +SetOwner(GameObject newOwner) void
        +SetBaseDamage(int damage) void
        +Initialize(IInteractionService service) void
    }
```

### 연결 매핑 테이블
| 호출 주체 (Caller) | 공개 메서드 / 프로퍼티 (Public API) | 수신 주체 (Callee) | 전달/반환 데이터 (Payload) | 비고 |
|---|---|---|---|---|
| CollisionDamageTrigger | `IInteractionService.ProcessDamageAsync(context)` | InteractionSystem | `DamageContext context` | 물리 충돌 피해 연산 요청 |
| UnitChangeService | `IInteractionService.ProcessUnitMagicAsync(context)` | InteractionSystem | `UnitMagicContext context` | 단위 변경 파이프라인 처리 |
| UnitChangeService | `CollisionDamageTrigger.SetOwner(GameObject)` | CollisionDamageTrigger | `GameObject caster` | 마법으로 변환된 물체의 소유권 이전 |

---

## 4. 아키텍처 점검 사항
- `InteractionSystem.ProcessDamageAsync` 진입부에 `await UniTask.Yield();`가 배치되어 있어, 물리 충돌 판정이 다음 프레임으로 지연되는 런타임 지연 병목이 존재합니다.
- 정밀한 물리 반응이 필요한 경우 동기 연산 경로 또는 즉시 평가 구조로의 보완이 검토되어야 합니다.
