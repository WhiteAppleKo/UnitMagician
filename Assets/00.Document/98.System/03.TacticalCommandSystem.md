```mermaid
    TacticalCommandLifetimeScope ..> TacticalCommandLogicSystem : RegisterEntryPoint Scoped (As IInitializable, ITickable, IDisposable)
    TacticalCommandLifetimeScope ..> RuntimeDataTacticalQueue : Register Scoped
    TacticalCommandLifetimeScope ..> ITacticalCommandVisualizer : RegisterComponent (From Hierarchy)

    TacticalCommandLogicSystem --> RuntimeDataTacticalQueue : 생성자 주입
    TacticalCommandLogicSystem --> ITacticalCommandVisualizer : 생성자 주입
```

## 2. 데이터 흐름 및 호출 시퀀스

```mermaid
sequenceDiagram
    autonumber
    actor Player as 플레이어
    participant ICM as InputContextManager
    participant TCLS as TacticalCommandLogicSystem
    participant RD_Q as RuntimeDataTacticalQueue
    participant VIS as TacticalCommandVisualizer
    participant UCHG as UnitChangeService

    Note over TCLS: 시간 정지 활성화 상태
    TCLS->>ICM: PushContext(TacticalContext)
    ICM->>ICM: 마우스 커서 표시 및 잠금 해제
    
    Player->>TCLS: 마우스 호버 및 대상 좌클릭
    TCLS->>TCLS: Raycast 대상 탐색 (TargetRuntimeData 검증)
    TCLS->>RD_Q: Enqueue(새로운 전술 명령 생성)
    RD_Q-->>TCLS: OnQueueChanged 이벤트 발행
    TCLS->>VIS: DrawTrajectory 및 마커 갱신
    
    Player->>TCLS: 시간 정지 해제 (T 키 입력)
    TCLS->>ICM: PopContext(TacticalContext)
    TCLS->>RD_Q: Dequeue 순차 실행
    loop 대기열 명령 처리
        RD_Q-->>TCLS: TacticalCommandData 인출
        TCLS->>UCHG: ChangeUnit(...) 호출
        UCHG->>UCHG: 단위 변경 및 마법 파이프라인 가동
    end
    TCLS->>VIS: ClearAllVisuals()
```

## 3. 인터페이스 명세 및 Public 메서드 연결점

```mermaid
classDiagram
    class RuntimeDataTacticalQueue {
        +IReadOnlyList~TacticalCommandData~ Commands
        +bool IsTacticalMode
        +event Action OnQueueChanged
        +Enqueue(TacticalCommandData command) void
        +Dequeue() TacticalCommandData
        +RemoveLast() bool
        +Clear() void
        +SetTacticalMode(bool isTactical) void
    }

    class ITacticalCommandVisualizer {
        <<interface>>
        +DrawQueueVisuals(IReadOnlyList~TacticalCommandData~ commands) void
        +SetHoverTarget(GameObject target) void
        +ClearAllVisuals() void
    }
```

### 연결 매핑 테이블
| 호출 주체 (Caller) | 공개 메서드 / 프로퍼티 (Public API) | 수신 주체 (Callee) | 전달/반환 데이터 (Payload) | 비고 |
|---|---|---|---|---|
| TacticalCommandLogicSystem | `RuntimeDataTacticalQueue.Enqueue(TacticalCommandData)` | RuntimeDataTacticalQueue | `TacticalCommandData` (대상, 마법, 수치) | 명령 대기열 등록 |
| TacticalCommandLogicSystem | `RuntimeDataTacticalQueue.RemoveLast()` | RuntimeDataTacticalQueue | 반환 `bool` (제거 성공 여부) | 우클릭 탭 시 마지막 명령 취소 |
| TacticalCommandUIView | `RuntimeDataTacticalQueue.Commands` | RuntimeDataTacticalQueue | 반환 `IReadOnlyList<TacticalCommandData>` | 전술 큐 HUD 렌더링 |
| TacticalCommandLogicSystem | `ITacticalCommandVisualizer.DrawQueueVisuals(...)` | TacticalCommandVisualizer | `IReadOnlyList<TacticalCommandData>` | 전술 궤적 및 핀 시각화 |

## 4. 아키텍처 점검 사항
- `TacticalCommandLogicSystem`에서 형제 스코프 컴포넌트인 `CameraFollowVisualizer`, `UnitQuickSlotUIComponent`, `UnitCasterSystem`을 `FindAnyObjectByType`으로 씬 역조회하고 있습니다.
- 상위 부모 스코프나 중계 인터페이스를 통해 VContainer 정식 주입 경로로 전환해야 합니다.
