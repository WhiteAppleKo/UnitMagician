## 1. VContainer 주입 관계

```mermaid
classDiagram

        -PureDataCameraSetting m_cameraSetting

    }

    class ICameraFollowService {
        <<interface>>
        +SetEventTargetOverride(bool active)
        +SetRequireRightClickToRotate(bool require)
        +TryGetEventCameraPose(Vector3 playerPosition, out Vector3 eyePosition, out Quaternion lookRotation) bool
        +IsEventTargetOverrideActive bool
        +CurrentTargetPosition Vector3
        +CurrentLookAngles Vector2
    }

    class IEventCameraLookTarget {
        <<interface>>
        +TryGetPosition(out Vector3 position) bool
    }

    class EventProjectileLookTarget {
        +Bind(IEventFlightTracker flightTracker)
    }

    LocomotionLifetimeScope ..> CameraFollowService : RegisterEntryPoint Singleton (As ICameraFollowService, ILateTickable)
    LocomotionLifetimeScope ..> LocomotionLogicSystem : RegisterEntryPoint Singleton (As ITickable)

    CameraFollowService ..|> ICameraFollowService
    CameraFollowService ..> IEventCameraLookTarget : 생성자 주입 (이벤트 투사체 위치 값)
    EventProjectileLookTarget ..|> IEventCameraLookTarget
    LocomotionLifetimeScope ..> EventProjectileLookTarget : Register Singleton (AsSelf, As IEventCameraLookTarget) + Start()에서 09의 IEventFlightTracker 사후 배선(Bind)
```

## 2. 데이터 흐름 및 호출 시퀀스

```mermaid
sequenceDiagram

    User->>IR: 마우스 이동 입력 (Look Delta)
    IR->>CFS: 마우스 델타 데이터 축적
    Note over CFS: LateUpdate 프레임 도달
    CFS->>ICM: CurrentContext 조회
    alt UI 컨텍스트 활성화 상태

        CFS-->>CFS: OnLookAnglesChanged 이벤트 발행
```

### 연결 매핑 테이블
| 호출 주체 (Caller) | 공개 메서드 / 프로퍼티 (Public API) | 수신 주체 (Callee) | 전달/반환 데이터 (Payload) | 비고 |
|---|---|---|---|---|
| TacticalCommandLogicSystem | `ICameraFollowService.SetRequireRightClickToRotate(bool)` | CameraFollowService | `bool require` (우클릭 회전 필수 여부) | 시간 정지 모드 시점 회전 제한 |
| EventCameraTriggerLogicSystem | `ICameraFollowService.SetEventTargetOverride(bool)` | CameraFollowService | `bool active` (이벤트 대상 오버라이드 ON/OFF) | 3단계 이벤트 카메라(이벤트 전용 1인칭 vcam으로 전환, 22번 §10) |
| CameraFollowVisualizer | `ICameraFollowService.OnEventTargetOverrideChanged` / `TryGetEventCameraPose(playerPosition, out eye, out lookRotation)` | CameraFollowService | `bool active` / 눈 위치 `Vector3` + 시선 `Quaternion`(눈→투사체) | 오버라이드 ON이면 이벤트 1인칭 vcam 우선순위 승격(숄더 100 < 이벤트 200) + `CinemachineBrain.DefaultBlend`(=`EventCameraBlendTime`) 설정, 매 프레임 이벤트 vcam 트랜스폼에 눈 위치/시선 적용, 블렌드 종료 후 몸 렌더러 ShadowsOnly. 숄더 피벗은 항상 `player+1.4`·플레이어 시선각 기준 |
| CameraFollowService | `IEventCameraLookTarget.TryGetPosition(out Vector3)` | EventProjectileLookTarget | 반환 `bool` + 투사체 위치 `Vector3`(09 `IEventFlightTracker.ProjectilePosition`) | 오버라이드 중 `TryGetEventCameraPose`가 매 프레임 눈→투사체 시선 계산(사후 배선: 09가 다른 스코프 트리) |
| (삭제) UnitCasterSystem | — | — | — | 숄더뷰 고정으로 카메라 모드별 시전 전략 교체 제거(마법 락온은 항상 MagicLockOnComponent 경로) |
| LocomotionLogicSystem | `ILockOnController.IsLockOnActive` | PlayerLockOnController | 반환 `bool` | 전투 락온 중 이동 방향 고정 |

## 4. 아키텍처 점검 사항

1. **공개 프로퍼티의 중복 노출 및 인터페이스 오염**
   - `CameraFollowService.cs`: 과거 레거시 호환성을 위해 `CurrentTargetPosition`과 `TargetPosition`, `CurrentLookAngles`와 `LookAngles`가 동시에 선언되어 있습니다. 이로 인해 동일한 상태값을 읽는 호출자마다 다른 프로퍼티를 사용하여 코드 일관성이 훼손됩니다.

2. **정적 싱글톤 의존으로 인한 의존성 역전 원칙 위배**
   - `CameraFollowService`의 `LateTick()` 루프 내에서 `InputContextManager.Instance?.CurrentContext`를 직접 조회하고 있습니다.
   - VContainer가 관리하는 순수 C# 서비스임에도 정적 프로퍼티를 통해 의존성을 직접 꺼내오는 안티패턴이 잔존합니다.

3. **입력 이벤트 다중 소비 및 간섭 가능성**
   - 마우스 휠 스크롤(`onMouseWheelScrolled`)을 카메라 서비스(줌 조절)와 단위 퀵슬롯(슬롯 전환)이 동시에 구독하고 있어, 모드 전환 시 이벤트 실행 순서가 꼬일 위험이 있습니다.
