# 03. 범용 파이프라인 일반화 및 비동기 연산 코드 작업 기획서 (PipeLine Generalization Plan)

* **작업 목표**: 기존 `Assets/PipeLine` 전투 전용 파이프라인 구조를 프로젝트 범용 비동기 파이프라인 아키텍처(`UniTask` 기반 제네릭 `PipeLineSo<TContext>`)로 일반화 재설계 및 피격/단위마법 도메인 확장 명세
* **저장 위치**: `Assets/00.Document/01.DEV/03.PipeLine_Generalization_Plan.md`

* **작업 분류**:
  * **비시청각 영역**: Pure Data (`DamageContext`, `UnitMagicContext`), Core Pipeline Logic (`PipeLineSo<T>`, `IPipeLineStep<T>`, `CharacterDamagePipeLine`, `UnitMagicPipeLine`)
  * **시청각 영역**: 파이프라인 수치 반영 연출 수신 (`ApplyDamageStep`, `ApplyUnitChangeStep` 시각 피드백 수신 연동)

## 2. 유형별 맞춤 핵심 요구사항

### 2-1. 비시청각 영역 요구사항 (공식: [구현 수단 / 방법] + [최적화 / 기대 효과])

* **제네릭 파이프라인 일반화**: `UniTask<TContext>` 비동기 연산 인터페이스 `IPipeLineStep<TContext>` 및 제네릭 `PipeLineSo<TContext>` 상속 구조로 구현하여 전투 이외 단위 마법, 퀘스트, 상태 이상 연산까지 동일 구조로 확장 보장
* **단계별 중단 제어 최적화**: `ShouldBreak(context)` 조건 검증 로직으로 구현하여 회피 발생, 마나 부족 등 실패 조건 감지 시 불필요한 하위 스텝 계산을 무효화하고 불필요 연산 부하 방지
* **캐릭터 피격 파이프라인 구축**: `CharacterDamagePipeLine` (`EvasionStep` → `CriticalStep` → `DefenseStep` → `ApplyDamageStep`) 순차 스텝 구조로 구현하여 명중률, 크리티컬, 방어력 계산 정확성 확보 및 HP 차감/사망 이벤트 자동 연결
* **단위 마법 파이프라인 구축**: `UnitMagicPipeLine` (`ManaCheckStep` → `TargetValidStep` → `ApplyUnitChangeStep`) 순차 스텝 구조로 구현하여 마나 수치 검증/차감 실패 시 단위 변환 차단 및 자원 연산 입출력 안정성 보장

### 2-2. 시청각 영역 요구사항 (사용자 행동 입력에 따른 실질적 동작 및 결과)

* **피격 데미지 텍스트 반응**: 사용자 공격 입력 후 피격 파이프라인 `ApplyDamageStep` 완료 시 피격 대상 캐릭터 위치에 피격 데미지 수치 Floating Text가 실시간으로 표출된다.
* **회피 연출 반응**: 피격 파이프라인 `EvasionStep` 회피 판정 성공 시 피격 대상 머리 위 "회피(Evade)" 텍스트 피드백이 실시간 연출 처리된다.
* **마나 부족 피드백 반응**: 단위 마법 파이프라인 `ManaCheckStep` 마나 부족 판정 시 화면 중앙 "마나 부족" 경고 UI 및 마나 바 진동 연출이 즉시 반응한다.

## 3. DLV 아키텍처 설계 명세

```
[ Data Layer ]          ↔       [ Logic Layer ]          ↔       [ Visual Layer ]
- DamageContext                  - IPipeLineStep<TContext>        - DamageFloatingText
- UnitMagicContext               - PipeLineSo<TContext>           - EvadeTextEffect
- PipeLineSoBase                 - CharacterDamagePipeLine        - InsufficientManaWarningUI
                                 - UnitMagicPipeLine              - UnitChangeEffectVisualizer
```

### 3-1. Data Layer (데이터 레이어)
* **`DamageContext` (Class)**:
  * `BaseCharacter attacker`, `BaseCharacter victim`, `int rawDamage`, `bool isEvaded`, `bool isCritical`, `int finalDamage`
* **`UnitMagicContext` (Class)**:
  * `BaseCharacter caster`, `GameObject targetObject`, `Weapon magicWeapon`, `int requiredMana`, `bool isSuccess`
* **`PipeLineSoBase` (Abstract ScriptableObject)**:
  * 최상위 에디터 직렬화 베이스 클래스 (`List<IPipeLineStep<T>> steps`)

### 3-2. Logic Layer (로직 레이어)
* **`IPipeLineStep<TContext>` (Interface)**:
  * `UniTask<TContext> Execute(TContext context)` (단일 실행 단계)
* **`PipeLineSo<TContext>` (Abstract Class)**:
  * `UniTask<TContext> Run(TContext context)` (순차 실행기, `ShouldBreak` 검증)
* **`CharacterDamagePipeLine`**:
  * `EvasionStep`: 명중률(`acc` - `eva`) 회피 연산
  * `CriticalStep`: 크리티컬(`crt`) 수치 계산
  * `DefenseStep`: 방어율(`def`) 차감 계산
  * `ApplyDamageStep`: victim `RuntimeStatData.HP` 차감 및 `OnDeath` 발송
* **`UnitMagicPipeLine`**:
  * `ManaCheckStep`: caster `RuntimeStatData.MP` 수치 검증/차감
  * `TargetValidStep`: target `UnitChangeableComponent` 확인
  * `ApplyUnitChangeStep`: 수치/단위 변환 연산 수행

### 3-3. Visual Layer (시청각 레이어)
* **`DamageFloatingText`**: 피격 수치 및 크리티컬 Floating Text 표출
* **`EvadeTextEffect`**: 회피 발생 텍스트 표출
* **`InsufficientManaWarningUI`**: 마나 부족 시 UI 경고 팝업 및 진동 연출
* **`UnitChangeEffectVisualizer`**: 단위 변환 적용 시 셰이더 및 시각 효과 연출

## 4. 예상 검수 방법 및 테스트 가이드

### 4-1. 회피 및 중단(ShouldBreak) 검수
* **테스트 항목**: 타깃 회피율 100% 설정 후 `CharacterDamagePipeLine` 실행
* **검증 기준**: `EvasionStep`에서 `isEvaded = true` 판정 시 이후 `CriticalStep`, `DefenseStep`, `ApplyDamageStep` 연산이 실행되지 않고 즉시 중단되는지 확인

### 4-2. 마나 검증 및 차감 파이프라인 검수
* **테스트 항목**: 마나 부족 상태(MP < requiredMana)에서 `UnitMagicPipeLine` 발동
* **검증 기준**: `ManaCheckStep`에서 파이프라인 중단 처리 확인, MP 차감 0 발생 및 마나 부족 경고 UI 표출 확인

### 4-3. UniTask 비동기 체이닝 검수
* **테스트 항목**: 연속 100회 파이프라인 비동기 `Run()` 호출 실행
* **검증 기준**: 비동기 체이닝 동작 중 데드락(Deadlock) 및 가비지 컬렉션(GC) 할당 누수 없이 정상 완료되는지 확인
