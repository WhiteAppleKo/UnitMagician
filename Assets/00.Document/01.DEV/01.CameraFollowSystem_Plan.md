# 01. 카메라 팔로우 및 동적 줌 시스템 코드 작업 기획서 (Camera Follow System Plan)

---

## 1. 작업 개요 및 유형 분류

* **작업 목표**: 3D 쿼터뷰 Cinemachine 기반 플레이어 추적, 마우스 가중치 뷰포트 연산, 마우스 커서 기준 동적 줌 시스템 세부 코드 설계
* **저장 위치**: `Assets/00.Documents/01.DEV/01.CameraFollowSystem_Plan.md`
* **작업 분류**:
  * **비시청각 영역**: Pure Data (`CameraSettingSO`), Logic System (`CameraFollowService`, `MouseWorldPositionProvider`), VContainer DI
  * **시청각 영역**: Cinemachine Virtual Camera, Lens Distance/FOV Zoom Effect, Target Offsets

---

## 2. 유형별 맞춤 핵심 요구사항

### 2-1. 비시청각 영역 요구사항 (공식: [구현 수단 / 방법] + [최적화 / 기대 효과])

* **시야 자동 확장 연산**: 플레이어 위치와 마우스 3D 월드 좌표의 가중 평균 지점(`Vector3.Lerp(PlayerPos, MouseWorldPos, mouseWeight)`)을 카메라 타깃 위치로 실시간 연산하는 보간 알고리즘 구조로 구현하여 마우스 조준 방향 시야 자동 확장 및 전투 쾌적성 극대화
* **부드러운 카메라 추적**: Cinemachine Virtual Camera 댐핑(Damping) 보간 연산 및 `Vector3.SmoothDamp` 구조로 구현하여 플레이어 캐릭터 이동 및 가속 시 카메라 뷰포트 화면 떨림(Jittering) 현상 차단 및 부드러운 시점 유지
* **마우스 방향 줌 연산**: 마우스 휠 조작 시 `Camera.main.transform` 뷰포트 오프셋 이동 및 Cinemachine Lens OrthographicSize/FOV 연동 줌 보간 구조로 구현하여 마우스 커서 방향 줌인 시 시야 이탈 없는 부드러운 카메라 구도 유지
* **동적 타깃 결합도 최소화**: 카메라 추적 타깃 지정 구조를 VContainer `ICameraFollowService` 인터페이스 주입 아키텍처로 구현하여 플레이어 캐릭터 동적 스폰/리스폰 시 런타임 카메라 타깃 변경 유연성 및 모듈성 향상

### 2-2. 시청각 영역 요구사항 (사용자 행동 입력에 따른 실질적 동작 및 결과)

* **마우스 조준 시야 이동**: 사용자가 마우스 커서를 특정 방향으로 이동 조작 시 플레이어 캐릭터와 마우스 커서 사이 25% 지점으로 카메라 시야 오프셋이 자연스럽게 가중 이동한다.
* **마우스 커서 방향 줌인/줌아웃**: 사용자가 마우스 휠 조작 시 마우스 커서가 가리키는 3D 월드 지점을 중심으로 카메라 시야가 부드럽게 줌인(Zoom In) 및 줌아웃(Zoom Out) 연출 처리된다.
* **시간 감속 조작 연동 줌 연출**: 사용자가 시간 감속(마우스 우클릭) 발동 조작 시 카메라 Lens 시야각이 15% 감속 강조 줌인 처리되어 몰입감이 상승한다.

## 3. DLV 아키텍처 설계 명세

```
[ Data Layer ]          ↔       [ Logic Layer ]          ↔       [ Visual Layer ]
- CameraSettingSO                - ICameraFollowService            - CinemachineVirtualCamera
                                 - CameraFollowService             - MainCamera (Camera.main)
                                 - MouseWorldPositionProvider      - CinemachineBrain
```

### 3-1. Data Layer (데이터 레이어)
* **`CameraSettingSO` (ScriptableObject)**:
  * `float mouseWeight`: 0.25f (마우스 커서 시야 가중치)
  * `float followSmoothTime`: 0.15f (카메라 보간 댐핑 시간)
  * `float minZoom`: 5f (최소 줌 거치)
  * `float maxZoom`: 15f (최대 줌 거리)
  * `float zoomSpeed`: 2.0f (마우스 휠 줌 감도)

### 3-2. Logic Layer (로직 레이어)
* **`ICameraFollowService` (Interface)**:
  * `void SetTarget(Transform target)` (추적 타깃 설정)
  * `void UpdateCameraOffset(Vector2 mouseInput, float wheelDelta)` (마우스 뷰포트 연산 갱신)
* **`CameraFollowService` (Implementation - VContainer `Lifetime.Singleton`)**:
  * 마우스 3D Raycast 좌표 연산 (`MouseWorldPositionProvider` 주입 수신)
  * 플레이어-마우스 가중 평균 지점(`TargetPivot`) 실시간 보간 계산
  * `unscaledDeltaTime` 기반 마우스 커서 방향 줌 보간 수치 계산
* **`MouseWorldPositionProvider`**:
  * 마우스 화면 좌표 → 3D 월드 지형 평면(Plane) Raycast 교차점 3D 좌표 변환 연산자

### 3-3. Visual Layer (시청각 레이어)
* **`CinemachineVirtualCamera`**:
  * Cinemachine Transposer (3D 쿼터뷰 고정 각도 오프셋 세팅)
  * `Follow` 속성 → `CameraFollowService` 계산 `TargetPivot Transform` 런타임 수동 바인딩
* **`CinemachineBrain`**:
  * Main Camera 렌더링 파이프라인 수신 및 최종 뷰포트 출력

## 4. 예상 검수 방법 및 테스트 가이드

### 4-1. 마우스 조준 방향 시야 가중치 검수
* **테스트 항목**: WASD 이동 중 마우스 커서를 화면 외곽 4방향 이동
* **검증 기준**: 플레이어 캐릭터가 화면 중심을 벗어나지 않는 선에서 마우스 커서 방향으로 카메라 뷰포트가 25% 가중 이동하는지 확인

### 4-2. 마우스 커서 방향 줌인/줌아웃 검수
* **테스트 항목**: 마우스 커서를 특정 오브젝트 위에 올린 후 마우스 휠 조작
* **검증 기준**: 마우스 커서 3D 월드 지점으로 시선이 당겨지며 부드럽게 줌인/줌아웃 처리되는지 확인

### 4-3. 카메라 화면 떨림(Jittering) 검수
* **테스트 항목**: 플레이어 최고 이동 속도 적용 및 대시 이동 조작
* **검증 기준**: Cinemachine 댐핑 연동 카메라 추적 시 화면 떨림 또는 픽셀 깨짐 현상이 발생하는지 검증

## 5. 정정 및 수정 이력 (3D Perspective 카메라, 줌 및 3대 카메라 모드 명세)

### 5-1. 정정 사유 및 서술 정정
* **기존 본문 서술 정정**: Section 2-1 및 Section 3-1 기재 2D 직교 파라미터(`OrthographicSize`) 용어 정정
* **3D Perspective 스펙 반영**: 본 게임 3D 공간 쿼터뷰 특성에 맞춰 Perspective Projection 모드로 정정 연산 적용

### 5-2. 3D Perspective 카메라 줌 파라미터 명세
* **투영 모드**: Perspective Projection (3D 원근 투영)
* **`CameraSettingSO` 정정 수치**:
  * `float minZoomFOV`: 30f (최소 시야각 줌인)
  * `float maxZoomFOV`: 60f (최대 시야각 줌아웃)
  * `float minCameraDistance`: 8f (최소 쿼터뷰 거리)
  * `float maxCameraDistance`: 18f (최대 쿼터뷰 거리)
* **줌 보간 제어**: 마우스 휠 조작 시 Cinemachine Lens `Field of View (FOV)` (30°~60°) 및 Framing Transposer `Camera Distance` (8m~18m) 동시 보간 제어 연산 적용

### 5-3. 일반 추적 타깃 및 마우스 확대(Zoom In) 전용 기준 정정
* **일반 상태 타깃팅 정정**: 평상시 이동/전투 시 마우스 조준 방향 가중치 시야 이동 제거 (`mouseWeight` = 0). 플레이어 캐릭터(Player Transform) 100% 고정 중앙 추적
* **확대(Zoom In) 전용 마우스 기준 줌 명세**:
  * 마우스 휠 전진 줌인(Zoom In) 조작 시에만 마우스 커서가 가리키는 3D 월드 좌표 지점으로 카메라 시선 오프셋이 마우스 방향 줌인 연산 처리
  * 마우스 휠 후진 줌아웃(Zoom Out) 조작 시 플레이어 캐릭터 중앙 100% 뷰포트 원점 시야 복귀

### 5-4. 3가지 카메라 모드 시스템 (`CameraMode` Enum) 추가 명세
* **`CameraMode` 열거형 수식 정의**:
  1. **`PlayerOnly` (플레이어 전용 추적 모드)**:
     * 마우스 조작 무시, 오직 플레이어 캐릭터 100% 중앙 추적
  2. **`MouseFocus` (마우스 추적 모드)**:
     * 마우스 커서 3D 월드 위치를 주 추적 타깃으로 설정
     * **플레이어 화면 이탈 방지 클램프 연산 (Player Screen Boundary Clamp)**: 마우스가 화면 외곽으로 멀어지더라도 플레이어 캐릭터 3D 좌표가 Camera Viewport [0.1, 0.9] 화면 경계를 벗어나지 않도록 카메라 오프셋 자동 한계 클램프 제어
  3. **`HybridFocus` (하이브리드 보정 모드 - 기본 모드)**:
     * 평소 플레이어 캐릭터 100% 추적 + 마우스 휠 줌인 조작 시 마우스 3D 월드 지점 줌 보정 추적 연산
* **VContainer 연동 메서드 명세**:
  * `ICameraFollowService.SetCameraMode(CameraMode mode)` 통해 모드 실시간 전환 지원
