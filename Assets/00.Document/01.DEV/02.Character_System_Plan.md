## 2. 유형별 맞춤 핵심 요구사항

### 2-1. 비시청각 영역 요구사항 (공식: [구현 수단 / 방법] + [기대 효과 / 최적화 목표])

* **데이터 오염 방지 및 분리**: 읽기 전용 카탈로그 SO(`PureStatData`)와 런타임 스탯 데이터 클래스(`RuntimeStatData`)를 분리 구조로 구현하여 인게임 수치 변경 시 에디터 원본 파일 오염 방지 및 메모리 안정성 확보
* **데이터 범위 캡슐화**: `ClampValue<T>` 상속 구조로 HP 및 MP 수치를 구현하여 범위 한계(Min 0 ~ Max) 자동 제어 및 경계 값 오버플로우 방지
* **사망 이벤트 발송**: HP Min(0) 도달 시 `OnDeath` 사망 이벤트를 발송하는 구조로 구현하여 전투 시스템과 캐릭터 간 직접 참조를 배제하고 시스템 모듈성 달성
* **마나 수치 제어 및 부족 반응**: MP `Increase(amount)` 및 `Reduce(amount)` 수치 조절 연산과 요구 마나 미달 시 `OnInsufficientMana` 이벤트를 발송하는 구조로 구현하여 단위 조작 마법 자원 검증 안정성 확보
* **전투 파이프라인 일반화**: `Assets/PipeLine` 전투 파이프라인(피격 판정 → 데이터 캡슐화 → 이벤트 중앙 전달 → 수치 연산 → 상태 적용 및 반응) 일반화 구조 적용 구현으로 피격 연산 입출력 안정성 및 시스템 확장성 보장
* **단위 마법 슬롯 다형성 캡슐화**: 캐릭터 관점 독립 `UnitMagicSlot` 단위 마법 보관 슬롯 및 `UnitMagicSlot.Fire()` 호출 인터페이스 구조로 구현하여 캐릭터-단위 마법 간 직참조 의존성을 제거하고 다형성 기반 단위 마법 교체 모듈성 확보

### 2-2. 시청각 영역 요구사항 (사용자 행동 입력에 따른 실질적 동작 및 결과)

* **UI Toolkit 게이지 바 실시간 반응**: 사용자 피격, 회복 또는 마나 소모 조작 시 UI Toolkit Pure API 연동 기반 HP 및 MP 게이지 바 수치가 `Update()` 무의존 이벤트 수신 방식으로 실시간 반영된다.
* **현재 장착 마법 UI 표시**: 사용자 단위 마법 교체 입력 조작 시 UI Toolkit 기반 현재 장착 마법(`CurrentUnitMagic`) 슬롯 아이콘 및 상세 정보가 실시간 표출된다.
* **UI - 인게임 입력 분리**: 사용자 UI 요소 마우스 클릭 조작 시 `RuntimePanelUtils.ScreenToPanel` 및 `panel.Pick` 검증 수행으로 백그라운드 3D 월드 클릭 레이캐스트가 즉시 중단 처리된다 (입력 불필요 투명 레이아웃 패널 `pickingMode = PickingMode.Ignore` 설정 연동).

## 3. DLV 아키텍처 설계 명세

```
[ Data Layer ]          ↔       [ Logic Layer & DI ]     ↔       [ Visual Layer ]
- PureStatData                   - CharacterStatSystem            - UI Toolkit HUD Document
- PureDataUnit (UnitSystem)      - BattlePipeLine                 - HPBar / MPBar VisualElement
- RuntimeStatData (ISaveableData)- UnitMagicSlotSystem            - CurrentUnitMagicSlotUI
- ClampValue<T>                  - UnitChangeService              - PickingMode.Ignore Panels
                                 - CharacterLifetimeScope (DI)
```

### 3-1. Data Layer (데이터 레이어)
* **`PureStatData` (ScriptableObject)**:
  * 읽기 전용 스탯 원본 프리셋 (MaxHP, MaxMP, BaseMoveSpeed, DefaultUnitMagicList)
* **`ClampValue<T>` (Generic Data Structure)**:
  * `T MinValue`, `T MaxValue`, `T CurrentValue` 수치 범위 제어 캡슐화 클래스
* **`RuntimeStatData` (Class, `ISaveableData` 상속)**:
  * `ClampValue<int> HP` (Min 0 도달 시 `OnDeath` 이벤트 발송)
  * `ClampValue<int> MP` (부족 시 `OnInsufficientMana` 이벤트 발송)
  * `float MoveSpeed` (런타임 이동 속도)
  * `ISaveableData` 구현 기반 데이터 저장 및 복원 연동
* **`PureDataUnit` (`Assets/02.System/01.UnitSystem/00.Data/PureDataUnit.cs`)**:
  * 기존 UnitSystem 마법/단위 기본 데이터 직접 참조 (UnitName, BaseCost, Icon, Applicator)

### 3-2. Logic Layer & DI (로직 및 의존성 주입 레이어)
* **`CharacterStatSystem`**:
  * `RuntimeStatData` 보유, HP/MP `Increase`/`Reduce` 연산 제어, 사망/자원 부족 이벤트 발행
* **`BattlePipeLine` (`Assets/PipeLine` 일반화)**:
  * 피격 데이터 캡슐화 → 파이프라인 전달 → 수치 연산 → 스탯 적용 처리
* **`UnitMagicSlotSystem`**:
  * `UnitMagic` 상속 객체 슬롯 보관, `Fire()` 실행, 단위 마법 사용 성공/실패 판정 및 피드백 반환
* **`UnitChangeService` 연동**:
  * 단위 조작 마법 발동 시 플레이어 `RuntimeStatData.MP` 수치 검증 및 차감 연동
* **`CharacterLifetimeScope` (VContainer LifetimeScope)**:
  * `CharacterStatSystem`, `UnitMagicSlotSystem`, `RuntimeStatData` VContainer 주입 등록 및 수명 관리

### 3-3. Visual Layer (시청각 레이어)
* **`UI Toolkit HUD Document`**:
  * `HPBar` VisualElement: `OnHPChanged` 이벤트 수신 실시간 FillAmount/Text 갱신
  * `MPBar` VisualElement: `OnMPChanged` 이벤트 수신 실시간 FillAmount/Text 갱신
  * `CurrentUnitMagicSlotUI`: `OnUnitMagicChanged` 이벤트 수신 마법 슬롯 아이콘 갱신
* **UI Toolkit Pure API 상호작용**:
  * `pickingMode = PickingMode.Ignore` 설정 (비노출 레이아웃 클릭 방해 차단)
  * `panel.Pick(panelPos)` 활용 UI 클릭 시 백그라운드 3D Raycast 자동 중단

## 4. 예상 검수 방법 및 테스트 가이드

### 4-1. HP/MP Clamp 및 이벤트 발송 검수
* **테스트 항목**: HP 0 이하 감소 처리 및 MP 요구량 미달 조작
* **검증 기준**: HP Min(0) 도달 시 `OnDeath` 사망 이벤트 발송 검증, MP 미달 시 `OnInsufficientMana` 이벤트 발송 및 마동 차단 검증

### 4-2. 단위 마법 슬롯 및 마나 연동 검수
* **테스트 항목**: 단위 마법 슬롯 마법 장착 후 `UnitMagicSlot.Fire()` 실행
* **검증 기준**: 마법 발동 시 MP 차감 연동 확인, 마나 부족 시 발동 실패 피드백 반환 확인

### 4-3. UI Toolkit 입력 분리 검수
* **테스트 항목**: UI Toolkit HUD 패널 영역 마우스 클릭 조작
* **검증 기준**: UI 클릭 시 3D 월드 레이캐스트 마우스 타깃팅 멈춤 확인, 투명 영역 클릭 시 인게임 레이캐스트 정상 작용 확인
