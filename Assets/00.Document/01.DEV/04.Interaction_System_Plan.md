# 04. 상호작용 및 비주얼라이저 연출 시스템 코드 작업 기획서 (Interaction System Plan)

---

## 1. 작업 개요 및 유형 분류

* **작업 목표**: 상호작용 신호(피격, 회복, 단위 조작 마법, 아이템 획득) 통합 수신, 상황별 비동기 파이프라인 연산 실행(`CharacterDamagePipeLine.Run()`, `UnitMagicPipeLine.Run()`), 스탯 수치 최종 적용(`HP`/`MP` `Reduce`/`Increase`), 비주얼라이저 연출 프로토콜 및 컴포넌트 세부 코드 설계 및 DLV 아키텍처 명세
* **저장 위치**: `Assets/00.Document/01.DEV/04.Interaction_System_Plan.md`
* **참고 문서**: `Assets/PipeLine/Visualizers`, `Assets/00.Document/01.DEV/03.PipeLine_Generalization_Plan.md`
* **작업 분류**:
  * **비시청각 영역**: Pure Data (`DamageContext`, `UnitMagicContext`), Core System (`InteractionSystem`, `IInteractionService`), VContainer DI
  * **시청각 영역**: Visualizer Protocol (`IDamageVisualizer`, `IUnitMagicVisualizer`), Visual Component (`DamageFloatingText`, `EvadeTextEffect`, `InsufficientManaWarningUI`, `UnitChangeEffectVisualizer`)

---

## 2. 유형별 맞춤 핵심 요구사항

### 2-1. 비시청각 영역 요구사항 (공식: [구현 수단 / 방법] + [기대 효과 / 최적화 목표])

* **결합도 최소화 상호작용 통합**: VContainer `IInteractionService` 싱글톤 인터페이스 주입 아키텍처로 구현하여 상호작용 요청자와 파이프라인 처리 시스템 간 직접 참조를 배제하고 루즈 커플링 모듈성 달성
* **상황별 비동기 파이프라인 통합 수신**: `OnDamageRequested`, `OnHealRequested`, `OnUnitMagicRequested` 이벤트 구독 방식으로 구현하여 상호작용 신호 수신 시 해당 컨텍스트 생성 및 비동기 파이프라인 실행 연동성 보장
* **최종 수치 스탯 적용**: 파이프라인 연산 완료 후 산출된 final 수치를 피격/회복 대상 캐릭터 `CharacterStatSystem.HP`/`MP` `Reduce()`/`Increase()` 연동 및 사망/자원부족 이벤트 연결 구조로 구현하여 수치 연산 정확성 및 상태 반응성 확보
* **비주얼 프로토콜 캡슐화**: `IDamageVisualizer` 및 `IUnitMagicVisualizer` 인터페이스 바인딩 연동 구조로 구현하여 상호작용 로직 스텝과 시청각 뷰 연출 간 의존성을 전면 분리하고 연출 효과 추가/교체 모듈성 보장

### 2-2. 시청각 영역 요구사항 (사용자 행동 입력에 따른 실질적 동작 및 결과)

* **피격 데미지 Floating Text 연출**: 사용자 피격/공격 상호작용 조작 시 `InteractionSystem` 연산 완료 후 `IDamageVisualizer.ShowDamageText()` 수신으로 피격 위치에 데미지 수치 Floating Text가 실시간 렌더링 표출된다.
* **회피 Evade 텍스트 연출**: 파이프라인 회피 발생 시 `IDamageVisualizer.ShowEvadeText()` 수신으로 대상 머리 위 "Evade" 텍스트 연출이 실시간 표출된다.
* **마나 부족 경고 UI 연출**: 단위 마법 상호작용 중 마나 부족 발생 시 `IUnitMagicVisualizer.ShowInsufficientManaWarning()` 수신으로 화면 중앙 마나 부족 경고 팝업 및 진동 연출이 실시간 표출된다.
* **단위 변환 시각 연출**: 단위 수치 변환 상호작용 성공 시 `IUnitMagicVisualizer.ShowUnitChangeEffect()` 수신으로 대상 물체 셰이더 변환 및 파티클 연출이 실시간 적용된다.

## 3. DLV 아키텍처 설계 명세

```
[ Data Layer ]          ↔       [ Logic Layer & DI ]     ↔       [ Visual Layer (Visualizers) ]
- DamageContext                  - IInteractionService            - IDamageVisualizer (Protocol)
- UnitMagicContext               - InteractionSystem (Singleton)  - IUnitMagicVisualizer (Protocol)
- PureStatData                   - CharacterDamagePipeLine        - DamageFloatingText
- RuntimeStatData                - UnitMagicPipeLine              - EvadeTextEffect
                                 - CharacterStatSystem            - InsufficientManaWarningUI
                                 - CharacterLifetimeScope (DI)    - UnitChangeEffectVisualizer
```

### 3-1. Data Layer (데이터 레이어)
* **`DamageContext` (Class)**:
  * `BaseCharacter attacker`, `BaseCharacter victim`, `int rawDamage`, `bool isEvaded`, `bool isCritical`, `int finalDamage`
* **`UnitMagicContext` (Class)**:
  * `BaseCharacter caster`, `GameObject targetObject`, `UnitMagic unitMagic`, `int requiredMana`, `bool isSuccess`

### 3-2. Logic Layer & DI (로직 및 의존성 주입 레이어)
* **`IInteractionService` (Interface)**:
  * `UniTask ProcessDamageAsync(DamageContext context)` (전투 데미지 상호작용 파이프라인 실행)
  * `UniTask ProcessUnitMagicAsync(UnitMagicContext context)` (단위 마법 상호작용 파이프라인 실행)
* **`InteractionSystem` (Implementation - VContainer `Lifetime.Singleton`)**:
  * `OnDamageRequested` / `OnHealRequested` / `OnUnitMagicRequested` 상호작용 신호 통합 수신
  * `CharacterDamagePipeLine.Run(context)` 및 `UnitMagicPipeLine.Run(context)` 실행
  * `context.Victim.CharacterStatSystem.HP.Reduce(context.FinalDamage)` 등 스탯 연동 수치 차감/증가 처리
* **파이프라인 스텝 ↔ 비주얼 프로토콜 연동**:
  * `EvasionStep`: 회피 성공 시 `IDamageVisualizer.ShowEvadeText(context)` 호출
  * `ApplyDamageStep`: 데미지 적용 시 `IDamageVisualizer.ShowDamageText(context)` 호출
  * `ManaCheckStep`: 마나 미달 시 `IUnitMagicVisualizer.ShowInsufficientManaWarning(context)` 호출
  * `ApplyUnitChangeStep`: 단위 변환 시 `IUnitMagicVisualizer.ShowUnitChangeEffect(context)` 호출

### 3-3. Visual Layer (시청각 비주얼라이저 레이어 - `Assets/PipeLine/Visualizers`)
* **`IDamageVisualizer` (Interface)**:
  * `void ShowDamageText(DamageContext context)`
  * `void ShowEvadeText(DamageContext context)`
* **`IUnitMagicVisualizer` (Interface)**:
  * `void ShowInsufficientManaWarning(UnitMagicContext context)`
  * `void ShowUnitChangeEffect(UnitMagicContext context)`
* **`DamageFloatingText`** (`IDamageVisualizer` 구현체):
  * 피격 위치 3D World Text 생성, Floating 연출 후 자동 소멸
* **`EvadeTextEffect`** (`IDamageVisualizer` 구현체):
  * 회피 발생 위치 Evade 텍스트 연출
* **`InsufficientManaWarningUI`** (`IUnitMagicVisualizer` 구현체):
  * 마나 부족 팝업 UI 및 HUD 마나 바 진동 피드백
* **`UnitChangeEffectVisualizer`** (`IUnitMagicVisualizer` 구현체):
  * 단위 변환 대상 아웃라인 셰이더 및 파티클 피드백 연출

## 4. 예상 검수 방법 및 테스트 가이드

### 4-1. 데미지/회복 상호작용 및 HP 차감 검수
* **테스트 항목**: 전투 피격 및 회복 상호작용 요청 발송
* **검증 기준**: `CharacterDamagePipeLine` finalDamage 산출 확인, 피격 대상 `CharacterStatSystem.HP` 정량 차감/증가 확인

### 4-2. 단위 마법 상호작용 및 MP 차감 검수
* **테스트 항목**: 단위 마법 상호작용 요청 발송
* **검증 기준**: `UnitMagicPipeLine` 마나 검증 확인, `CharacterStatSystem.MP` 정량 차감 및 수치/단위 변환 적용 확인

### 4-3. Visualizer 연출 수신 검수
* **테스트 항목**: 피격, 회피, 마나 부족, 단위 변환 상호작용 발생
* **검증 기준**: `DamageFloatingText`, `EvadeTextEffect`, `InsufficientManaWarningUI`, `UnitChangeEffectVisualizer` 실시간 연출 표출 검증
