## 1. DLV 아키텍처 (Data-Logic-Visual) v0.3

**철학:** "입력은 흐르고, 데이터는 안전하게 보존되며, 로직은 판단하고, 비주얼은 표현한다."

* 코드 작성 후 테스트 케이스 가이드 제공 필수.
* 네트워크 관련: 기능 작업 후 추가. 기존 파일 존재 시 `파일명 + 리팩토링 진행` 출력.

---

### 1-1. [D] 데이터 그룹

| 모듈 | 네이밍 | 형태 | 핵심 규칙 |
|------|--------|------|-----------|
| Pure Data | `[PureData]명` | ScriptableObject | Immutable(readonly/private set), Logic-Free |
| Pure DataBase | `[PureDataBase]명` | SO | `Dictionary<ID, PureData>` 보관, Root Scope 단일 등록 |
| Runtime Data | `[RuntimeData]명` | 순수 C# 클래스 | PureData 읽기 참조, Observable(C# event), 값 캡슐화, ISaveableData 상속 |
| Data Save-Load | — | — | ISaveableData 인터페이스, 저장/불러오기로 RuntimeData 복원 |

#### Runtime Data 상세 규칙
- 모든 속성은 `private set`으로 외부 임의 수정 차단.
- 상태 변경은 내부 전용 메서드(`DecreaseHp`, `AddExp` 등)를 통해서만 수행.
- 데이터 스스로 프레임 갱신(`Tick`)을 돌지 않으며, 상태가 바뀔 때 이벤트만 발행.

---

### 1-2. [L] 로직 그룹

| 모듈 | 네이밍 | 형태 | 핵심 규칙 |
|------|--------|------|-----------|
| 유니티 생명주기 연동 로직 | `[System]` | 순수 C# 클래스 | `IInitializable`, `ITickable`, `IFixedTickable`, `ILateTickable`, `IDisposable` 구현. 유니티 생명주기 기반 판단. |
| 호출형 순수 로직 | `[System]` | 순수 C# 클래스 | 기능 인터페이스 구현. 요청 시 연산 및 결과 반환. |

#### Logic System 상세 규칙
- MonoBehaviour 상속 금지 (순수 C# 클래스로 작성).
- `Rigidbody`, `NavMeshAgent`, `transform.position` 직접 참조 및 수정 금지.
- 구체 클래스 직접 참조 금지 (인터페이스 또는 이벤트를 통해서만 소통).
- 데이터 값 직접 조작 금지 (Runtime Data의 상태 변경 메서드를 호출하여 지시).
- 비주얼 연출은 Visual Interface를 호출하여 실행.

### 1-3. [V] 비주얼 그룹

| 모듈 | 네이밍 | 핵심 규칙 |
|------|--------|-----------|
| Visual Interface | `I[Feature]Visualizer` | 추상 메서드만 포함. 구체 구현 노출 금지. DIP 연결 고리 역할 |
| World Visualizer | `[Feature]Visualizer` | 수동적 수행자. Interface 구현. 물리 및 이동 실질 수행 |
| UI View Layer | `[Feature]UIView` | Runtime Data event 직접 구독. 자체 계산 로직 포함 금지 |

### 1-4. 개발 3대 원칙

* **Rule 1 – Everything is Data:**  
  모든 입력은 Pure Data 객체로 변환하여 전달. 인자 나열 전달 금지.

* **Rule 2 – Blind Logic (순수 로직 및 인터페이스 소통):**  
  로직 클래스는 순수 C# 클래스로 작성. 타 시스템이나 비주얼과는 인터페이스/이벤트로만 소통하며 구체 클래스 직접 참조 금지.

* **Rule 3 – Encapsulated Data (데이터 캡슐화):**  
  Pure Data는 불변 유지. Runtime Data는 `private set`과 전용 변경 메서드로 상태를 안전하게 보호.
