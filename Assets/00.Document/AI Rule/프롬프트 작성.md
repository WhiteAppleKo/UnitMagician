# AI 프롬프트 

## 1. 분석
```
[스크립트 명]을 읽고 분석해줘.
컴포넌트에 노출된 수정 가능한 변수의 역할과 적용 방식을 목록으로 정리해서 보고해.
파일 수정은 하지 말고, 연계된 다른 스크립트가 있다면 마찬가지로 분석해서 보고해.
```

## 2. 방안 제시
```
분석한 스크립트를 [수정하고 싶은 방향]으로 작업할 거야.
내가 생각한 [수정하고 싶은 방식]의 효율성을 검증하고, 일반적인 다른 작업 방식 2가지와 각 방식의 장단점을 알려줘.
그중에 가장 추천하는 방식을 1개 골라주고, 아직 파일 수정은 하지 마.
```

## 3. 작업 진행
```
[선택한 방식]으로 작업을 진행해줘.
검증 절차([검증 절차 내용])를 진행하고, 통과하지 못하면 만족할 때까지 수정해줘. 
3회 시도해도 검증을 통과하지 못하면 작업을 멈추고 문제의 원인을 보고해.
기존 코드와 주석은 유지하면서 부분 수정으로 진행해줘.
```

## 4. 작업 요약
```
작업한 내용 요약과 함께 결과물 사용 가이드를 작성해줘.
가이드는 다음 순서대로 번호를 매겨서 설명해줘:

Scene 배치 가이드 - 컴포넌트 추가 및 설정 가이드 (주의사항 포함) - 인게임 테스트 가이드
```
