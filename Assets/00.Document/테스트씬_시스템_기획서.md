# 1단계 훈련장 테스트 씬 시스템 기획서

---

## 1. 개요 및 목적
- **목적**: 적 몬스터를 배제하고 **플레이어 캐릭터 + 허수아비 표적**만으로 핵심 마법과 전투 규칙을 검증하는 최소 테스트 환경 구축
- **범위**: 캐릭터 조작, 락온, 카메라 조준 시간 감속, 단위 조작, 거리별 마나 소모, 무기 및 피격 판정

---

## 2. 조작 키 배치

| 키 입력 | 기능 설명 |
| :--- | :--- |
| **WASD** | 캐릭터 이동 |
| **마우스 회전** | 3D 카메라 시점 회전 |
| **Q / 휠 클릭** | 허수아비 타겟 락온 켜기 및 대상 전환 |
| **F 키** | 내 손에 쥔 무기 즉시 강화 (시간 감속 없음, 최소 마나) |
| **마우스 우클릭 유지** | 시간 감속 및 카메라 자유 조준 (슬로우 게이지 소모) |
| **마우스 좌클릭** | 락온 대상에게 마법 시전 확정 (시간 정상화 및 시전 동작) |

---

## 3. 캐릭터 상태 및 시간 제어 구조

### 1) 캐릭터 상태
- **일반 상태**: 대기, 이동 등 기본적인 동작 상태
- **마법 시전 상태**: 좌클릭으로 마법 확정 시, 손을 뻗어 마법을 발동하는 짧은 모션 상태

### 2) 시간 감속 (독립 환경 기능)
- 캐릭터 상태와 별개로 작동하는 전역 시간 조절 기능
- **우클릭 유지 시**: 세상과 캐릭터의 시간이 느려지며, **유저의 카메라만 자유롭게 회전**하여 타겟을 탐색
- **우클릭 해제 시**: 마법을 쏘지 않고 취소하며 일반 상태로 복귀

---

## 4. 필수 구현 7대 시스템

### 1) 캐릭터 조작 및 카메라 시스템
- WASD 이동 및 중력 처리
- 3인칭 백뷰 카메라 시점 회전
- 조작 입력 감지 및 캐릭터 상태 제어

### 2) 타겟 락온 시스템
- Q 키 또는 마우스 휠 클릭 시 주변 허수아비 자동 탐색
- 대상 고정 및 허수아비 머리 위에 타겟 조준 마크 표시

### 3) 시간 제어 시스템 (슬로우 모션)
- 마우스 우클릭 유지 시 게임 시간을 느리게 감속
- 슬로우 집중력 게이지 소모 및 미사용 시 자동 회복

### 4) 단위 및 수치 조작 시스템 (핵심)
- 모든 오브젝트에 4대 속성 부여: 온도(℃), 무게(kg), 부피(L), 방향 및 속도(m/s)
- **거리 판정 로직**:
  - 1.5m 이내: 손 터치 모션 + 아주 적은 마나 소모
  - 1.5m 초과: 원거리 시선 모션 + 보통 마나 소모
- **F 키 로직**: 내 무기에 즉시 단위 부여

### 5) 무기 및 투사체 시스템
- 검 근접 공격 및 활 투사체 발사
- 날아가는 탄환의 물리 궤적 처리
- 방향이 반전된 탄환의 역방향 비행 처리

### 6) 타격 및 데미지 판정 시스템
- 무기 및 투사체와 허수아비의 충돌 감지
- 기본 데미지 + 단위 속성(화염, 충격 등) 추가 피해 계산
- 피격 시 허수아비 흔들림 연출

### 7) 테스트 UI 표시 시스템
- **화면 좌하단**: 플레이어 체력, 마나 게이지, 슬로우 게이지
- **허수아비 머리 위**: 현재 체력, 무게, 온도, 적용된 단위 수치 실시간 텍스트 표시

## 5. 핵심 검증 시나리오

1. **시나리오 A: 무기 즉시 강화 검증**
   - F 키를 눌러 화살에 온도(℃)를 부여한 뒤 발사하여 불화살 데미지가 들어가는지 확인
2. **시나리오 B: 거리별 마나 차이 검증**
   - 허수아비 코앞(1.5m 이내)에서 마법 사용 시 마나 소모량과, 멀리서 락온 후 사용 시 마나 소모량 비교
3. **시나리오 C: 카메라 조준 및 투사체 반사 검증**
   - 발사기에서 날아오는 탄환에 마우스 우클릭(카메라 조준 슬로우)을 걸고 방향을 반전시켜 발사기를 파괴하는지 확인
