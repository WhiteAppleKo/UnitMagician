## 2. 문제점 분석 (Code Smells - 5대 기준 위배 상세)

### 2-1. VContainer DI 전환 위배
* **Find 계열 메서드 직접 탐색:** `CameraFollowVisualizer.cs` 내부에서 `FindAnyObjectByType<CinemachineBrain>()`, `FindAnyObjectByType<LocomotionVisualizer>()`를 호출함.
* **직접 new 키워드 생성:** `CameraFollowService.cs` 생성자에서 `m_mousePositionProvider = new MouseWorldPositionProvider();`로 구체 클래스를 직접 생성하여 결합도가 높음.

### 2-2. 디자인 패턴 적용 위배 (전략 패턴 부재)
* **모드별 거대 Switch 분기:** `CameraFollowService.UpdateCameraOffset()` 내에서 `FirstPerson`, `ThirdPersonShoulder`, `MouseFocus`, `HybridFocus`, `PlayerOnly` 분기가 하드코딩되어 모드 확장 시 OCP 위배.

### 2-3. 중복 코드 및 결합도
* **Camera.main 중복 호출:** `CameraFollowService`, `MouseWorldPositionProvider`, `CameraFollowVisualizer` 등 여러 클래스에서 `Camera.main`을 매 프레임 개별 조회함.

### 2-4. 설계 원칙 위배 (SRP 및 LOD)
* **Visualizer 과다 책임 (God Component):** `CameraFollowVisualizer`가 피벗 오브젝트 런타임 동적 생성, 3개 가상 카메라(Cinemachine) 전환, 락온 피벗 동기화, 시간 정지 예외(IgnoreTimeScale) 처리 등 과도한 역할을 동시에 수행함.

### 2-5. DLV 아키텍처 위배
* **Blind Logic 위배:** Logic 계층인 `CameraFollowService`가 Unity 씬의 `Camera.main` 및 `Mouse.current` 하드웨어 디바이스에 직접 결합되어 순수 로직 단위 테스트가 불가함.

## 3. 리팩토링 설계 (To-Be Architecture)

```
[D: Data Layer]
PureDataCameraSetting (ScriptableObject)
CameraMode (Enum)

[L: Logic Layer]
CameraFollowService (Context / Dispatcher)
├── ICameraModeCalculationStrategy (Interface)
│   ├── FirstPersonCameraStrategy
│   ├── ThirdPersonShoulderCameraStrategy
│   ├── TopViewMouseFocusStrategy
│   └── HybridFocusCameraStrategy
└── IMousePositionProvider (Interface)

[V: Visualizer Layer]
ICameraFollowVisualizer (Interface)
├── CameraFollowVisualizer (Cinemachine Orchestrator)
└── CinemachineBrainController (TimeScale 예외 처리 전담)
```

### 3-1. 카메라 모드 연산 전략 패턴(Strategy Pattern) 적용
* 각 뷰 모드별 타겟 위치 및 회전각 계산식을 `ICameraModeCalculationStrategy`로 분리.
* 모드 변경 시 해당 전략 객체를 활성화하여 Switch 분기 제거.

### 3-2. 마우스 입력 및 카메라 공급자 추상화
* `IMousePositionProvider` 인터페이스 추출 후 VContainer 싱글톤 주입.

### 3-3. VContainer 수명 주기 등록
* `CameraFollowService`: `builder.Register<ICameraFollowService, CameraFollowService>(Lifetime.Scoped).As<ILateTickable>()`
* `CameraFollowVisualizer`: `builder.RegisterComponentInHierarchy<CameraFollowVisualizer>()`

## 4. 단계별 변경 명세

### Step 1: 신규 인터페이스 및 전략 클래스 분리
* `Assets/02.System/00.Movement/01.Logic/01.CameraMovement/Strategy/ICameraModeCalculationStrategy.cs`
  ```csharp
  namespace CameraMovement
  {
      public interface ICameraModeCalculationStrategy
      {
          CameraMode Mode { get; }
          Vector3 CalculateTargetPivot(Vector3 basePos, Vector2 mouseInput, float zoomRatio, PureDataCameraSetting setting);
          Vector2 CalculateLookAngles(Vector2 currentAngles, Vector2 mouseInput, PureDataCameraSetting setting);
      }
  }
  ```
* `FirstPersonCameraStrategy.cs`, `ShoulderCameraStrategy.cs`, `HybridFocusCameraStrategy.cs` 구현체 작성.
* `IMouseWorldPositionProvider.cs` 인터페이스 추출.

### Step 2: 기존 클래스 수정
* `CameraFollowService.cs`:
  * `IMouseWorldPositionProvider`를 생성자 주입받도록 변경.
  * Switch 분기를 `Dictionary<CameraMode, ICameraModeCalculationStrategy>` 조회 방식으로 교체.
  * `Camera.main` 및 `Mouse.current` 직접 참조 제거.
* `CameraFollowVisualizer.cs`:
  * `FindAnyObjectByType` 제거. `[Inject]`를 통해 `ILocomotionVisualizer` 및 `CinemachineBrain` 주입.

### Step 3: MovementLifetimeScope 바인딩 갱신
* `MovementLifetimeScope.cs`:
  ```csharp
  builder.Register<IMouseWorldPositionProvider, MouseWorldPositionProvider>(Lifetime.Scoped);
  builder.Register<ICameraModeCalculationStrategy, FirstPersonCameraStrategy>(Lifetime.Scoped);
  builder.Register<ICameraModeCalculationStrategy, ShoulderCameraStrategy>(Lifetime.Scoped);
  builder.Register<ICameraModeCalculationStrategy, HybridFocusCameraStrategy>(Lifetime.Scoped);
  builder.Register<ICameraFollowService, CameraFollowService>(Lifetime.Scoped).As<ILateTickable>();
  builder.RegisterComponentInHierarchy<CameraFollowVisualizer>();
  ```

## 5. 기능 무결성 검증 기준 및 테스트 케이스

### 검증 체크리스트
1. **모드 전환 무결성:** FirstPerson <-> Shoulder <-> HybridFocus 간 모드 전환 시 Cinemachine 가상 카메라 우선순위(Priority)가 정확히 100/0으로 교체되는가?
2. **줌 인/아웃:** 마우스 휠 스크롤 시 MinZoomFOV ~ MaxZoomFOV 및 카메라 거리 Lerp가 부드럽게 적용되는가?
3. **시간 정지 시 카메라 조작:** T키(TimeSlow) 중에도 마우스 회전 및 카메라 추적이 멈추지 않고 독립 시간(`Time.unscaledDeltaTime`)으로 동작하는가?
4. **락온 타겟 추적:** 락온 활성화 시 카메라 피벗이 락온 대상을 향해 부드럽게 회전하는가?
