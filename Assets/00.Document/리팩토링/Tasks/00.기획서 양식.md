# [문서번호] 기능 이름

## 1. 작업 개요 및 유형
* **기능 요약**: 구현할 내용 1~2줄 작성
* **작업 유형**: (시청각 영역 / 비시청각 영역 중 선택)

## 2. 핵심 요구사항
* **시청각 영역일 때**: 사용자의 조작에 따른 동작과 결과 작성
* **비시청각 영역일 때**: [구현 방법] + [최적화 목표] 한 문장 결합 작성

## 3. DLV 아키텍처 파일 설계

### [D] 데이터 그룹
* **Pure Data**: `Assets/Scripts/.../PureData[기능명].cs`
    * ScriptableObject 형태, 불변 데이터 정의
* **Runtime Data**: `Assets/Scripts/.../RuntimeData[기능명].cs`
    * C# event 보유, 변경 데이터 보관

### [L] 로직 그룹
* **Logic System**: `Assets/Scripts/.../[기능명]LogicSystem.cs`
    * 순수 판단만 수행
    * 위치나 물리 직접 조작 금지, Interface로만 소통

### [V] 비주얼 그룹
* **Visual Interface**: `Assets/Scripts/.../I[기능명]Visualizer.cs`
    * 화면 표현 함수 규격 정의
* **World Visualizer / UIView**: `Assets/Scripts/.../[기능명]Visualizer.cs`
    * 실제 이동, 연출 및 UI 화면 처리

## 4. DLV 3대 원칙 준수 확인
- [ ] **Everything is Data**: 모든 입력을 Pure Data 객체로 변환했는가?
- [ ] **Blind Logic**: 로직이 비주얼을 직접 참조하지 않고 Interface를 통하는가?
- [ ] **Immutable Data**: Pure Data를 런타임에 직접 변경하지 않는가?

## 5. QA 검증 및 테스트 가이드
* **컴파일 검사**: `dotnet build` 에러 0건
* **테스트 케이스**:
    * 정상 입력 시 기대 결과
    * 비정상 입력 시 예외 처리
