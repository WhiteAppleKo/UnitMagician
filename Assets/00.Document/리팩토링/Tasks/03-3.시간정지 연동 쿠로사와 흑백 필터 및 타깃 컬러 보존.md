# 03-3. 시간 정지 연동 쿠로사와 흑백 필터 및 타깃 컬러 보존

## 1. 작업 개요 및 유형
* **기능 요약**: 기존의 밋밋하고 탁한 잿빛 화면을 전면 폐기하고, 깊은 명암 대비와 날카로운 질감을 가진 영화 같은 쿠로사와 풍 흑백 화면을 구현합니다. 또한 시간 정지가 켜질 때만 단일 렌더러 피처가 작동하여 평소 화면 간섭을 100% 차단하고, 락온 타깃과 플레이어만 완벽한 원본 컬러를 유지하도록 통합합니다.
* **작업 유형**: 시청각 영역 (그래픽 셰이더 및 화면 렌더링 파이프라인 전면 개편)

---

## 2. 기존 문제점 및 원인 분석

### 1) 온 화면이 잿빛으로 뭉개진 이유
* **단순 채도 감소의 한계**: 빛과 그림자의 대비 없이 단순 계산식으로 색상만 빼버려, 입체감 없는 탁한 시멘트 색으로 변했습니다.
* **톤 곡선 부재**: 밝은 부분은 눈부시게 살리고 어두운 그림자는 깊게 눌러주는 명암 곡선이 없어 중간 톤만 뭉개졌습니다.

### 2) 타깃과 플레이어까지 회색으로 물든 이유
* **스텐실 연결 누락**: URP 기본 전체 화면 기능이 스텐실 버퍼를 읽지 못하고 화면 전체를 덮어버려, 타깃 도장을 무시하고 모든 대상을 강제로 회색칠했습니다.

### 3) 평소에도 화면이 흑백으로 나오는 이유
* **별도 분리 기능의 상시 구동**: 흑백 화면을 그리는 기능이 시간 정지 로직과 결합되지 않고 독자적으로 매 프레임 실행되어 평소 게임 화면을 망쳤습니다.

---

## 3. 핵심 요구사항 및 해결 방안

### 1) 영화 같은 쿠로사와 흑백 톤 재설계
* **S자 명암 곡선 적용**: 어두운 영역은 더 깊은 검은색으로 누르고, 밝은 영역은 선명한 흰색으로 끌어올려 강렬한 흑백 대비를 만듭니다.
* **디테일 보존**: 중간 톤의 텍스처 질감과 외곽선이 묻히지 않도록 선명도를 보정합니다.

### 2) 단일 렌더러 피처 통합
* 두 개로 쪼개져 있던 도장 기능과 흑백 기능을 **단 하나의 렌더러 피처(`TimeSlowKurosawaFeature`)**로 완전히 합칩니다.
* **평소 상태**: 아무런 렌더 패스도 실행하지 않아 원래 게임 화면에 0% 간섭 및 성능 낭비 차단.
* **시간 정지 상태**: 
  1. 1단계: 플레이어와 타깃의 위치에 스텐실 1번 도장을 기록.
  2. 2단계: 스텐실 1번을 제외한 나머지 배경 영역에만 쿠로사와 흑백 필터를 적용.

---

## 4. 전체 렌더링 흐름도

```
[평상시]
    └─ 시간 정지 OFF 상태 : 연산 완전히 정지, 100% 정상 원본 컬러 화면

[시간 정지 발동 (T키 입력)]
    ├─ 1단계: 타깃 스텐실 도장 패스
    │   └─ 플레이어 및 마법 락온 대상 렌더러만 골라 스텐실 1번 기록
    │
    └─ 2단계: 쿠로사와 흑백 필터 패스
        ├─ 스텐실 == 1 (타깃, 플레이어) : 필터 통과 제외 -> 선명한 원본 컬러 100% 유지
        └─ 스텐실 != 1 (주변 배경, 지형) : S자 곡선 기반 고대비 흑백 필름 톤 적용
```

## 5. DLV 아키텍처 파일 설계

### [D] 데이터 그룹
* **Pure Data**: `Assets/02.System/05.TimeSlowFilter/00.Data/PureDataKurosawaFilter.cs`
  * 전환 시간, 그림자 깊이 수치, 하이라이트 강도, 대비 계수 보관

### [L] 로직 그룹
* **Logic System**: `Assets/02.System/05.TimeSlowFilter/01.Logic/TimeSlowFilterLogicSystem.cs`
  * 시간 정지 시작과 종료 신호를 받아 비주얼 인터페이스에 전환 지시
  * 순수 C# 클래스로 동작하며 렌더러나 엔진을 직접 제어하지 않음

### [V] 비주얼 그룹
* **Unified Feature**: `Assets/02.System/05.TimeSlowFilter/02.Visual/TimeSlowKurosawaFeature.cs`
  * 스텐실 도장과 흑백 필터를 하나로 묶은 단일 URP 렌더러 피처
  * 시간 정지가 아닐 때는 패스 등록을 완전히 건너뛰어 성능과 화면을 보호
* **Kurosawa Shader**: `Assets/02.System/05.TimeSlowFilter/02.Visual/Shaders/KurosawaExcludeTarget.shader`
  * 스텐실 1번 영역을 완벽히 제외하고, S자 곡선 고대비 흑백 필름 톤을 연산하는 셰이더
* **World Visualizer**: `Assets/02.System/05.TimeSlowFilter/02.Visual/TimeSlowFilterVisualizer.cs`
  * 현실 시간 기준으로 흑백 강도를 부드럽게 넘겨주는 연출 담당

## 6. DLV 3대 원칙 준수 확인
- [ ] **Everything is Data**: 흑백 필터의 모든 명암 및 시간 값을 Pure Data 객체로 정의
- [ ] **Blind Logic**: 로직 시스템이 셰이더나 렌더 패스를 직접 다루지 않고 인터페이스를 통해서만 상태 전달
- [ ] **Immutable Data**: 원본 머티리얼 에셋을 변경하지 않고 인스턴스 및 렌더 그래프 명령어로만 처리

## 7. QA 검증 및 테스트 가이드
* **컴파일 검사**: 유니티 에디터 에러 0건
* **테스트 케이스**:
  1. **평상시 화면 유지**: 시간 정지를 켜지 않았을 때 화면 색상이나 밝기에 아무런 왜곡이 없는지 확인
  2. **쿠로사와 흑백 질감**: 시간 정지 진입 시 뿌연 잿빛이 아니라 빛과 그림자가 뚜렷한 영화 같은 흑백으로 바뀌는지 확인
  3. **타깃 컬러 완벽 보존**: 플레이어와 마법 타깃이 회색으로 물들지 않고 원본의 생생한 색상을 칼같이 유지하는지 확인
  4. **시간 정지 해제 복귀**: 시간 정지를 풀면 즉시 흑백이 걷히고 원래 컬러 화면으로 자연스럽게 복귀하는지 확인
