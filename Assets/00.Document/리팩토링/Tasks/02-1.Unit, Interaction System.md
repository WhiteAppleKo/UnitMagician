# [02-1] 단위 마법 시점별 입력 처리 전략 패턴 리팩토링 및 시간 정지 카메라 독립 시간 연동

## 1. 작업 개요 및 유형
* **기능 요약**: 카메라 모드별 마법 조작 시스템을 전략 패턴(`IUnitCastingStrategy`)으로 전면 전환하여 탑뷰/숄더뷰 간 입력 누수를 원천 차단하고, 시간 정지(`Time.timeScale = 0`) 상태에서도 카메라가 자유롭게 회전/이동할 수 있도록 Cinemachine 및 카메라 파이프라인에 독립 시간(`unscaledDeltaTime`)을 전면 적용
* **작업 범위 구분**:
    * **기존 구현 완료**: 진영(`FactionType`) 및 `CharacterStatComponent` 적대 락온, `RuntimeDataUnitGroup` 다중 락온 데이터, 5종 카메라 모드
    * **신규 구현 대상**:
        1. 전략 인터페이스 `IUnitCastingStrategy` 정의 (`Enter`, `Update`, `Exit`)
        2. 탑뷰/쿼터뷰 전용 전략 `TopViewMouseCastingStrategy` 구현 (마우스 커서 호버 UI + 클릭 핀포인트 변환)
        3. 1인칭/3인칭 숄더뷰 전용 전략 `AimLockOnCastingStrategy` 구현 (크로스헤어 UI + 마우스 클릭 즉시 시전 차단 + 시간 정지 다중 락온 및 해제 시 일괄 시전)
        4. 컨텍스트 `UnitCasterSystem`에서 `OnCameraModeChanged` 이벤트 수신 시 현재 전략 교체(스위칭)
        5. `PlayerStateLogicSystem`의 마우스 좌클릭 시전 로직을 전략 패턴으로 일원화하여 모드 간 입력 누수 완전 제거
        6. Cinemachine 및 `CameraFollowVisualizer`, `CameraFollowService`의 모든 시간 기반 보간/추적 연산을 `Time.unscaledDeltaTime`으로 전면 전환하여 시간 정지 중 카메라 회전 완벽 보장
* **작업 유형**: 시청각 영역 및 비시청각 영역 복합

## 2. 핵심 요구사항
* **시청각 영역일 때**: 
    * [탑뷰/쿼터뷰 모드 (`HybridFocus`, `PlayerOnly`, `MouseFocus`)]: 마우스 커서 위치에 대상 정보 UI가 실시간 표시되며, 마우스 클릭 시 즉시 핀포인트 단위 마법이 발동된다.
    * [1인칭/3인칭 숄더뷰 모드 (`FirstPerson`, `ThirdPersonShoulder`)]: 화면 중앙에 크로스헤어가 표시되며 마우스 클릭 즉시 시전은 완전 차단된다. 시간 정지(T키) 중 카메라를 회전하여 시야 내 대상을 조준하면 다중 락온 마커가 누적되고, 시간 정지 해제 시 락온된 모든 대상에게 일괄 마법이 발동된다.
    * [시간 정지 중 카메라 회전 연출]: T키를 눌러 게임 내 시간이 정지(`Time.timeScale = 0`)된 상태에서도 1인칭 및 3인칭 숄더뷰 카메라가 마우스 입력에 따라 부드럽게 360도 회전하며 시야 내 타겟들을 탐색할 수 있어야 한다.
    * [카메라 모드 전환 시]: 모드가 바뀌는 즉시 이전 모드의 UI(호버 정보창 또는 크로스헤어/락온 마커)와 상태가 완전 정리되고, 새로운 모드의 입력 전략으로 즉시 교체된다.
* **비시청각 영역일 때**: 
    * [신규 - 독립 시간 적용]:
        1. 메인 카메라의 `CinemachineBrain`에 `IgnoreTimeScale = true`를 적용하여 시네머신 가상 카메라 엔진이 게임 타임스케일에 영향받지 않고 현실 시간 기준으로 항상 동작하도록 강제한다.
        2. `CameraFollowVisualizer.cs`의 피벗 회전 보간(`Quaternion.Slerp`) 및 `CameraFollowService.cs`의 위치 추적(`Vector3.SmoothDamp`), 줌 보간(`Mathf.SmoothDamp`)에 전달되는 델타타임을 모두 `Time.unscaledDeltaTime`으로 일원화하여 연산 정지(0) 현상을 원천 방지한다.
    * [신규 - 전략 패턴]:
        1. `IUnitCastingStrategy` 인터페이스를 기반으로 카메라 모드별 입력 처리 시스템을 분리 구현하고, `OnCameraModeChanged` 이벤트 발생 시 전략을 스위칭하여 매 프레임 `if` 조건문 검사 비용과 런타임 입력 누수를 원천 차단한다.
        2. `PlayerStateLogicSystem`과 `UnitCasterSystem` 간의 마법 시전 책임을 전략 패턴 컨텍스트로 단일화하여 아키텍처 결합도를 최소화한다.

## 5. QA 검증 및 테스트 가이드
* **컴파일 검사**: `dotnet build` 에러 0건
* **테스트 케이스**:
    * **정상 입력**:
        * 시간 정지(T키) 활성화(TimeScale=0) 상태에서 1인칭 및 3인칭 숄더뷰 카메라가 멈추거나 굳지 않고 마우스 조작에 따라 360도 자유롭게 회전/이동하는지 확인
        * 적대 진영(`Enemy`)의 `CharacterStatComponent`를 가진 오브젝트 조준 시 붉은색 락온 마커가 데이터적/시각적으로 정상 작동하는지 확인
        * `IsTargetable == true`인 사물 오브젝트 조준 시 락온 마커가 정상 표출되는지 확인
        * 1인칭 및 3인칭 숄더뷰 모드에서 시간 정지(T키) 중 카메라 회전으로 유효 대상 다중/중복 락온이 순차적으로 누적되는지 확인
        * 1인칭 및 3인칭 숄더뷰 모드에서 시간 정지 해제 시 중복 지정된 모든 대상에게 일괄 마법 변환이 적용되고 총 마나가 정상 차감되는지 확인 (마나 코스트 충분 시)
        * 락온 마커가 정상 표출된 유효 대상들만을 상대로 락온 타겟팅 및 마법 적용이 정확히 수행되는지 확인
        * 탑뷰/쿼터뷰 모드(`HybridFocus`, `PlayerOnly`, `MouseFocus`)에서 마우스 호버 시 정보창 표시 및 마우스 클릭 즉시 핀포인트 마법 변환이 정상 동작하는지 확인
        * 카메라 모드 전환 시 이전 모드의 UI(호버창 또는 크로스헤어/락온)가 즉시 정리되고, 디자인 패턴(전략 패턴, Strategy Pattern)에 따라 `IUnitCastingStrategy` 구현체 객체가 정상적으로 교체되어 동작하는지 확인
    * **비정상 입력 및 예외 처리**:
        * 1인칭 및 3인칭 숄더뷰 모드에서 마우스 좌클릭/우클릭 시 즉시 마법 발동 및 마나 소모가 완벽히 차단되는지 확인
        * 아군(`Ally`/`Player`) 및 비적대 진영 오브젝트 조준 시 락온 마커가 일체 뜨지 않는지 확인
        * `IsTargetable == false`인 사물 오브젝트 조준 시 락온 마커가 일체 뜨지 않는지 확인
        * 락온 마커가 뜨지 않은 오브젝트는 락온 리스트 등록 및 마법 시전 대상에서 완전히 제외되는지 확인
        * 다중 락온 대상이 0개인 상태에서 시간 정지 해제 시 마법 미발동 및 마나 미소모 확인
        * 다중 락온된 마법의 총 필요 마나가 보유 마나보다 많을 경우 마나 부족 알림 및 안전 예외 처리 확인
