## 2. 문제점 분석 (Code Smells - 5대 기준 위배 상세)

### 2-1. VContainer DI 전환 위배
* **Find 계열 탐색 및 태그 검색:** `UnitCasterSystem.cs`에서 `FindFirstObjectByType<UnitQuickSlotUIComponent>()`, `FindFirstObjectByType<CameraFollowVisualizer>()`, `GameObject.FindGameObjectWithTag("Player")`를 호출함.
* **직접 new 키워드 생성:** `new TopViewMouseCastingStrategy(...)`, `new AimLockOnCastingStrategy(...)`, `new UnitChangeService(...)`를 내부에서 직접 인스턴스화하여 DI 컨테이너를 우회함.

### 2-2. 극심한 코드 중복 (Code Duplication)
* **일괄 시전 로직 중복:** `UnitCasterSystem.ExecuteBatchCast()`와 `MultiLockOnLogicSystem.ExecuteBatchCast()`의 마나 검증, `CalculateNewValueForUnit()`, 타겟 순회 변환 코드가 완전히 중복되어 로직 수정 시 버그 발생 위험이 큼.

### 2-3. 설계 원칙 위배 (SRP / God Class)
* **다중 책임:** `UnitCasterSystem`이 전략 컨텍스트 스위칭뿐 아니라 마나 소모 연산, 타겟팅 예외 처리, 이펙트 지시까지 과도한 책임을 담당함.

### 2-4. DLV 아키텍처 위배
* `01.Logic` 폴더에 위치한 `UnitCasterSystem`이 `MonoBehaviour`를 상속받고 `Update()`를 돌며 직접적인 씬 오브젝트 및 UI Document에 결합됨.

## 3. 리팩토링 설계 (To-Be Architecture)

```
[L: Logic Layer]
UnitCasterLogicSystem (ITickable, IDisposable - Pure C#)
├── IUnitCastingStrategy (전략 인터페이스)
│   ├── TopViewMouseCastingStrategy
│   └── AimLockOnCastingStrategy
└── IUnitBatchCastingService (일괄 시전 공통 비즈니스 로직 단일화)

[V: Visualizer Layer]
UnitCasterVisualizer (MonoBehaviour)
├── 카메라 레이캐스트 / 마우스 월드 좌표 연산
└── UnitGhostPreviewComponent (고스트 프리뷰 렌더링)
```

### 3-1. 일괄 시전 로직 단일화 (공통 서비스 추출)
* 중복되는 마나 계산 및 유닛 수치 산출 로직을 `IUnitBatchCastingService`로 일원화.

### 3-2. 전략 객체 DI 팩토리화 및 순수 C# 로직 전환
* `TopViewMouseCastingStrategy`와 `AimLockOnCastingStrategy`를 VContainer에서 관리되는 객체로 등록.
* `UnitCasterSystem`을 `ITickable`을 구현하는 순수 C# `UnitCasterLogicSystem`으로 분리.

## 4. 단계별 변경 명세

* 전략 및 시전 시스템을 LifetimeScope에 등록.

## 5. 기능 무결성 검증 기준 및 테스트 케이스

### 검증 체크리스트
1. **탑뷰 마우스 시전:** 탑뷰 시점에서 마우스 호버 대상에 마법 프리뷰 표시 및 클릭 시 유닛 변환이 정상 동작하는가?
2. **숄더/1인칭 에임 락온:** 숄더뷰/1인칭에서 에임 조준선에 들어온 다중 타겟 락온 누적이 정상 작동하는가?
3. **일괄 시전 마나 차감:** 다중 타겟 일괄 변환 시 총 필요 마나가 1회 정확히 차감되며, 마나 부족 시 시전이 취소되는가?
