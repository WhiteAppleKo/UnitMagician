## 2. 문제점 분석 (Code Smells - 5대 기준 위배 상세)

### 2-1. DLV 아키텍처 위배 (Data 계층의 오염)
* **MonoBehaviour 및 Visual 컴포넌트 상속:** `RuntimeDataUnitGroup.cs`가 `SampleObjectLockOn`(MonoBehaviour)을 상속받아 `Highlight()` 렌더링/머티리얼 교체 로직을 Data 레이어에서 직접 수행하고 있음.
* **가이드라인 위배:** DLV 가이드라인상 `00.Data`는 Pure C# 클래스 또는 ScriptableObject여야 하며, 월드 오브젝트 상호작용 및 렌더링을 직접 제어할 수 없음.

### 2-2. 설계 원칙 위배 (SRP - 단일 책임 원칙)
* **God Component 형태:** `RuntimeDataUnitGroup`이 단위 데이터(Mass, Volume, Vector) 관리, 인스펙터 직렬화 설정, 베이킹된 질량 보관, 마우스/락온 하이라이트 처리를 한 곳에서 담당함.

## 3. 리팩토링 설계 (To-Be Architecture)

```
[D: Data Layer]
PureDataUnit (ScriptableObject - Immutable, Logic-Free)
RuntimeDataUnit (Pure C# Observable Model)
RuntimeDataUnitGroup (Pure C# Data Group Container)

[V: Visualizer Layer]
UnitTargetComponent / UnitTargetObjectVisualizer (MonoBehaviour)
├── RuntimeDataUnitGroup 인스턴스 보유 및 생명주기 관리
└── ILockOnTarget / IHighlightable 구현을 통한 시각 효과 전담
```

### 3-1. 순수 데이터 모델 추출
* `RuntimeDataUnitGroup`을 MonoBehaviour 종속성이 없는 Pure C# Observable 클래스로 변경.
* 데이터 변경 이벤트(`OnUnitGroupChanged`, `OnTargetableChanged`)를 통해 외부(Logic/Visual)에 상태 통보.

### 3-2. 월드 컴포넌트 분리
* 씬 오브젝트에 부착되는 컴포넌트는 `UnitGroupComponent`(또는 `UnitTargetObjectVisualizer`)로 분리하여 `SampleObjectLockOn` 상속 및 하이라이트 시각 효과를 전담.

## 4. 단계별 변경 명세

### Step 1: Pure C# RuntimeDataUnitGroup 구현
* `Assets/02.System/01.UnitSystem/00.Data/RuntimeDataUnitGroup.cs`:
  ```csharp
  namespace UnitSystem
  {
      public class RuntimeDataUnitGroup
      {
          public UnitType SupportedUnits { get; private set; }
          public bool IsTargetable { get; private set; }
          public float BakedMassValue { get; set; }
          public List<RuntimeDataUnit> Units { get; } = new();

          public event Action<RuntimeDataUnitGroup, RuntimeDataUnit> OnUnitGroupChanged;
          public event Action<bool> OnTargetableChanged;

          public RuntimeDataUnitGroup(UnitType supportedUnits, float bakedMass = 1.0f, bool isTargetable = true)
          {
              SupportedUnits = supportedUnits;
              BakedMassValue = bakedMass;
              IsTargetable = isTargetable;
              InitUnits();
          }
          // ... 데이터 관리 순수 메서드
      }
  }
  ```

### Step 2: UnitGroupComponent (Visualizer) 신설 및 이관
* 인스펙터 직렬화 필드 및 `Highlight()` 오버라이드는 `UnitTargetObjectVisualizer` 또는 `UnitGroupComponent`로 이관.
