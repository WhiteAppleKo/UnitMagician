## 2. 문제점 분석 (Code Smells - 5대 기준 위배 상세)

### 2-1. 중복 코드 및 레거시 클래스 방치
* **100% 중복 레거시 잔재:** `00.Movement/.../UI/Legacy/CameraModeUIComponent.cs`는 신규 옵션 UI 시스템(`OptionUIComponent`)과 버튼 콜백 및 하이라이트 로직이 완전히 중복되어 프로젝트 내 혼선을 유발함.
* **불필요한 빈 파생 클래스:** `CameraOptionUIController.cs`가 본문 없이 단순 상속만 선언된 상태로 방치됨.

### 2-2. DLV 및 디자인 패턴 위배
* **Update 폴링:** `OptionUIComponent.cs`의 `Update()`에서 `Keyboard.current.escapeKey.wasPressedThisFrame`을 폴링하여 옵션창을 토글함 -> Input System 이벤트 방식으로 전환 필요.
* **엔진 환경 변수 직접 제어:** UI 컴포넌트가 `Time.timeScale = 0f / 1f`를 직접 제어함.

## 3. 리팩토링 설계 (To-Be Architecture)

```
[V: UI View Layer]
OptionUIView (통합 옵션 UI - 탭 전환, 카메라 모드 변경 버튼, 해상도/사운드 설정 전담)

[폐기 대상]
- CameraModeUIComponent.cs (삭제)
- CameraOptionUIController.cs (삭제 또는 OptionUIView로 통폐합)
```

### 3-1. 레거시 클래스 완전 폐기 및 통합
* `CameraModeUIComponent` 및 `CameraOptionUIController`를 삭제하고 `OptionUIView` 단일 컴포넌트로 통합.

### 3-2. ESC 키 입력 이벤트 푸시 전환
* `InputReader`의 ESC 취소/옵션 이벤트를 구독하여 폴링 제거.
