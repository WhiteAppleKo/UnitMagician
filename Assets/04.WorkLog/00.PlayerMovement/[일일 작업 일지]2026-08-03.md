# [일일 작업 일지]2026-08-03

## 1. 작업 개요
* 캐릭터 WASD 이동 및 카메라 벽 밀림 연출 시스템 구현
* Unity DLV (Data-Logic-Visual) 아키텍처 v0.2 준수
* VContainer 의존성 주입 및 New Input System 적용

---

## 2. 문제·변경·성과 (Before-After + Why)

### Step 1: 이동 및 회전 기본 구현
* **Before:** 기본 이동 스크립트 부재
* **After:** PureData, RuntimeData, LogicSystem, Visualizer 분리 구조 기반 WASD 이동 및 Slerp 회전 구현
* **Why:** DLV 규칙 준수 및 데이터-로직-비주얼 분리

### Step 2: New Input System 개편
* **Before:** 레거시 Input.GetAxisRaw 입력 감지
* **After:** UnityEngine.InputSystem Keyboard.current 기반 개편
* **Why:** 최신 입력 패키지 표준화

### Step 3: VContainer 의존성 주입 및 순수 C# 클래스 리팩토링
* **Before:** 수동 파사드 Controller 컴포넌트 및 MonoBehaviour 상속 로직 시스템
* **After:** MovementLifetimeScope 기반 VContainer 바인딩 및 ITickable/IFixedTickable 순수 C# 클래스 변환
* **Why:** Unity 생명주기 결합도 최소화 및 자동 의존성 주입 확보

### Step 4: 네임스페이스 통일 및 API 경고 대응
* **Before:** UnitMagician.Movement 네임스페이스 및 Rigidbody.velocity obsolete 경고 발생
* **After:** PlayerMovement 네임스페이스 변경 및 Rigidbody.linearVelocity 교체
* **Why:** 프로젝트 네임스페이스 표준화 및 Unity 최신 API 호환

### Step 5: NullReferenceException 방지 및 카메라 벽 밀림 연출 추가
* **Before:** Inspector 드래그 미연결 시 visualizer null 예외 발생 및 벽 충돌 피드백 부재
* **After:** RegisterComponentInHierarchy 적용 예외 차단, PlayerCameraSystem 기반 벽 밀림 오프셋 연출 추가
* **Why:** 안정성 확보 및 플레이어 경계 막힘 직관적 간접 전달

### Step 6: 하드코딩 제거
* **Before:** PlayerCameraSystem 내부 0.5f 임계값 하드코딩
* **After:** PureDataCamera WallStuckThreshold 데이터 속성 추출
* **Why:** 데이터 중심 관리 (Rule 1 준수)

## 3. 상세 사용 가이드

1. **에셋 준비:**
   * Create > PlayerMovement > Data > PlayerMovement 에셋 생성
   * Create > PlayerMovement > Data > Camera 에셋 생성

2. **GameObject 설정:**
   * Player GameObject: Rigidbody, PlayerMovementVisualizer 컴포넌트 추가
   * Main Camera GameObject: PlayerCameraVisualizer 컴포넌트 추가
   * MovementLifetimeScope GameObject: MovementLifetimeScope 컴포넌트 추가

3. **LifetimeScope 연결:**
   * MovementLifetimeScope Inspector 필드 PureDataPlayerMovement, PureDataCamera 에셋 연결

4. **실행:**
   * Play 클릭, WASD 이동 및 벽 충돌 카메라 밀림 동작 확인

---

## 4. 문제 재현 방법

### Case 1: VContainer visualizer null 예외
* 계층 구조 PlayerMovementVisualizer 존재 미확인 상태 실행 시 예외 발생
* 해결: RegisterComponentInHierarchy 자동 검색 바인딩 적용

### Case 2: Obsolete API 경고
* Rigidbody.velocity 호출 시 CS0618 경고 발생
* 해결: Rigidbody.linearVelocity 구문 교체
